3. Boas Problems, Section 17 — complete solutions

Every numerical answer below was checked by computer, as Boas recommends.

1. $\left(\dfrac{1+i}{1-i}\right)^{2718}$
Show solution

$\frac{1+i}{1-i}=\frac{(1+i)^2}{2}=i$. Since $2718=4\cdot679+2$, the answer is $i^{2718}=i^2=-1$.

2. $\left(\dfrac{1+i\sqrt3}{\sqrt2+i\sqrt2}\right)^{50}$
Show solution

$\frac{2e^{i\pi/3}}{2e^{i\pi/4}}=e^{i\pi/12}$. Then $e^{50\pi i/12}=e^{25\pi i/6}=e^{4\pi i}e^{i\pi/6}=\frac{\sqrt3}2+\frac i2$.

3. $\sqrt[5]{-4-4i}$
Show solution

$-4-4i=4\sqrt2e^{5\pi i/4}=2^{5/2}e^{5\pi i/4}$. So $\rho=2^{1/2}=\sqrt2$ and the angles are $\frac\pi4+\frac{2k\pi}5$: $45^\circ,117^\circ,189^\circ,261^\circ,333^\circ$.

Values: $1+i,\ -0.642+1.260i,\ -1.397-0.221i,\ -0.221-1.397i,\ 1.260-0.642i$.

4. $\sinh(1+i\pi/2)$   5. $\tanh(i\pi/4)$
Show solution

4: $\sinh1\cos\frac\pi2+i\cosh1\sin\frac\pi2=i\cosh1=1.543i$.   5: $\tanh(i\pi/4)=i\tan\frac\pi4=i$.

6. $(-e)^{i\pi}$   7. $(-i)^i$
Show solution

6: $\ln(-e)=1+i(\pi+2n\pi)$, so $(-e)^{i\pi}=e^{i\pi[1+i(2n+1)\pi]}=e^{i\pi}e^{-(2n+1)\pi^2}=-e^{-(2n+1)\pi^2}$. Principal: $-e^{-\pi^2}=-5.17\times10^{-5}$.

7: $\ln(-i)=i\left(-\frac\pi2+2n\pi\right)$, so $(-i)^i=e^{\pi/2-2n\pi}$. Principal: $e^{\pi/2}=4.810$.

8. $\cos\left[2i\ln\dfrac{1-i}{1+i}\right]$   9. $\arcsin\left[\left(\dfrac{\sqrt3+i}{\sqrt3-i}\right)^{12}\right]$
Show solution

8: $\frac{1-i}{1+i}=-i$ and $\ln(-i)=i\left(-\frac\pi2+2n\pi\right)$, so $2i\ln(-i)=\pi-4n\pi$ and $\cos=-1$.

9: $\frac{\sqrt3+i}{\sqrt3-i}=\frac{2e^{i\pi/6}}{2e^{-i\pi/6}}=e^{i\pi/3}$. The 12th power is $e^{4\pi i}=1$. So $\arcsin1=\frac\pi2+2n\pi$.

10. $e^{2i\arctan(i\sqrt3)}$   11. $e^{2\tanh^{-1}i}$   12. $e^{i\arcsin i}$
Show solution

10: $2i\arctan w=\ln\frac{1+iw}{1-iw}$, so $e^{2i\arctan w}=\frac{1+iw}{1-iw}$ (single valued!). With $w=i\sqrt3$: $\frac{1-\sqrt3}{1+\sqrt3}=\frac{(1-\sqrt3)^2}{-2}=\sqrt3-2\approx-0.268$.

11: $2\tanh^{-1}w=\ln\frac{1+w}{1-w}$, so the answer is $\frac{1+i}{1-i}=i$.

12: $i\arcsin w=\ln(iw\pm\sqrt{1-w^2})$, so the answer is $iw\pm\sqrt{1-w^2}$ with $w=i$: $-1\pm\sqrt2$, i.e. $0.414$ or $-2.414$.

13. Find real $x$ and $y$ for which $|z+3|=1-iz$, where $z=x+iy$.
Show solution

$1-iz=1+y-ix$ must be real and $\ge0$: $x=0$, $y\ge-1$. Then $|iy+3|=\sqrt{9+y^2}=1+y$ gives $9+y^2=1+2y+y^2$, so $y=4$. Answer $z=4i$ (check: $|3+4i|=5=1-i(4i)$ ✔).

14. Find the disk of convergence of $\sum(z-2i)^n/n$.
Show solution

$\rho=|z-2i|$, so the disk is $|z-2i|\lt1$ (centre $2i$, radius 1).

15. For what $z$ is $\sum z^{\ln n}$ absolutely convergent?
Show solution

$z^{\ln n}=e^{\ln n\cdot\ln z}=n^{\ln z}$, so $|z^{\ln n}|=n^{\operatorname{Re}\ln z}=n^{\operatorname{Ln}|z|}$ (the same for every branch). $\sum n^{-p}$ converges iff $p>1$, so we need $\operatorname{Ln}|z|\lt-1$, i.e. $|z|\lt\frac1e$.

16. Describe the set of points $z$ for which $\operatorname{Re}(e^{i\pi/2}z)>2$.
Show solution

$e^{i\pi/2}z=iz=-y+ix$, so we need $-y>2$, i.e. $y\lt-2$: the half-plane below the line $\operatorname{Im}z=-2$. (Geometrically: rotating by $90^\circ$ must land the point to the right of $x=2$.)

17–24. Verify the inverse-function formulas, and $\cos iz=\cosh z$, $\cosh iz=\cos z$.
Show solution

17–22 are derived in full on the 2.15 page (Section 3, "Show derivations"), each by putting $u=e^{iw}$ or $e^w$ and solving a quadratic. 23: $\cos iz=\frac{e^{-z}+e^{z}}2=\cosh z$. 24: $\cosh iz=\frac{e^{iz}+e^{-iz}}{2}=\cos z$.

25. (a) $\overline{\cos z}=\cos\bar z$? (b) $\overline{\sin z}=\sin\bar z$? (c) $f(z)=1+iz$: is $\overline{f(z)}=f(\bar z)$? (d) real power series. (e) Show $i[\sinh(1+i)-\sinh(1-i)]$ is real.
Show solution

(a) Yes: $\overline{\frac{e^{iz}+e^{-iz}}2}=\frac{e^{-i\bar z}+e^{i\bar z}}{2}=\cos\bar z$. (b) Yes, in the same way.

(c) No: $\overline{f(z)}=1-i\bar z$, but $f(\bar z)=1+i\bar z$. The coefficient $i$ is not real.

(d) $f(z)=\sum a_nz^n$ with $a_n$ real gives $\overline{f(z)}=\sum\bar a_n\bar z^n=\sum a_n\bar z^n=f(\bar z)$.

(e) $\sinh$ has real coefficients, so $\sinh(1-i)=\overline{\sinh(1+i)}$. With $w=\sinh(1+i)$: $i(w-\bar w)=i\cdot2i\operatorname{Im}w=-2\operatorname{Im}w$, which is real ✔.

26. Find $\left|\dfrac{2e^{i\theta}-i}{ie^{i\theta}+2}\right|$.
Show solution

Use $|w|^2=w\bar w$. Numerator: $(2e^{i\theta}-i)(2e^{-i\theta}+i)=4+2ie^{i\theta}-2ie^{-i\theta}+1=5-4\sin\theta$. Denominator: $(ie^{i\theta}+2)(-ie^{-i\theta}+2)=1+2ie^{i\theta}-2ie^{-i\theta}+4=5-4\sin\theta$. So the ratio is $1$ for every real $\theta$.

27. (a) $\operatorname{Re}z=\frac12(z+\bar z)$, $\operatorname{Im}z=\frac1{2i}(z-\bar z)$. (b) $|e^z|^2=e^{2\operatorname{Re}z}$. (c) Evaluate $\left|e^{(1+ix)^2(1-it)-|1+it|^2}\right|^2$.
Show solution

(a) $z+\bar z=2x$ and $z-\bar z=2iy$. (b) $|e^z|^2=e^ze^{\bar z}=e^{z+\bar z}=e^{2\operatorname{Re}z}$.

(c) $(1+ix)^2(1-it)=(1-x^2+2ix)(1-it)$, whose real part is $1-x^2+2xt$. Also $|1+it|^2=1+t^2$. So the answer is $e^{2(1-x^2+2xt)-2(1+t^2)}=e^{-2(x-t)^2}$: a Gaussian centred at $x=t$, i.e. a wave packet moving with speed 1.

28. Evaluate $\left|\dfrac{(a+bi)^2e^b-(a-bi)^2e^{-b}}{4abie^{-ia}}\right|^2$ ($a,b$ real) in terms of a hyperbolic function.
Show solution

The denominator has modulus $4ab$. Let $(a+bi)^2=A+iB$ with $A=a^2-b^2$ and $B=2ab$. The numerator is $(A+iB)e^b-(A-iB)e^{-b}=2A\sinh b+2iB\cosh b$. So

$$\frac{4A^2\sinh^2b+4B^2\cosh^2b}{16a^2b^2}=\frac{(a^2-b^2)^2\sinh^2b+4a^2b^2(1+\sinh^2b)}{4a^2b^2}=1+\frac{(a^2+b^2)^2}{4a^2b^2}\sinh^2b .$$

(This is the barrier-tunnelling formula of quantum mechanics.)

29. If $z=\frac ab$ and $\frac{1}{a+b}=\frac1a+\frac1b$, find $z$.
Show solution

$\frac1{a+b}=\frac{a+b}{ab}$ gives $ab=(a+b)^2$, so $a^2+ab+b^2=0$. Dividing by $b^2$: $z^2+z+1=0$, so $z=\frac{-1\pm i\sqrt3}{2}=\omega,\ \omega^2$ (the complex cube roots of unity). So $a$ and $b$ cannot both be real.

30. The series for $e^{x(1+i)}$ and the $e^x\cos x$, $e^x\sin x$ series.
Show solution

$(1+i)^n=2^{n/2}e^{in\pi/4}$, so $e^x\cos x=\sum\frac{2^{n/2}\cos(n\pi/4)}{n!}x^n$ and $e^x\sin x=\sum\frac{2^{n/2}\sin(n\pi/4)}{n!}x^n$. Since $\cos\frac{n\pi}4=0$ for $n=2,6,10,\dots$, there are no $x^2,x^6,\dots$ terms in $e^x\cos x$. Since $\sin\frac{n\pi}{4}=0$ for $n=0,4,8,\dots$, there are no $x^4,x^8,\dots$ terms in $e^x\sin x$. (Details on the 2.8 page.)

31. Show $z_n\to0\iff|z_n|\to0$.
Show solution

$\max(|a_n|,|b_n|)\le|z_n|\le|a_n|+|b_n|$. If $|z_n|\to0$, both $a_n,b_n\to0$. Conversely, if $a_n,b_n\to0$ then $|a_n|+|b_n|\to0$, so $|z_n|\to0$.

32. Show $\displaystyle\sum_{n=0}^\infty\frac{(1+i\pi)^n}{n!}=-e$.
Show solution

This is the exponential series: $e^{1+i\pi}=e\cdot e^{i\pi}=-e$ ✔.

6. Exam-level mixed problems (CSIR NET / GATE / JAM style)

M1. If $z=\frac{\sqrt3+i}{2}$, find $z^{69}$. Easy
Show solution

$z=e^{i\pi/6}$, so $z^{69}=e^{69\pi i/6}=e^{23\pi i/2}=e^{-i\pi/2}\cdot e^{12\pi i}=-i$.

M2. How many solutions does $z^2+|z|^2=0$ have? Medium
Show solution

$x^2-y^2+2ixy+x^2+y^2=2x^2+2ixy=0$ gives $x=0$ (and then $2xy=0$ automatically). So every $z=iy$ works: infinitely many (the whole imaginary axis).

M3. Identify $|z-i|+|z+i|=4$. Easy
Show solution

An ellipse with foci $\pm i$, $a=2$, $c=1$, $b=\sqrt3$, major axis vertical: $\frac{x^2}3+\frac{y^2}4=1$.

M4. Evaluate $\displaystyle\sum_{k=0}^n\binom nk\cos k\theta$. Medium
Show solution

$\operatorname{Re}(1+e^{i\theta})^n=\operatorname{Re}\left[2^n\cos^n\frac\theta2\,e^{in\theta/2}\right]=2^n\cos^n\frac\theta2\cos\frac{n\theta}2$.

M5. With $\omega=e^{2\pi i/3}$, evaluate $(1+\omega-\omega^2)^7$. Medium
Show solution

$1+\omega=-\omega^2$, so $1+\omega-\omega^2=-2\omega^2$. Then $(-2\omega^2)^7=-128\,\omega^{14}=-128\,\omega^2$.

M6. Find the greatest $|z|$ such that $\left|z+\frac1z\right|=1$. Hard
Show solution

$|z|-\frac1{|z|}\le1$ gives $r^2-r-1\le0$, so $r\le\frac{1+\sqrt5}{2}$ (the golden ratio). Equality needs $z$ and $1/z$ to point in opposite directions, i.e. $z=iR$: then $|iR+\frac{1}{iR}|=R-\frac1R=1$ ✔. Maximum $\frac{1+\sqrt5}2\approx1.618$.

M7. Solve $z^2+2\bar z=0$. Medium
Show solution

Real part: $x^2-y^2+2x=0$. Imaginary part: $2xy-2y=0$, so $y=0$ or $x=1$. With $y=0$: $x^2+2x=0$, so $x=0$ or $-2$. With $x=1$: $3-y^2=0$, so $y=\pm\sqrt3$. Solutions: $0,\ -2,\ 1\pm i\sqrt3$.

M8. All values of $(-1)^{1/\pi}$, and how many there are. Medium
Show solution

$e^{\frac1\pi(i\pi+2n\pi i)}=e^{i(2n+1)}$. The exponent $1/\pi$ is irrational, so there are infinitely many values, all on the unit circle. Principal: $e^{i}=0.540+0.841i$.

M9. Evaluate $\displaystyle\sum_{n=1}^\infty\frac{\sin(n\pi/3)}{2^n}$. Medium
Show solution

$\operatorname{Im}\frac{w}{1-w}$ with $w=\frac12e^{i\pi/3}$ equals $\frac{2\sin\theta}{5-4\cos\theta}$ at $\theta=\frac\pi3$: $\frac{\sqrt3}{3}=\frac1{\sqrt3}$.

M10. Show $\displaystyle\int_0^{2\pi}\cos^{2n}\theta\,d\theta=\frac{2\pi}{4^n}\binom{2n}{n}$. Hard
Show solution

$\cos^{2n}\theta=\frac{1}{4^n}(e^{i\theta}+e^{-i\theta})^{2n}=\frac1{4^n}\sum_k\binom{2n}ke^{i(2n-2k)\theta}$. Only the $k=n$ term (the constant) survives integration over $[0,2\pi]$, giving $\frac{2\pi}{4^n}\binom{2n}n$.

M11. Find all $z$ with $e^z=1+i\sqrt3$, and the one with smallest $|z|$. Easy
Show solution

$z=\operatorname{Ln}2+i\left(\frac\pi3+2n\pi\right)$. The smallest $|z|$ is for $n=0$: $0.693+1.047i$.

M12. Solve $\sin z=3$. Medium
Show solution

$z=\frac\pi2+2n\pi\pm i\operatorname{Ln}(3+2\sqrt2)=\frac\pi2+2n\pi\pm1.763i$.

M13. Radius of convergence of the Taylor series of $\frac{1}{z^2+2z+2}$ about $z=1$. Medium
Show solution

The poles are at $z=-1\pm i$. Their distance from $1$ is $|2\mp i|=\sqrt5$, so $R=\sqrt5$.

M14. The points $z$, $iz$, $z+iz$ form a triangle. Find its area. Medium
Show solution

From the vertex $z$, the sides are $iz-z$ and $(z+iz)-z=iz$. Area $=\frac12|\operatorname{Im}(\overline{(iz-z)}\,iz)|=\frac12|z|^2$. (Check with $z=1$: vertices $1$, $i$, $1+i$, a right triangle with legs 1, so area $\frac12$ ✔.)

M15. (JAM) If $|z_1|=|z_2|=1$ and $z_1+z_2=1$, find $z_1$ and $z_2$. Medium
Show solution

Two unit vectors adding to the unit vector $1$ form an equilateral triangle: $z_{1,2}=e^{\pm i\pi/3}=\frac12\pm\frac{\sqrt3}2i$.

8. Going deeper: five ideas that tie Chapter 2 together

  1. Multiplication is rotation plus scaling. Polar form $re^{i\theta}$ turns products, powers and roots into "multiply moduli, add angles" (2.3, 2.9, 2.10).
  2. Conjugation is a symmetry. $\bar z$ gives Re and Im, the modulus, real-polynomial root pairing, and $|z|=1\Leftrightarrow\bar z=1/z$ (2.2, 2.4, 2.5).
  3. Everything elementary is $e^z$. $\sin$, $\cos$, $\sinh$ and $\cosh$ are combinations of $e^{\pm z}$ or $e^{\pm iz}$, and $\ln$ and the inverses are its inverse (2.8, 2.11–2.15).
  4. Multivaluedness comes from $\arg$. The $2\pi k$ in the argument produces infinitely many logs, $n$ roots, and the classification of values of $a^b$ (2.13, 2.14).
  5. Geometric series everywhere. Convergence, trigonometric sums, $N$-slit interference and roots-of-unity identities are all $\sum w^n$ (2.6, 2.10, 2.16).

The ten traps of Chapter 2
  1. $\sqrt a\sqrt b\ne\sqrt{ab}$ for negative $a,b$.
  2. $\arctan(y/x)$ ignores the quadrant.
  3. $\operatorname{Arg}(z_1z_2)$ can overflow $(-\pi,\pi]$.
  4. $e^z$ has period $2\pi i$, not $2\pi$.
  5. $|\sin z|$ and $|\cos z|$ are unbounded.
  6. $\tan z=\pm i$ has no solution.
  7. $\operatorname{Ln}(e^z)\ne z$ when $|\operatorname{Im}z|\gt\pi$.
  8. Reduce $p/q$ before counting the values of $a^{p/q}$.
  9. Removable singularities do not limit the radius of convergence.
  10. $|z-a|-|z-b|=|a-b|$ is a ray, not a hyperbola.

T1. Evaluate $\dfrac{(\sqrt3+i)^6}{(1-i)^4}$. NATEasy
Show solution

$(2e^{i\pi/6})^6=64e^{i\pi}=-64$ and $(1-i)^4=(-2i)^2=-4$. The answer is $\mathbf{16}$.

T2. The number of solutions of $z^4=\bar z$ is MCQMedium
(a) 4(b) 5(c) 6(d) infinitely many
Show solution

Moduli: $|z|^4=|z|$, so $|z|=0$ or $1$. On $|z|=1$, $\bar z=1/z$ and the equation becomes $z^5=1$, giving 5 roots. With $z=0$ that makes 6. Option (c).

T3. Find the principal value of $(-i)^{-i}$, to three decimal places. NATMedium
Show solution

$\operatorname{Ln}(-i)=-\frac{i\pi}2$, and $-i\cdot\left(-\frac{i\pi}2\right)=-\frac\pi2$. The value is $e^{-\pi/2}=\mathbf{0.208}$.

T4. Evaluate $\displaystyle\sum_{n=0}^\infty\frac{\cos(2n\pi/3)}{2^n}$, to three decimal places. NATMedium
Show solution

$\operatorname{Re}\frac{1}{1-\omega/2}$ with $\omega=e^{2\pi i/3}$. $1-\frac\omega2=\frac54-\frac{\sqrt3}4i$, so the real part of the reciprocal is $\frac{5/4}{25/16+3/16}=\frac57=\mathbf{0.714}$.

T5. The number of $z$ with $|z-1|=|z+1|=|z-i|$ is MCQEasy
(a) 0(b) 1(c) 2(d) infinitely many
Show solution

The first equality gives $x=0$ and the second gives $y=x$. So $z=0$ only, the circumcentre of the triangle $1,-1,i$. Option (b).

T6. The set where $|e^{iz}|\lt1$ is MCQEasy
(a) $\operatorname{Re}z\gt0$(b) $\operatorname{Im}z\gt0$(c) $\operatorname{Im}z\lt0$(d) $|z|\lt1$
Show solution

$|e^{iz}|=e^{-y}\lt1\iff y\gt0$. Option (b). This is why $e^{imz}$ ($m\gt0$) is used with upper semicircles in 14.7.

T7. $\sinh\dfrac{i\pi}{6}=$ MCQEasy
(a) $\frac12$(b) $\frac i2$(c) $\frac{\sqrt3}2$(d) $i\frac{\sqrt3}2$
Show solution

$\sinh(iy)=i\sin y=\frac i2$. Option (b).

T10. Show that every root of $(z+1)^6=z^6$ lies on the line $\operatorname{Re}z=-\frac12$, and find how many roots there are. Part CHard
Show solution

Taking moduli: $|z+1|=|z|$. That is the perpendicular bisector of $0$ and $-1$, the line $\operatorname{Re}z=-\frac12$. The equation is actually of degree 5, because the $z^6$ terms cancel: $6z^5+\dots+1=0$. So there are 5 roots. Explicitly, $\frac{z+1}{z}=e^{2\pi ik/6}$ for $k=1,\dots,5$ gives $z=\frac{1}{e^{i\pi k/3}-1}=-\frac12-\frac i2\cot\frac{\pi k}{6}$.
