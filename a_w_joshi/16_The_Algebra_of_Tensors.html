0. Roadmap

Section 15 defined a tensor by its transformation law. This section asks: which operations on tensors give tensors again? The answer is a short list. Anything outside it is suspect.

1. Equality, null tensor, addition, subtraction (Eqs. 1–7)

  • Same type: two tensors with the same contravariant rank and the same covariant rank.
  • Equality: same type, and every component equal: Ai₁…ipj₁…jq = Bi₁…ipj₁…jq.  (1)
  • Null tensor: all Nr components are 0. By (15.41), if every component is zero in one system it is zero in all systems. Every term on the right side contains a zero component.
  • Sum C = A + B, component by component, only for the same type.  (2)

Proof that the sum is a tensor: A and B transform with the same chain of Jacobian factors, because they are the same type. Adding (3) and (15.41) term by term, the common factors come out: C̄ = (∂x̄/∂x)…(∂x/∂x̄)…(A + B) = (factors)·C.  (4–6)   The same works for the difference D = A − B.  (7)

Why the types must match Ai + Bi: the first part transforms with ∂x̄/∂x and the second with ∂x/∂x̄. No common factor can be taken out, so the sum transforms like nothing. That is why "Ai = Bi" is not a valid tensor equation (except in Cartesian coordinates, where the two kinds coincide).
Consequence: the most useful fact in physics If A = B holds in one frame (both tensors), then A − B is a null tensor, so A = B in every frame. So once you have proved a tensor equation in a convenient coordinate system, it is proved in all of them.

2. Outer (Kronecker) product (Eqs. 8–12)

Definition Multiply every component of one tensor by every component of the other, using distinct indices:
Cijpkq = Aijk Bpq   (10)
Contravariant rank = sum of contravariant ranks (2 + 1 = 3). Covariant rank = sum of covariant ranks (1 + 1 = 2). Total rank 5, N⁵ components.

Proof: multiply the transformation laws (8a) and (8b). The product of the two Jacobian chains is exactly the chain for a tensor with upper indices i, j, p and lower indices k, q:

C̄αβργσ = (∂x̄α/∂xi)(∂x̄β/∂xj)(∂x̄ρ/∂xp)(∂xk/∂x̄γ)(∂xq/∂x̄σ) Cijpkq   (11)

Example 1: the outer product of Aij, Bk and Clmnp, written with all-different indices, is Dilmjknp = AijBkClmnp, a tensor of rank 7 (contravariant 3, covariant 4).  (12)

Use distinct indices Writing the outer product of Aij, Bk, Clmnp as AijBkClmkp would be wrong: the repeated k would mean a sum, which is no longer an outer product.

Link to Section 13: for two vectors, the outer product AiBj is the N×N matrix abᵀ, i.e. the Kronecker product a ⊗ b arranged as a matrix. A rank-2 tensor built this way always has matrix rank 1.

3. Inner product (Eqs. 13–18, Example 2)

Definition Take an outer product, but set one upper index of one tensor equal to one lower index of the other and sum:
Cijq = Aijk Bkq   (17)
Rank = (3 + 2) − 2 = 3. N³ functions.

Proof, step by step

  1. In the outer-product law (9), put ρ = γ and sum over γ.  (13)
  2. The two Jacobian factors attached to γ are (∂xk/∂x̄γ)(∂x̄γ/∂xp) = δkp by (15.23).  (14)
  3. The δ kills the sum over p, leaving only p = k.  (15)
  4. What remains is exactly the law for a tensor with upper i, j and lower q. ∎  (16)

There are several inner products of the same pair: AijkBpi, AijkBpj, AijkBkq, and the double contractions AijkBki, AijkBkj (each a contravariant vector).

Example 2: AijkBjq is NOT a tensor

Here j is summed but it is upper in both. In the transformation the two j-factors are (∂x̄α/∂xj)… paired with (∂x̄ρ/∂xp). Setting ρ = α gives (∂x̄α/∂xi)(∂x̄α/∂xp) summed over α. That is not δip; in matrix language it is (JᵀJ)ip, which equals δ only when J is orthogonal. So the result does not transform like a tensor.  (18)

The rule In an inner product, one contravariant index must be paired with one covariant index. No index may occur more than twice: AikkBkq is meaningless (k appears 3 times; Exercise 3 has 4).

4. Contraction (Eqs. 19–21)

Definition In a single tensor, set one upper index equal to one lower index and sum. Example with Aijklm (rank 5, N⁵ components):
Aijkim = A1jk1m + A2jk2m + … + ANjkNm   (19)
The result is a tensor of contravariant rank 2 and covariant rank 1 (N³ components). Each contraction lowers the total rank by 2.

Proof: in (20) put ρ = α and sum: (∂x̄α/∂xi)(∂xl/∂x̄α) = δli, so one pair of factors disappears and the rest is the rank-3 law.  (21)

  • A tensor can be contracted in several ways: Aijkim, Aijkjm, Aijklk, ….
  • Repeated contraction: Aijklm → Aijkim (rank 3) → Aijkij (rank 1, a contravariant vector).
  • Inner product = outer product, then contraction: AijkBkq = contraction of Dijpkq = AijkBpq over p and k.
  • Fully contracted tensors are scalars. Aii is the trace of a mixed tensor, invariant in every frame. That is why the trace of a matrix is invariant under similarity transformations (Section 15, Ā = JAJ⁻¹).
Equating two similar indices is not a contraction Diipkq (two upper indices equal and summed) and Dijpkk (two lower) are not tensors (Exercise 4). For a matrix this is the difference between Tr(A) = Aii (invariant) and Σᵢ Aii for a covariant Aij, which changes under non-orthogonal transformations.

6. Symmetric and antisymmetric tensors (Eqs. 22–32)

Definitions Symmetric: Aij = Aji, or Aij = Aji, for all i, j.  (22, 23)
Antisymmetric (skew): Aij = −Aji, or Aij = −Aji.  (24)   Then the diagonal is zero: Aii = −Aii ⇒ Aii = 0 (no sum).

Example 3: symmetry is an intrinsic property

  1. Āαβ = (∂x̄α/∂xi)(∂x̄β/∂xj)Aij.  (25)
  2. Swap α ↔ β: Āβα = (∂x̄β/∂xi)(∂x̄α/∂xj)Aij.  (26)
  3. Rename the dummies i ↔ j and use Aji = Aij: Āβα = (∂x̄β/∂xj)(∂x̄α/∂xi)Aij, the same as (25).  (27)
  4. So Āαβ = Āβα in every system. ∎  (28)   The same works for antisymmetry. In matrix form: (JAJᵀ)ᵀ = JAᵀJᵀ = JAJᵀ.

Higher rank: symmetry is about a pair of similar indices

Aijklmp is symmetric in the first two upper indices if Aijklmp = Ajiklmp (29), and in the first and third lower indices if Aijklmp = Aijkpml (30). Say "symmetric in the first two upper positions": the letters themselves can be renamed.

Example 4: symmetry between an upper and a lower index means nothing

Suppose Aij = Aji (as numbers) in the x-system. Then

Āαβ = (∂x̄α/∂xi)(∂xj/∂x̄β)Aij,    Āβα = (∂x̄β/∂xj)(∂xi/∂x̄α)Aij  (31, 32)

The Jacobian factors are different kinds, so in general Āαβ ≠ Āβα. In matrix language: JAJ⁻¹ need not be symmetric when A is (unless J is orthogonal).

Rule Symmetry or antisymmetry between two similar indices (both upper or both lower) is intrinsic, true in every frame. Between dissimilar indices it is only an accidental property of one coordinate system.

Every rank-2 tensor splits into symmetric + antisymmetric (Exercise 6)

Aij = ½(Aij + Aji) + ½(Aij − Aji) = Sij + Kij

Both parts are tensors (sums of tensors of the same type), and the split is unique. Number of independent components in N dimensions: symmetric N(N+1)/2, antisymmetric N(N−1)/2. In 3D: 6 + 3 = 9. In 4D: 10 + 6 = 16. The electromagnetic field tensor Fμν is antisymmetric with 6 components, which are E and B.

Exercise 7: Aij antisymmetric ⇒ AijBiBj = 0. A symmetric times an antisymmetric pair always gives zero when fully contracted.

7. 🔬 Symmetry lab: what survives a change of coordinates?

Start with a symmetric 3×3 array. Treat it once as a contravariant tensor Aij (transforms as JAJᵀ) and once as a mixed tensor Aij (transforms as JAJ⁻¹). Slide "shear" to make J non-orthogonal. The heat maps show the asymmetry Ā − Āᵀ. It stays exactly zero for Aij, but becomes nonzero for Aij as soon as J stops being a rotation.

8. The Kronecker delta is a tensor, and an isotropic one (Eqs. 33–34)

Treat δij as a mixed tensor and transform it:

δ̄αβ = (∂x̄α/∂xi)(∂xj/∂x̄β)δij = (∂x̄α/∂xi)(∂xi/∂x̄β) = ∂x̄α/∂x̄β = δαβ   (33)

So δij has the same components (1 and 0) in every coordinate system. A tensor with this property is called isotropic. In matrix language, JIJ⁻¹ = I.

Only the mixed form δij is isotropic under all transformations. The "δij" with both indices down would transform as JᵀJ (or KᵀIK), which is I only for orthogonal J. In general coordinates its role is taken by the metric tensor gij (Section 18).

9. The fully antisymmetric (Levi-Civita) tensor ε (Eqs. 35–39)

Definition In N dimensions, εi₁i₂…iN has N indices (NN components):
  • +1 if (i₁ … iN) is an even permutation of (1 2 … N),
  • −1 if it is an odd permutation,
  • 0 if any two indices are equal.
Only N! components are nonzero.

In 3D (x, y, z): εxyz = εyzx = εzxy = 1 (cyclic), εxzy = εzyx = εyxz = −1 (anticyclic); the other 21 components are 0.  (35)

Example 5(a): the cross product

(u × v)i = εijkujvk   (37)

Check i = x: the only nonzero terms are j, k = (y, z) with εxyz = 1 and (z, y) with εxzy = −1, giving uyvz − uzvy ✓.  (36)

Example 5(b): angular momentum in quantum mechanics

[Lx, Ly] = iħLz, [Ly, Lz] = iħLx, [Lz, Lx] = iħLy   ⇔   [Li, Lj] = iħ εijk Lk   (38, 39)

(Compare the Pauli matrices: [σi, σj] = 2iεijkσk, Section 14.)

Is ε really a tensor? Under a general change of coordinates, εijk with the fixed values ±1, 0 picks up a factor det(J). It is a tensor density (or "pseudotensor"), not a true tensor. It behaves as a true tensor under transformations with det J = 1, e.g. proper rotations. Under a reflection (det = −1) it flips sign, which is why u × v is an axial vector. The book's footnote says the index positions in (37) are justified only in Cartesian coordinates. 11. Rules for checking index equations

  1. A free index must match in every term of the equation, at the same height (upper in every term or lower in every term).
  2. A dummy index is checked term by term. It may occur in some terms only, but where it occurs it must appear exactly twice: once upper, once lower.
  3. No index more than twice in any term.
  4. In ∂xi/∂x̄α, i counts as an upper (contravariant) index and α, sitting in the denominator, counts as a lower (covariant) index.
Worked check Āαβ = (∂x̄α/∂xi)(∂xj/∂x̄β)Aij. Free indices: α (up on both sides ✓), β (down on both sides; it sits in a denominator on the right ✓). Dummies: i (down in a denominator, up in A ✓), j (up in a numerator, down in A ✓). The equation is well formed.

Note: in Eqs. (37) and (39) the book writes every index down. That is allowed only because Cartesian coordinates do not distinguish upper from lower (Section 19).

13. Book's Exercise 16: all problems solved

1. If Aij is a mixed tensor of rank two, show that Aii is also a tensor.
Show solution

Āαα = (∂x̄α/∂xi)(∂xj/∂x̄α)Aij = δjiAij = Aii, using (15.23). The trace is the same number in every system: a scalar, i.e. a tensor of rank 0. ∎

2. In N dimensions, how many different expressions are represented by AipjBkirCrtsk? How many terms does each contain?
Show solution

Count the indices: i (up in A, down in B), k (up in B, down in C), r (down in B, up in C) each appear twice, so they are dummies (3 of them). p, j, t, s appear once: free (4 of them).

Number of expressions = N⁴ (one for each choice of p, j, t, s). Each is a sum over i, k, r: N³ terms. The result is a tensor Dptjs of rank 4. (Book's answer: N⁴ expressions, N³ terms each.)

3. If Aijk and Bpql are tensors, show that AijkBpjl (summed over the two upper j's) is not a tensor.
Show solution

In the transformation of the outer product, the factors carrying the two j positions are (∂x̄β/∂xj) and (∂x̄ρ/∂xq). Setting ρ = β and summing gives Σβ(∂x̄β/∂xj)(∂x̄β/∂xq) = (JᵀJ)jq, not δjq. So the factors do not collapse and the N⁴ functions (free i, k, p, l) do not obey the tensor law. ∎ (Same mechanism as Example 2. Test "A^ij_k B^pj_l" in Lab 5.)

4. If Aijkl is a tensor, show that Aiikl and Aijkk are not tensors.
Show solution

Aiikl: contracting two upper indices leaves the factor Σα(∂x̄α/∂xi)(∂x̄α/∂xj) = (JᵀJ)ij in the transformation, which is not δ. Likewise Aijkk leaves (KKᵀ) for two lower indices. Neither transforms as a rank-2 tensor under a general change of coordinates. (Both pass under rotations, where JᵀJ = I.) ∎

5. If Aijklm is a tensor, show that Aijkjk, Aijkkj, Aijmlm… (each with two contractions) are contravariant vectors.
Show solution

Each expression contracts twice, each time pairing one upper with one lower index. Each contraction removes one upper and one lower index (rank − 2), so 5 → 3 → 1, leaving one free upper index. By the contraction theorem (21), applied twice, each is a contravariant vector. Example: Aijkjk: pairs (j up, j down) and (k up, k down) ⇒ free i up ⇒ contravariant vector. ∎

6. Show that any covariant or contravariant tensor of rank two can be written as the sum of a symmetric and an antisymmetric tensor of the same type.
Show solution

Aij = Sij + Kij with Sij = ½(Aij + Aji) and Kij = ½(Aij − Aji). Sji = Sij and Kji = −Kij by inspection. Aji is a tensor of the same type (just a renaming of positions), so S and K, being sums of same-type tensors, are tensors.

Uniqueness: if A = S + K = S′ + K′, then S − S′ = K′ − K is both symmetric and antisymmetric, hence zero. ∎ Same for Aij. (Not for a mixed Aij, where symmetry has no invariant meaning.)

7. If Aij is antisymmetric and Bi is a vector, show AijBiBj = 0.
Show solution

Let X = AijBiBj. Rename the dummies i ↔ j: X = AjiBjBi = −AijBiBj = −X (numbers commute). So X = 0. ∎ Example: the quadratic form of an antisymmetric matrix is zero (Section 11).

8. Show that (a × b)·c = εijkaibjck (Cartesian components).
Show solution

(a × b)k = εkijaibj by (37), with the indices renamed. Dot with c: (a × b)·c = εkijaibjck. A cyclic shift does not change ε: εkij = εijk. Hence = εijkaibjck, which written out is the 3×3 determinant with rows a, b, c. ∎

9. If ai is any vector, show that εijkajak = 0.
Show solution

Let Xi = εijkajak. Rename j ↔ k: Xi = εikjakaj = −εijkajak = −Xi. So Xi = 0, i.e. a × a = 0. Same mechanism as Exercise 7: antisymmetric ε contracted with the symmetric ajak. ∎

Show solution

∂j∂kφ is symmetric in j, k (mixed partials commute), and ε is antisymmetric in j, k, so the contraction vanishes. Similarly div curl A = εijk∂i∂jAk = 0.

P8. Aij has eigenvalues 1, 2, 3 in some frame. What is AijAji? invariants
Show solution

It is Tr(A²) = 1 + 4 + 9 = 14, the same in every frame (a double contraction is a scalar).

P9. Write det A for a 3×3 matrix with ε, and show det A = det Aᵀ. det
Show solution

det A = εijkA1iA2jA3k, or symmetrically det A = (1/6)εijkεlmnAilAjmAkn. The second form is unchanged when A ↔ Aᵀ (swap the roles of the two ε's).

P10. How many independent components does a tensor Aijk have in 3D if it is fully antisymmetric? Fully symmetric? count
Show solution

Fully antisymmetric: C(3,3) = 1 (it must be a multiple of εijk). Fully symmetric: C(3+2, 3) = 10.

16. Interesting facts

Levi-Civita Tullio Levi-Civita (1873–1941) developed tensor calculus with his teacher Ricci. Einstein, struggling with general relativity, wrote that he admired "the elegance of your method of computation". He also said, half joking, that tensor calculus was one of only two things he had learned from Italians, the other being spaghetti.
Penrose graphical notation Roger Penrose drew tensors as boxes with legs (one leg per index) and contraction as joining legs. The same diagrams are now used for "tensor networks", which simulate quantum many-body systems and neural networks. Modern libraries even have a function called einsum that evaluates Einstein-summation strings like the one in Lab 5.
Why trace and determinant are invariant Tr A = Aii is a contraction, and det A can be written as ε…ε…A A A (Practice 9) with the ε's carrying compensating density factors. Every invariant of a matrix can be built from contractions. That is how physicists find quantities like E² − B² and E·B, the two invariants of the electromagnetic field.
Mirror test for axial vectors In a mirror, a velocity flips its perpendicular component, but angular momentum L = r × p (built with ε) behaves the opposite way. The weak interaction "notices" the difference: parity violation (Wu experiment, 1957).
