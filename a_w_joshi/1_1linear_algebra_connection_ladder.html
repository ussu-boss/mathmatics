    5. Connect: see what the next rung adds.

    Important distinction

    A set is a collection of objects. An operation tells you how to combine objects. A structure is a set equipped with operations that obey particular rules.

    Set + operations + rules = structure

    Mini glossary

    Scalar

    A number from the chosen field, such as 2 or −½ in \(\mathbb R\).

    Vector

    An object that can be added to other vectors and scaled, such as (2, 3).

    Dimension

    The number of vectors in any basis of a finite-dimensional vector space.
