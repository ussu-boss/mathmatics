0. Roadmap and notation

1. What is a matrix?

Definition A matrix is a rectangular array of numbers (real or complex), or of functions. The individual entries are its elements. A matrix with m rows and n columns has order m × n ("m by n"):
A = [aᵢⱼ]m×n, 1 ≤ i ≤ m (row index), 1 ≤ j ≤ n (column index)
aᵢⱼ is the element in the i-th row and the j-th column. The first index is always the row.

Memory aid: "RC", Rows come before Columns The order m × n means m rows first. The element aᵢⱼ means row i first. An m×n matrix has mn elements, so the set of all m×n matrices is a vector space of dimension mn (Section 1).

2. The zero matrix and equality of matrices

Zero matrix A = 0 ⇔ (A)ᵢⱼ = 0 for every i, j. For any A, A + (−A) = A − A = 0. (The book uses the same bold 0 as for the null vector. A column of zeros is both.)
Equality A = B ⇔ (1) A and B have the same order m×n, and (2) aᵢⱼ = bᵢⱼ for all i, j. This is a set of mn equations.

Having the same order is necessary but not sufficient. A 2×3 matrix is never equal to a 3×2 matrix, even when the two contain the same numbers.

4. Matrix multiplication

Definition If A is m × n and B is n × p (columns of A = rows of B), then AB is the m × p matrix with
(AB)ᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + … + aᵢₙbₙⱼ = Σₖ₌₁ⁿ aᵢₖ bₖⱼ (Eq. 16)
In words: the ij-th element of AB is row i of A "dotted" with column j of B.
⚡ The size rule (domino rule)
(m × n) · (n × p) = (m × p)
The inner numbers must match, and they disappear. The outer numbers give the size of the answer. Check this first in every MCQ. If AB is defined, BA may not be. Both are defined only when A is m×n and B is n×m. Then AB is m×m and BA is n×n, and they can have the same order only if m = n.

Strassen (1969) found an n2.81 method, and the best known exponents today are about 2.37.

6. Row vectors, column vectors, inner and outer products

A row vector of dimension n is a 1×n matrix, aᵢ′ = [aᵢ₁ aᵢ₂ … aᵢₙ]. A column vector of dimension n is an n×1 matrix, written compactly as bⱼ = {b₁ⱼ, b₂ⱼ, …, bₙⱼ}. The book uses small bold letters for both.

aᵢ′ bⱼ = aᵢ₁b₁ⱼ + … + aᵢₙbₙⱼ (1×n)(n×1) = 1×1, a scalar

When do matrices commute? (all cases)

  • Always: A with I, with 0, with cI (scalar matrices), with itself, with its powers Aᵏ, with any polynomial p(A), and with A⁻¹.
  • Two diagonal matrices always commute. Two 2D rotations commute. 3D rotations about different axes do not.
  • Polynomials in the same matrix commute: p(A)q(A) = q(A)p(A).
  • Diagonalizable A and B commute ⇔ they have a common set of eigenvectors (Section 9).
  • Commuting is not transitive (Exercise 6): I commutes with everything, but that does not make every pair commute.
  • Only scalar matrices cI commute with every n×n matrix.

8. The laws of matrix algebra, and where ordinary arithmetic fails

What still holds
  • Associative: (AB)C = A(BC) (Eq. 25). Proof: both sides have ij-th element Σₖ Σₗ aᵢₗ bₗₖ cₖⱼ, the same double sum in a different order (Eqs. 28–30).
  • Distributive: A(B + C) = AB + AC and (A + B)C = AC + BC (Example 4). Proof: Σₖ aᵢₖ(bₖⱼ + cₖⱼ) = Σₖ aᵢₖbₖⱼ + Σₖ aᵢₖcₖⱼ.
  • Scalars move freely: A(cB) = c(AB) = (cA)B.
  • Identity: IₘA = A = AIₙ for A m×n.

9. Powers of a square matrix

For a square matrix, A² = AA, A³ = AAA, and so on. A⁰ = I. Because multiplication is associative, the brackets don't matter, and AᵐAⁿ = Aᵐ⁺ⁿ = AⁿAᵐ, so powers of the same matrix always commute. (Powers of a non-square matrix are not defined.)

10. Derived matrices: A*, Aᵀ (Ã) and A†

Definitions
  • Complex conjugate A*: conjugate every element, (A*)ᵢⱼ = aᵢⱼ*. Same order m×n.
  • Transpose Ã = Aᵀ: rows become columns, (Aᵀ)ᵢⱼ = aⱼᵢ. The order becomes n×m. The transpose of a column vector is a row vector.
  • Hermitian conjugate A† = (A*)ᵀ = (Aᵀ)*: conjugate and transpose, in either order. (A†)ᵢⱼ = aⱼᵢ*. Order n×m.

11. Linear transformations in matrix language

Write the components as column vectors x = {x₁, …, xₚ}, y = {y₁, …, yₙ}, z = {z₁, …, zₘ}. Then:

yᵢ = Σₖ bᵢₖxₖ ⇔ y = Bx (B is n×p) zᵢ = Σₖ aᵢₖyₖ ⇔ z = Ay (A is m×n)
z = A(Bx) = (AB)x = Cx, C = AB (m×p)

The two sets of variables do not need to have the same number of elements, so the matrices can be rectangular. Then x (p variables) → y (n variables) → z (m variables), and the sizes chain exactly like dominoes: (m×n)(n×p) = (m×p). This is the reason matrix multiplication is defined the way it is. It is the only definition that makes "do B, then do A" equal to "do AB".

Example: y₁ = x₁ + 2x₂ − x₃, y₂ = 3x₂ + x₃ and z₁ = y₁ − y₂, z₂ = 2y₁, z₃ = y₂. Find z in terms of x.

12. The inner product in matrix notation

For column vectors u, v, the row u† = [u₁*, …, uₙ*] times the column v gives

(u, v) = u†v = Σ uᵢ*vᵢ orthogonal ⇔ u†v = 0 real case: ũv = Σuᵢvᵢ
Results worth knowing
  • ‖u‖² = u†u = Σ|uᵢ|² ≥ 0.
  • Moving a matrix across the inner product: (u, Av) = u†Av = (A†u)†v = (A†u, v). This defining property of A† is the bra–ket rule ⟨u|A|v⟩* = ⟨v|A†|u⟩.
  • (A†A)ᵢⱼ = (column i, column j). So A†A is the Gram matrix of the columns, and it is diagonal ⇔ the columns are mutually orthogonal. Likewise AA† is the Gram matrix of the rows (Exercise 17).
  • Tr(A†A) = Σᵢⱼ |aᵢⱼ|² ≥ 0, with equality ⇔ A = 0. So A†A = 0 ⇒ A = 0 (useful in proofs).
  • uv† is an n×n matrix (an outer product, written |u⟩⟨v| in Dirac notation), while u†v is a number (⟨u|v⟩).

19. Interesting facts

  • The word "matrix" (Latin for "womb") was coined by Sylvester in 1850, because a matrix "gives birth" to determinants (its minors). Cayley wrote the first paper on matrix algebra in 1858, motivated by composing linear transformations.
  • Hamilton's quaternions (1843) were the first famous non-commutative algebra: ij = k but ji = −k. The Pauli matrices reproduce them, since −iσₓ, −iσᵧ, −iσ_z multiply like i, j, k.
  • Heisenberg (1925) invented quantum mechanics with arrays whose multiplication did not commute, without knowing they were matrices. Born recognised them as matrices, and [x, p] = iħ became the heart of QM.
  • Every modern AI model and every GPU spends most of its time doing matrix multiplication. Finding the smallest exponent ω for multiplying matrices is a famous open problem (ω ≈ 2.37 today; ω = 2 would be optimal).
  • Matrix multiplication is associative because composition of functions is associative. A matrix is just a linear function written down in coordinates.
  • The trace is basis-independent, which is why physicists use it for the partition function Z = Tr e−βH and for density matrices (Tr ρ = 1).
One-paragraph summary Matrices of the same order add element by element and form a vector space of dimension mn. Multiplication is "row × column", defined so that doing B and then A is the same as doing AB, and it requires the inner sizes to match. It is associative and distributive, but not commutative. Zero divisors, nilpotents and many square roots of I exist. The commutator [A,B] measures the failure to commute, and its trace is always 0. Conjugation does not reverse a product, while transposition and the dagger do: (AB)† = B†A†. Inner products are u†v, and A†A collects all the inner products of A's columns.
