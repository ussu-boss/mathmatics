0. Roadmap

To prove that N³ numbers A(i, j, k) form a tensor, Section 15 says: check the transformation law. In practice this is often hard, because you may not even know the components in another frame. The quotient law is a shortcut:

Quotient law (one sentence) If the inner product of a set of quantities with an arbitrary tensor is always a tensor, then the quantities themselves form a tensor.

It is called a "quotient" law because it runs multiplication backwards. We know "tensor × tensor = tensor" (Section 16). Here we know "A × arbitrary tensor = tensor" and conclude that A = "tensor ÷ tensor" is a tensor.

A(i,j,k) Bjk = Ci for every B→[Ā·JJ − J·A]B = 0 for every B→bracket = 0→A = Aijk, a tensor
Needed from earlier Transformation laws (Section 15), the identity (∂xj/∂x̄β)(∂x̄β/∂xl) = δjl, inner products and the rule "pair an upper index with a lower one" (Section 16), cofactors and the inverse matrix (Section 4).

1. How the rule decides the index positions

Each slot of the unknown A gets the opposite height to the index it is contracted with, and a free slot gets the height of the free index on the other side of the equation.

Known fact (for every arbitrary B)Conclusion
A(i, j, k) Bjk = CiAijk is a tensor (contravariant 1, covariant 2)
A(i, j) Bj = CiAij is a covariant tensor
A(i, j) Bi = CjAij is a contravariant tensor
A(i, j) BiCj = scalar, for arbitrary vectors B, CAij is a covariant tensor
A(i, j) Bk = Cijk (outer product, Exercise 3)Aij is a covariant tensor

2. Proof for the case A(i, j, k)Bjk = Ci (Eqs. 1–7)

  1. In the unbarred frame: A(i, j, k)Bjk = Ci (1). In the barred frame, with whatever values Ā(α, β, γ) the quantity has there: Ā(α, β, γ)B̄βγ = C̄α.  (2)
  2. B and C are tensors, so substitute their laws: B̄βγ = (∂x̄β/∂xj)(∂x̄γ/∂xk)Bjk and C̄α = (∂x̄α/∂xi)Ci = (∂x̄α/∂xi)A(i, j, k)Bjk.  (3)
  3. Bring everything to one side:
    [ Ā(α, β, γ)(∂x̄β/∂xj)(∂x̄γ/∂xk) − (∂x̄α/∂xi)A(i, j, k) ] Bjk = 0   (4)
  4. B is arbitrary, i.e. its N² components can be chosen independently. Choose B with only B11 = 1: the (j, k) = (1, 1) bracket vanishes. Do this for every (j, k): every bracket vanishes separately.  (5)
  5. Multiply by (∂xj/∂x̄ρ)(∂xk/∂x̄σ) and sum over j, k. The δ's from (15.23) reduce the left side to Ā(α, ρ, σ):
    Ā(α, ρ, σ) = (∂x̄α/∂xi)(∂xj/∂x̄ρ)(∂xk/∂x̄σ) A(i, j, k)   (6)
  6. This is exactly the transformation law of a mixed tensor Aijk. ∎  (7)
Matrix version (rank 2) If y = A x is a vector for every vector x, then in a new frame ȳ = Jy and x̄ = Jx, so Ā x̄ = J A x = J A J⁻¹ x̄ for every x̄. Hence Ā = JAJ⁻¹: A transforms as a mixed tensor (a linear operator). "Something that turns every vector into a vector is a tensor."

3. 🔬 Black-box lab: can you catch a fake tensor?

A machine gives you 3×3 numbers A(i, j) in every coordinate system. You don't know how it computes them. Your only tool is the quotient law: feed in a probe tensor Bjk, compute the number s = A(j, k)Bjk in the unbarred frame and s̄ = Ā(β, γ)B̄βγ in the barred frame, and check whether s̄ = s (a scalar must not change). Choose what the machine secretly does, then probe it.

Try the trap machine with symmetric probes: it passes every test. Switch to arbitrary probes and it is caught at once. That is Example 1.

4. Why the probe must be arbitrary (Example 1)

Suppose we only know that A(i, j, k)Bjk = Ci is a tensor for every symmetric tensor Bjk. We still reach Eq. (4), now written as

D(α, j, k) Bjk = 0   (8)

where D is the bracket in (4). But we can no longer conclude D = 0, because a symmetric B cannot be chosen freely: Bjk = Bkj. Each pair of terms D(α, j, k)Bjk + D(α, k, j)Bkj = [D(α, j, k) + D(α, k, j)]Bjk involves the same B component, so only the sum is forced to vanish:

D(α, j, k) + D(α, k, j) = 0

Working this out as before (9, 10) gives the conclusion:

Example 1 result Aijk ≡ A(i, j, k) + A(i, k, j), the part of A symmetric in j, k, is a tensor. Nothing can be said about the antisymmetric part ½[A(i, j, k) − A(i, k, j)]: it never shows up in A B when B is symmetric.

Plain picture: a symmetric probe is "blind" to the antisymmetric part, just as a quadratic form xᵀAx only sees the symmetric part of A (Section 11). If the probe cannot see a part, it cannot test it.

Physics example (Exercise 1): ds² = gijdxidxj is invariant, and dxidxj is symmetric. So we can only conclude that gij + gji is a tensor. That is why the metric is always chosen symmetric: any antisymmetric part would be invisible in ds² anyway.

5. Conjugate symmetric tensors (Eqs. 11–14)

Let Aij be a symmetric covariant tensor with det(Aij) ≠ 0. Define

Bij = (cofactor of Aij) / det(Aij)   (11)

From the cofactor expansion of a determinant (Section 4, Eq. 5.6):

AijBik = δkj   (12)

As matrices, B = A⁻¹ (A is symmetric, so cofactors need no transposing).

Proof that Bij is a contravariant tensor

We cannot use (12) directly with the quotient law, because Aij is symmetric, not arbitrary. The trick is to introduce an arbitrary vector:

  1. Let Cj be an arbitrary contravariant vector and Di = AijCj.  (13)   This is an inner product of tensors, so Di is a covariant vector.
  2. Since det A ≠ 0, the map C → D is one-to-one: every D comes from exactly one C. So as C runs over all vectors, Di is an arbitrary covariant vector.
  3. DiBik = AijBikCj = δkjCj = Ck.  (14)
  4. So "B times an arbitrary vector D gives a vector C". By the quotient law, Bik is a (contravariant) tensor. ∎
  5. Symmetry: cofactor of Aij = cofactor of Aji for a symmetric matrix ⇒ Bij = Bji.
Conjugate (reciprocal) tensors Aij and Bij related by (12) are called conjugate. As matrices they are inverses. A symmetric rank-2 tensor has a conjugate if and only if its determinant is nonzero. The relation is mutual: the conjugate of Bij is Aij again (Exercise 2).
Why this matters next In Section 18 the metric tensor gij (from ds² = gijdxidxj) and its conjugate gij are used to raise and lower indices: Ai = gijAj, Ai = gijAj. This section is what guarantees that gij is a tensor.

6. 🔬 Conjugate-tensor lab: a tensor and its inverse, seen as two ellipses

In 2D a symmetric positive-definite Aij defines the ellipse Aijxixj = 1 (blue, drawn in the space of vectors xi). Its conjugate Bij defines Bijyiyj = 1 (orange, in the space of covectors yi). The two ellipses have the same axes with reciprocal lengths: a long axis of one is a short axis of the other.

Now change coordinates with J (rotation + shear). A transforms as KᵀAK, B as JBJᵀ. Both pictures deform, yet the product AijBjk stays exactly δki: the conjugate of the transformed tensor is the transformed conjugate.

7. 🔬 Index fixer (the method of Exercise 4)

Write unknown quantities with slots in brackets, e.g. A(i,j,k), and known tensors with ^ and _ as before, e.g. B^j_k. Separate terms with + or −, and the two sides with =. The fixer applies the quotient-law rules:

  • a slot whose index is contracted with a known tensor gets the opposite height;
  • a slot whose index is free gets the height that index has in the other terms;
  • every term must have the same set of free indices. If not, the equation must first be rewritten with renamed indices.

9. Book's Exercise 17: all problems solved

1. The distance between xi and xi + dxi is ds² = gijdxidxj. Given that ds² is invariant and dxi is a contravariant vector, show that gij + gji is a symmetric covariant tensor of rank two.
Show solution

In the barred frame ḡαβdx̄αdx̄β = gijdxidxj. Substitute dx̄α = (∂x̄α/∂xi)dxi:

[ ḡαβ(∂x̄α/∂xi)(∂x̄β/∂xj) − gij ] dxidxj = 0   for all dx

Call the bracket Dij. The product dxidxj is symmetric, so (as in Example 1) only Dij + Dji = 0 follows. (Proof: put dx = ei to get Dii = 0, then dx = ei + ej to get Dij + Dji = 0.) That says

ḡαβ + ḡβα = (∂xi/∂x̄α)(∂xj/∂x̄β)(gij + gji)

(after multiplying by the inverse Jacobians). So hij = gij + gji transforms as a covariant tensor, and it is obviously symmetric. ∎ Since ds² only sees this part, one simply takes gij symmetric from the start.

2. Aij is a symmetric covariant tensor, Bij = (cofactor of Aij)/det(Aij). Define Eij = (cofactor of Bij)/det(Bij). Show that Eij = Aij.
Show solution

Index proof (book's answer): by the same cofactor rule applied to B, BijEik = δjk. Multiply (12), AijBik = δkj, by Eks:

AijBikEks = δkjEks  ⇒  Aijδis = Ejs  ⇒  Asj = Ejs = Esj

using BikEks = δis (B and E are symmetric). ∎

Matrix proof: B = A⁻¹ and E = B⁻¹ = (A⁻¹)⁻¹ = A. The conjugate of the conjugate is the original.

Numerical check: A = [[2, 1], [1, 3]], det = 5, B = (1/5)[[3, −1], [−1, 2]], det B = (6 − 1)/25 = 1/5, cofactors of B: [[2/5, 1/5], [1/5, 3/5]], so E = (cofactors)/(1/5) = [[2, 1], [1, 3]] = A ✓.

3. If Bk is an arbitrary tensor and AijBk is a tensor, show that Aij is a tensor.
Show solution

Let Cijk = A(i, j)Bk (a tensor). In the barred frame Ā(α, β)B̄γ = C̄αβγ = (∂xi/∂x̄α)(∂xj/∂x̄β)(∂x̄γ/∂xk)A(i, j)Bk. Using B̄γ = (∂x̄γ/∂xk)Bk:

[ Ā(α, β) − (∂xi/∂x̄α)(∂xj/∂x̄β)A(i, j) ] B̄γ = 0

B is arbitrary, so choose some B̄γ ≠ 0: the bracket vanishes. That is the law of a covariant tensor Aij. ∎ (This is the quotient law for an outer product. Here a single nonzero B is enough, since no summation mixes the components.)

4. Assuming all capital letters are tensors, rewrite in proper tensorial form: (a) A(i, j, k)Bjk + C(r, t)Dr = E(r, s, t)Frist; (b) A(i, j, k)Blij − C(r, s, k, t)DrsElt = F(l, i, j)Gjkl; (c) A(i, l, k, p)Bpij + C(j, k, l, m)Dimj + E(i, j)Fk = 0.
Show solution (a)

RHS: in Frist, r is up so E's r slot is down; s, t are down so E's s, t slots are up. The free index is i (up). So the RHS is EstrFrist.

Term 1: Bjk has j up and k down, so A's j is down and k is up. The free i must be up: AikjBjk.

Term 2: Dr is down, so C's r is up. Its free index is t, but every term must carry the free index i, so rename t → i: CriDr.

AikjBjk + CriDr = EstrFrist

This is the book's answer.

Show solution (b)

Free indices as printed: term 1 → {k, l}, term 2 → {k, l}, but in term 3 the letter l appears twice (F's first slot and G's last), so it is a dummy there, and the free set is {i, k}. The sets do not match, so rename in term 3: dummy l → m, then free i → l: F(m, l, j)Gjkm.

  • Term 3: Gjkm ⇒ F's j down, m up; free k is down (from G), free l → F's slot.
  • Term 2: Drs ⇒ C's r, s up; Elt ⇒ C's t down; free l is up (from E), free k must be down.
  • Term 1: Blij ⇒ A's i, j up; l up ✓; A's k slot free ⇒ down.
AijkBlij − CrsktDrsElt = FmljGjkm

Free: l (up), k (down) in every term ✓.

Show solution (c)

Free sets as printed: term 1 → {j, k, l} (j down from B), term 2 → j is a dummy (C's j and Dj), free {i, k, l} with i up (from D), term 3 → {i, j, k}. They don't match. One consistent renaming:

  • Term 2: dummy j → n, D's free i → l, C's free l → j: C(n, k, j, m)Dlmn ⇒ Cnkjm (n up pairs with Dn; m down pairs with Dm).
  • Term 3: E(i, j) → E(l, j); Fk has k down ⇒ k is down everywhere: EljFk.
  • Term 1: Bpij ⇒ A's p down, i up; free l up, k down: Ailkp.
AilkpBpij + CnkjmDlmn + EljFk = 0

Free: l up; j, k down in every term ✓. (Other letter choices are equally correct; the heights are what matter.)

10. Practice set (CSIR-NET / GATE style)

P1. A(i, j)xiyj is a scalar for arbitrary vectors xi, yj. What type is A? quotient
Show solution

Aij: covariant in i (pairs with xi), contravariant in j (pairs with yj). A mixed tensor.

P2. A(i, j)xixj is a scalar for every x. What can you conclude? trap
Show solution

Only that A(i, j) + A(j, i) is a covariant tensor (symmetric probe, as in Example 1 and Exercise 17.1). The antisymmetric part is undetermined.

P3. In some frame gij = diag(1, r²). Find its conjugate gij. conjugate
Show solution

gij = diag(1, 1/r²). Check gijgjk = δik.

P4. Aij = [[1, 2], [2, 4]]. Does it have a conjugate tensor? det
Show solution

det = 4 − 4 = 0 ⇒ no. The map Cj → AijCj is not one-to-one, so the proof breaks down.

P5. If A(i, j, k) Bk = Cij for an arbitrary Bk, write A in tensor form. heights
Show solution

Aijk: i, j free and up (as in Cij), k up (paired with the lower Bk). Fully contravariant, rank 3.

P6. Show σij in ji = σijEj is a tensor (Cartesian, E arbitrary). physics
Show solution

j and E are vectors and E can be any vector (we can apply any field). By the quotient law, σij is a rank-2 tensor. This is how material constants (conductivity, susceptibility, elasticity) are shown to be tensors.

P7. The elastic energy density is u = ½cijklεijεkl, with a symmetric strain εij. What does the quotient law guarantee about cijkl? symmetry
Show solution

Only its part symmetric in (i, j), in (k, l) and under the swap (ij) ↔ (kl). So one assumes those symmetries, reducing 81 components to 21 independent elastic constants.

P8. Aij symmetric, Bij its conjugate. Evaluate AijBij in N dimensions. trace
Show solution

AijBij = δjj = N (Tr(A A⁻¹) = Tr I).

12. Interesting facts

How material tensors are discovered Nobody measures the conductivity of a crystal in a second coordinate system to check the transformation law. Instead, the experimenter applies fields in many directions and finds the response is linear. The quotient law then guarantees that the coefficients form a tensor, and crystal symmetry tells you which components vanish (Neumann's principle).
The name In older books the "quotient law" was stated as "if C = A·B with B arbitrary, then A = C/B is a tensor", even though tensors cannot actually be divided. The division sign is only a memory aid.
Raising and lowering indices The conjugate pair gij, gij from this section is what lets physicists move indices up and down freely: pμ = gμνpν in relativity. In Euclidean Cartesian coordinates gij = δij, which is why the difference was invisible in school physics.
