0. Roadmap

A determinant is a single number (or function) attached to a square matrix. It tells you whether the matrix can be inverted (det ≠ 0), how much the matrix scales areas and volumes, and whether it flips orientation. The book needs three things from this section: (1) expansion by cofactors, (2) the "alien cofactor" identity Σₖ aᵢₖAʲᵏ = (det A)δᵢⱼ, which gives the inverse in Section 5, and (3) the derivative of a determinant.

Area/volume meaning→Minor, cofactor, expansion→n! permutation terms→Properties→Σ aᵢₖAʲᵏ = det·δᵢⱼ→d(det)/ds→Tricks & special determinants
Notation det A = det(A) = |A|. The book writes the cofactor of aᵢⱼ as Aⁱʲ (superscripts). Many books write it as Cᵢⱼ. Do not confuse |A| (determinant) with the absolute value |a| of a number.

1. What a determinant means

det = ad − bc

Geometric meaning: the columns (a,c) and (b,d) are the images of the unit vectors e₁ and e₂. det is the signed area of the parallelogram they span, i.e. the factor by which the matrix scales every area. In 3D, det is the signed volume of the parallelepiped spanned by the three columns, and it equals the scalar triple product a·(b × c). The sign says whether orientation is kept (+) or flipped (−, a mirror image).

The single most important fact det A = 0 ⇔ the columns (or rows) are linearly dependent ⇔ space is squashed into a lower dimension ⇔ A has no inverse ⇔ Ax = 0 has a nonzero solution.

Definitions
  • Minor Mᵢⱼ of aᵢⱼ: the determinant of the (n−1)×(n−1) matrix left after deleting row i and column j.
  • Cofactor Aⁱʲ = (−1)^{i+j} Mᵢⱼ. The sign follows a checkerboard:
  • Laplace expansion along row i, or along column i:
    det A = Σₖ aᵢₖ Aⁱᵏ = Σₖ aₖᵢ Aᵏⁱ (Eq. 1)
    Any row or column gives the same value, so the determinant is unique.

3×3 example: expanding along row 1,

det = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁)
⚡ Choose the row or column with the most zeros Each zero kills a whole (n−1)×(n−1) determinant. Sarrus' rule (copy the first two columns to the right, add the three "down" diagonals and subtract the three "up" diagonals) works only for 3×3. Never use it for 4×4.

3. The full formula: n! terms (Eq. 2)

det A = Σpermutations (i₁ i₂ … iₙ) ε · a1i₁ a2i₂ ⋯ aniₙ, ε = +1 (even permutation) or −1 (odd permutation)
  • There are n! terms: 2, 6, 24, 120, …. Each term contains exactly one element from every row and every column, like n rooks on a chessboard that do not attack each other.
  • Sign: count the inversions in (i₁ … iₙ), i.e. the pairs that are out of order. If the count is even, the sign is +; if odd, −. Example: a₁₃a₂₁a₃₂a₄₄ has permutation (3,1,2,4) with inversions (3,1) and (3,2), so 2 inversions and sign +.
  • With the Levi-Civita symbol: det A = εijk a₁ᵢa₂ⱼa₃ₖ (3×3, summed).
  • Every term is a product of n elements. So if every element is a polynomial of degree p, det has degree ≤ np. This is useful for the "degree counting" trick below.

🔬 Lab 4 – Watch all n! terms build the determinant

Each step lights up one "rook placement" (one element in each row and column), shows its permutation, its inversion count, its sign and its product, and adds it to the running total. After all n! terms, the total equals det A.

5. Expansion with "alien" cofactors (Eqs. 3–5)

Take the elements of row i but the cofactors of a different row j:

S = Σₖ aᵢₖ Aʲᵏ

This is the expansion, along row j, of the matrix obtained from A by replacing row j with row i. That matrix has two identical rows, so S = 0. The same holds for columns. Combined with Eq. (1):

Σₖ aᵢₖ Aʲᵏ = Σₖ aₖᵢ Aᵏʲ = (det A) δᵢⱼ (Eq. 5)
Why this matters: the inverse (Section 5) Define the adjugate adj A = (matrix of cofactors)ᵀ, so (adj A)ₖⱼ = Aʲᵏ. Then Eq. (5) says exactly
A · adj A = adj A · A = (det A) I ⇒ A⁻¹ = adj A / det A (if det A ≠ 0)
For 2×2: ⁻¹ = (1/(ad − bc)). Also det(adj A) = (det A)ⁿ⁻¹.

Check with A = , which has det = −29. Row 1 with the cofactors of row 2: the cofactors of row 2 are A²¹ = −(−1·1 − 3·2) = 7, A²² = 2·1 − 3·5 = −13, A²³ = −(2·2 − (−1)·5) = −9. Then 2(7) + (−1)(−13) + 3(−9) = 14 + 13 − 27 = 0 ✓. Try it in Lab 3's alien mode.

6. Derivative of a determinant (Eq. 6)

If the elements aᵢⱼ(s) depend on a parameter s, then each aᵢⱼ appears linearly in det A, with coefficient its cofactor Aⁱʲ. So:

d(det A)/ds = Σᵢ Σⱼ Aⁱʲ · (daᵢⱼ/ds) (Eq. 6)
Two equivalent forms (use whichever is quicker)
  • Row-by-row rule: d(det A)/ds = Σᵢ det(A with row i differentiated), giving n determinants. For 2×2: d/ds|a b; c d| = |a′ b′; c d| + |a b; c′ d′|.
  • Jacobi's formula: d(det A)/ds = det A · Tr(A⁻¹ dA/ds), when A is invertible. In particular d(ln det A)/ds = Tr(A⁻¹ dA/ds).
Application: Abel's formula for the Wronskian For y″ + p(x)y′ + q(x)y = 0 with solutions y₁, y₂: W = |y₁ y₂; y₁′ y₂′|. By the row rule, W′ = |y₁′ y₂′; y₁′ y₂′| + |y₁ y₂; y₁″ y₂″| = 0 + |y₁ y₂; −py₁′ − qy₁, −py₂′ − qy₂| = −pW. So W = W₀ e^{−∫p dx}, which is either never zero or always zero. This explains why "W ≠ 0 at one point" is enough for independence of ODE solutions (Section 1).

Worked example (method 6): show det = (a − b)(b − c)(c − a)(a + b + c) (Book Exercise 1(c)).
Show solution

Factors: a = b makes columns 1 and 2 equal, so det = 0 and (a − b) is a factor. Likewise (b − c) and (c − a) are factors.

Degree: each term is (1)(degree 1)(degree 3), so total degree 4. The three factors have degree 3, so one more linear factor is left. The determinant is symmetric under swapping any two variables (it changes sign, and so does (a−b)(b−c)(c−a)). So the leftover factor is symmetric: k(a + b + c).

Constant: test a = 0. The product (a − b)(b − c)(c − a)·k(a + b + c) becomes (−b)(b − c)(c)·k(b + c) = k(bc³ − b³c). The determinant at a = 0 is det = bc³ − cb³. So k = 1.

2. Show det Iₙ = 1.
Show solution

I is diagonal, so det = 1·1⋯1 = 1. (In the n!-term formula, only the identity permutation picks no zeros.)

3. Show det(cA) = cⁿ det A, and hence det(−A) = ±det A depending on whether n is even or odd.
Show solution

Every term of the permutation formula is a product of n elements, each multiplied by c, so each term gains cⁿ. With c = −1: det(−A) = (−1)ⁿ det A, which is +det A for even n and −det A for odd n.

4. The determinant of a triangular matrix is the product of its diagonal elements.
Show solution

For upper triangular T, expand along the first column. Its only nonzero element is t₁₁, so det T = t₁₁·det(T with row 1 and column 1 deleted), which is again upper triangular. Repeating: det T = t₁₁t₂₂⋯tₙₙ. (Permutation view: any permutation other than the identity uses some element below the diagonal, which is 0.)

5. Show (a) det A* = (det A)*, (b) det Ã = det A, (c) det A† = (det A)*.
Show solution

(a) Conjugate every element. Each term of Eq. (2), a product of elements, becomes the conjugate of that term, so the sum becomes (det A)*.

(b) In Eq. (2), choosing one element from each row by a permutation is the same as choosing one from each column by the inverse permutation, which has the same sign. So the sum for Ã equals the sum for A. (Equivalently, expanding along a row of Ã is expanding along a column of A.)

(c) det A† = det((A*)~) = det A* = (det A)*.

6. The determinant of a Hermitian matrix is real.
Show solution

det H = det H† = (det H)* by 5(c), so det H is real. (It is the product of real eigenvalues, Section 9.)

7. The determinant of an antisymmetric matrix of odd order is 0. That of an antiHermitian matrix of odd order is purely imaginary or 0.
Show solution

Antisymmetric: det A = det Ã = det(−A) = (−1)ⁿ det A = −det A ⇒ det A = 0.

AntiHermitian: det A = det(−A†) = (−1)ⁿ det A† = −(det A)* ⇒ det A + (det A)* = 0 ⇒ Re(det A) = 0. So it is purely imaginary (or 0). Example: det(iI₁) = i.

Total: dD/dx = 2e⁻ˣ, matching d(−2e⁻ˣ)/dx = 2e⁻ˣ ✓.

P19. Why does a Slater determinant vanish if two electrons occupy the same orbital?
Show solution

Two identical rows (or columns) give det = 0. That is the Pauli exclusion principle. Swapping two electrons swaps two rows, so the wavefunction changes sign (fermion antisymmetry).

16. Interesting facts

  • Determinants are older than matrices. Seki Takakazu in Japan (1683) and Leibniz (1693) used them to solve linear equations, and Cramer published his rule in 1750. The word "matrix" came 150 years later.
  • Computing a 25×25 determinant by the n! formula would need about 1.5 × 10²⁵ terms, which is longer than the age of the universe on a fast computer. Row reduction does it in about 5000 operations.
  • det is the only function of the rows that is linear in each row, changes sign under a row swap, and gives 1 for I. These three properties define it completely.
  • The Slater determinant (1929) builds Pauli's principle into the mathematics, so that fermion wavefunctions are automatically antisymmetric.
  • The Jacobian determinant is why the volume element in polar coordinates is r dr dθ, and also why probability densities change when you change variables.
