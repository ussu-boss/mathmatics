0. Roadmap

This section puts the matrix tools of Sections 1–13 to work in physics:

  • Rotations: change of axes is an orthogonal matrix with det +1. A general rotation is built from three simple ones, given by the Euler angles.
  • Pauli matrices: the spin of an electron cannot be described by numbers, because its components anticommute. The smallest matrices that work are 2×2, and we derive them step by step.
  • Dirac matrices: the relativistic electron needs four mutually anticommuting objects. 2×2 is too small, so they are 4×4.
  • Infinite matrices and the matrix of an operator: quantum mechanics is linear algebra in an infinite-dimensional space. In practice we pick a basis, write the operator as a matrix, and diagonalize it.
Needed from earlier Orthogonal and unitary matrices (Section 5), hermitian matrices and their real eigenvalues (Section 9), diagonalization by a unitary matrix (Section 10), eA (Section 12), direct product ⊗ (Section 13).

Euler's three rotations

Any rotation can be written as three successive rotations about coordinate axes:

  1. by α about z,
  2. by β about the new y (or x) axis,
  3. by γ about the new z axis.
R(α, β, γ) = Rz(γ) Ry(β) Rz(α)   (8, 9)

The order matters: the first rotation stands on the right, because it acts on u first. Rotations about different axes do not commute.

3. Pauli spin matrices (Eqs. 11–19)

The spin operator is s = (ħ/2)σ, with σx, σy, σz hermitian and satisfying

σx² = σy² = σz² = 1  (12a),    σxσy + σyσx = σyσz + σzσy = σzσx + σxσz = 0  (12b)

Numbers commute, so anticommuting nonzero objects cannot be numbers. Try 2×2 matrices.

Derivation, step by step

  1. Make σz diagonal. Only one of them can be diagonal: diagonal matrices commute with each other, while these anticommute. σz² = I ⇒ its diagonal entries are ±1. They cannot be equal, since ±I commutes with everything. So σz = diag(1, −1) (the order is a matter of choice).  (13)
  2. Anticommute with σz: for M = [[a, b], [c, d]], σzM + Mσz = [[2a, 0], [0, −2d]] = 0 ⇒ a = d = 0. So M = [[0, b], [c, 0]].  (14)
  3. Square to I: [[0, b], [c, 0]]² = [[bc, 0], [0, bc]] = I ⇒ bc = 1.  (15)
  4. So σx = [[0, p], [q, 0]] and σy = [[0, r], [s, 0]] with pq = 1, rs = 1.  (16, 17)
  5. σx and σy anticommute: σxσy + σyσx = diag(ps + qr, qr + ps) = 0 ⇒ ps + qr = 0.  (18)
  6. Choose p = 1 ⇒ q = 1. Then s + r = 0 and rs = 1 ⇒ −r² = 1 ⇒ r = −i, s = i. Hermiticity is automatic: s = r*.

5. Dirac matrices (Eqs. 20–26)

Dirac's Hamiltonian for a free relativistic particle is

H = c(αxpx + αypy + αzpz) + βmc²   (20)

We need H² = (p²c² + m²c⁴)I, Einstein's energy relation. Squaring (20) gives cross terms like αxαy + αyαx, which must vanish. So:

αx² = αy² = αz² = β² = I  (21a);   all four mutually anticommute  (21b)

Why they must be 4×4

  1. 2×2 is too small. Exercise 1: no nonzero 2×2 matrix anticommutes with all three σ's, so there is no room for a fourth.
  2. Make β diagonal with entries ±1, not all equal: β = [[Im, 0], [0, −In]].  (22)
  3. Partition αi = [[A, B], [C, D]]. Anticommuting with β forces A = D = 0, and αi² = I gives BC = I, CB = I.  (23, 24)
  4. B is m×n and C is n×m. BC = Im and CB = In force m = n (Appendix II: a non-square matrix cannot have a two-sided inverse). We need m + n > 2, so the smallest choice is m = n = 2: 4×4 matrices.
  5. Take B = C = σᵢ (Pauli): then BC = σᵢ² = I, and the α's anticommute because the σ's do.

6. Infinite matrices (Eqs. 27–28)

A matrix is infinite if it has infinitely many rows or columns. (It does not mean the entries are infinite. A matrix with an infinite entry does not exist.) The index can be:

  • discrete: aij, i, j = 1, 2, 3, … (denumerably infinite);
  • continuous: axy, with x, y real numbers in an interval (nondenumerably infinite);
  • mixed: aix, a matrix with discrete rows and continuous columns.

A matrix is square if rows and columns are labelled by the same scheme. A hermitian infinite matrix must be square, since aμν* = aνμ needs μ and ν to run over the same set.

Discrete indicesContinuous indices
Productcij = Σk aikbkj (the series must converge)  (27)ciy = ∫ aixbxy dx (the integral must converge)  (28)
Unit matrix(I)μν = δμν(I)μν = δ(μ − ν): diagonal "entries" are not 1 (they are infinite in the δ-function sense)
Example⟨m|x̂|n⟩ for the harmonic oscillator⟨x|p̂|x′⟩ = −iħ δ′(x − x′)
Strange things happen when n = ∞
  • A finite nonsingular matrix must be square, but an infinite nonsingular matrix can be "rectangular".
  • Tr(AB − BA) = 0 for finite matrices, so [A, B] = iħI is impossible for finite matrices (the trace of the right side is iħn ≠ 0). The canonical commutator [x, p] = iħ forces infinite matrices.
  • The shift matrix S (1's just below the diagonal) satisfies SᵀS = I but SSᵀ ≠ I, so it has a left inverse that is not a right inverse.

7. Matrix representation of an operator (Eqs. 29–34)

The central problem of quantum mechanics is the eigenvalue equation of a hermitian operator P:

Pψμ = λμψμ   (29, 30)

Its eigenfunctions ψμ form an orthonormal basis of the Hilbert space, so any state is φ = ∫μ aμψμ.  (31)   (∫μ means a sum over the discrete part and an integral over the continuous part.)

The practical recipe

  1. We don't know the ψμ yet. So choose any convenient orthonormal basis {φμ}, e.g. the harmonic-oscillator states or plane waves.
  2. Compute the matrix elements Pμν = (φμ, Pφν) = ∫φμ* Pφν dτ.  (32)
  3. Arrange them as a matrix P = [Pμν], the operator matrix (generally infinite).  (33)
  4. Diagonalize it by a unitary transformation. The diagonal entries are the eigenvalues λμ, and the columns of the unitary matrix give the eigenfunctions as combinations of the φ's.
In its own eigenbasis an operator is diagonal (Eq. 34) (ψμ, Pψν) = (ψμ, λνψν) = λν(ψμ, ψν) = λμδμν (discrete) or λμδ(μ − ν) (continuous).
So "the basis that makes an operator diagonal" and "the eigenfunctions of that operator" mean the same thing.

In practice the infinite matrix is truncated to N×N and diagonalized numerically. As N grows, the low eigenvalues converge. This is how most of quantum chemistry and nuclear physics is actually computed.

🔬 Lab 4: anharmonic oscillator by matrix diagonalization

9. Book's Exercise 14: all problems solved

1. Show that there is no nonzero 2×2 matrix that anticommutes with all three Pauli matrices.
Show solution

Method 1 (direct): anticommuting with σz gives M = [[0, b], [c, 0]] (Eq. 14).
With σx: σxM + Mσx = [[c, 0], [0, b]] + [[b, 0], [0, c]] = (b + c)I = 0 ⇒ c = −b.
With σy: σyM = [[−ic, 0], [0, ib]], Mσy = [[ib, 0], [0, −ic]], sum = i(b − c)I = 0 ⇒ c = b.
Together b = c = 0 ⇒ M = 0. ∎

Method 2 (elegant): write M = a₀I + a·σ. Then {σⱼ, M} = 2a₀σⱼ + 2aⱼI (using {σⱼ, σₖ} = 2δⱼₖI). This vanishes ⇔ a₀ = 0 and aⱼ = 0 for every j, i.e. M = 0. ∎ This is why Dirac needed matrices bigger than 2×2.

2. Verify that the Pauli matrices satisfy (12), and show (a) [σx, σy] = 2iσz etc.; (b) σ² = σx² + σy² + σz² = 3I; (c) [σ², σᵢ] = 0; (d) [σz, σ±] = ±2σ±, σ± = σx ± iσy; (e) [σ₊, σ₋] = 4σz.
Show solution

(12): σx² = [[0, 1], [1, 0]]² = I. σy² = [[(−i)(i), 0], [0, (i)(−i)]] = I. σz² = I.
σxσy = [[0, 1], [1, 0]][[0, −i], [i, 0]] = [[i, 0], [0, −i]] = iσz. σyσx = [[−i, 0], [0, i]] = −iσz. Their sum is 0 ✓. Similarly σyσz = iσx = −σzσy and σzσx = iσy = −σxσz.

(a) [σx, σy] = iσz − (−iσz) = 2iσz, and cyclically [σy, σz] = 2iσx, [σz, σx] = 2iσy.

(b) I + I + I = 3I. (For spin ½: s² = (ħ²/4)·3I = ħ²·½(½ + 1)I ✓.)

(c) σ² = 3I commutes with everything.

(d) σ₊ = [[0, 2], [0, 0]], σ₋ = [[0, 0], [2, 0]]. σzσ₊ = [[0, 2], [0, 0]] and σ₊σz = [[0, −2], [0, 0]], so [σz, σ₊] = [[0, 4], [0, 0]] = 2σ₊. Similarly [σz, σ₋] = −2σ₋.

(e) σ₊σ₋ = [[4, 0], [0, 0]], σ₋σ₊ = [[0, 0], [0, 4]], difference = 4σz ✓.

P4. A rotation matrix has Tr R = 0. What is the rotation angle? rotation
Show solution

1 + 2cos φ = 0 ⇒ cos φ = −½ ⇒ φ = 120°. Example: the cyclic permutation [[0, 0, 1], [1, 0, 0], [0, 1, 0]], a rotation by 120° about (1, 1, 1).

P5. Is Rz(90°)Rx(90°) = Rx(90°)Rz(90°)? order
Show solution

No. Finite rotations about different axes do not commute. Try it with a book: turn it 90° about z then x, versus x then z. The difference is a second-order effect in the angles: infinitesimal rotations do commute to first order, and their commutator gives the angular momentum algebra.

P6. Expectation of σx in the state χ = (cos(θ/2), eiφsin(θ/2)). Bloch
Show solution

χ†σxχ = 2 Re[cos(θ/2)·eiφsin(θ/2)] = sin θ cos φ. Likewise ⟨σy⟩ = sin θ sin φ and ⟨σz⟩ = cos θ.

P7. Show that γ⁰ = β, γⁱ = βαᵢ satisfy {γμ, γν} = 2ημνI, η = diag(1, −1, −1, −1). Dirac
Show solution

(γ⁰)² = β² = I. (γⁱ)² = βαᵢβαᵢ = −β²αᵢ² = −I (since αᵢβ = −βαᵢ). For i ≠ j: γⁱγʲ + γʲγⁱ = βαᵢβαⱼ + βαⱼβαᵢ = −(αᵢαⱼ + αⱼαᵢ) = 0. {γ⁰, γⁱ} = β²αᵢ + βαᵢβ = αᵢ − αᵢ = 0. ∎

P8. Why can't [x, p] = iħI hold for finite matrices? infinite
Show solution

Tr(xp − px) = Tr(xp) − Tr(px) = 0, but Tr(iħIn) = iħn ≠ 0. A contradiction, so the matrices must be infinite.

P9. In the HO basis, ⟨m|x|n⟩ = (1/√2)(√n δm,n−1 + √(n+1) δm,n+1). Find ⟨0|x²|0⟩ and ⟨0|x²|2⟩. matrix elements
Show solution

(x²)00 = Σk x0kxk0 = x01x10 = (1/√2)² = ½. (x²)02 = x01x12 = (1/√2)(√2/√2) = 1/√2. This is matrix multiplication with infinite matrices (Eq. 27). Only a few terms are nonzero.

P10. U = e−iθσz/2. Find U for θ = 2π and interpret. spinor
Show solution

U = I cos π − iσz sin π = −I. A full 360° rotation multiplies a spinor by −1. You need 720° to return to +1. This has been confirmed in neutron interferometry experiments.

12. Interesting facts

Gimbal lock At β = 0 the first and third Euler rotations are about the same axis, so α and γ merge into one angle and a degree of freedom is lost. The Apollo 11 guidance computer had to avoid this ("gimbal lock"). Modern spacecraft and video games use quaternions, which are closely related to the Pauli matrices: iσx, iσy, iσz multiply like −i, −j, −k.
Heisenberg's matrix mechanics (1925) Heisenberg found rules for multiplying arrays of transition amplitudes without knowing they were matrices. Born recognized the "matrix multiplication", and then Born, Jordan and Heisenberg wrote down [x, p] = iħ. Infinite matrices were the very first form of quantum mechanics, before Schrödinger's waves.
Dirac's surprise The 4 components of the Dirac spinor give 2 spin states × 2 energy signs. Dirac first tried to read the negative energies as protons, but the prediction turned out to be the positron, discovered by Anderson in 1932.
The only anticommuting families The number of mutually anticommuting n×n matrices that square to I is at most 2k + 1 when n = 2km with m odd. For 2×2 that is 3 (the Pauli matrices), for 4×4 it is 5 (Dirac's four plus γ⁵). These are Clifford algebras, which also describe rotations in any dimension.
