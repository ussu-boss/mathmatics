0. Roadmap

This section is about matrices that can be undone. A matrix moves vectors around. Sometimes you can move them back exactly (the matrix has an inverse). Two families can be undone very cheaply:

  • Orthogonal (real): the inverse is just the transpose, A⁻¹ = Aᵀ. These are rotations and reflections.
  • Unitary (complex): the inverse is the conjugate transpose, U⁻¹ = U†. They keep the length of complex vectors fixed. This is why they run quantum mechanics.
Inverse A⁻¹→adjoint ÷ det→(AB)⁻¹ = B⁻¹A⁻¹→Orthogonal AᵀA = I→Unitary U†U = I→Keep lengths→Change of basis x′ = P⁻¹x→Similarity B = P⁻¹AP
What you need from earlier sections Transpose Ãᵢⱼ = Aⱼᵢ (the book writes Ã, here written Aᵀ), hermitian conjugate A† = (A*)ᵀ, cofactor Aⁱʲ, and the "alien cofactor" result of Section 4: ∑ₖ aᵢₖ Aʲᵏ = (det A) δᵢⱼ. Expanding a row against its own cofactors gives det A. Expanding it against another row's cofactors gives 0.

1. The inverse matrix

Definition (Eq. 1–2) A matrix A is nonsingular if there is a matrix B with
AB = I,   BA = I.
Then B is the inverse of A, written B = A⁻¹, and A is also the inverse of B (A = B⁻¹). If no such B exists, A is singular.

Facts that come straight from the definition

  1. Only square matrices have inverses (for finite matrices, Appendix II). A 2×3 matrix can have a "one-sided" inverse at most, never a full one.
  2. One side is enough (finite square matrices): AB = I ⇔ BA = I. So you only need to check one product.
  3. Determinant test. Take det of AB = I: (det A)(det B) = 1 (Eq. 3). If det A = 0 there is no number det B that works, so A is singular. Conversely if det A ≠ 0 the adjoint formula below builds the inverse. So:
    A⁻¹ exists ⇔ det A ≠ 0,    and then det(A⁻¹) = 1 / det A.
  4. The inverse is unique (Eq. 13–14). If AB = I and AC = I, then BA = I too, so C = (BA)C = B(AC) = B.
  5. Every matrix commutes with its own inverse: AA⁻¹ = A⁻¹A = I (Eq. 12).
Infinite matrices are different For infinite matrices (Section 14 of the book, matrix mechanics), AB = I does not imply BA = I. Example: the "shift" matrix that pushes every component one place down has a left inverse but no right inverse. That is why the book insists on both equations in the definition.
Picture det A is the factor by which A scales areas (volumes in 3D). If det A = 0, A squashes the plane onto a line (or a point), and information is lost. Many different vectors land on the same point, so no matrix can send them back. That is exactly "singular".

2. Finding the inverse: the adjoint method (Eqs. 4–7)

Recipe
  1. Cofactor matrix Ac: replace every element aᵢⱼ by its cofactor Aⁱʲ = (−1)^{i+j} × (minor).
  2. Adjoint (also called adjugate): transpose it, adj A = Ãc. Its (i, j) element is the cofactor Aʲⁱ (note the swapped indices).
  3. Divide by the determinant:
    A⁻¹ = adj A / det A,    equivalently  A · adj A = (det A) I  (Eq. 6b)

Why it works (Eq. 7)

Element (i, j) of A · adj A is ∑ₖ aᵢₖ Aʲᵏ. This is row i of A expanded against the cofactors of row j. If i = j you get det A. If i ≠ j you get the determinant of a matrix with two equal rows, which is 0. So A · adj A = (det A) I, and dividing by det A gives I.

The 2×2 shortcut (learn this by heart)

−1 = 1/(ad − bc)

Swap the diagonal entries, change the sign of the off-diagonal entries, then divide by the determinant.

Common traps
  • (A + B)⁻¹ ≠ A⁻¹ + B⁻¹ in general. Even for numbers, 1/(2+3) ≠ 1/2 + 1/3.
  • (AB)⁻¹ ≠ A⁻¹B⁻¹ unless A and B commute. Think of putting on socks and then shoes: to undo it you take the shoes off first.
  • Cancelling: from AB = AC you may conclude B = C only if A is nonsingular. With AB = 0 and A ≠ 0, B ≠ 0 is possible (both singular, Ex. 4).

4. Inverse transformation (Eqs. 21–28)

A linear transformation y = Ax (both vectors of size n) can be undone if A is nonsingular. Multiply by B = A⁻¹ on the left:

x = A⁻¹y,    xᵢ = ∑ⱼ bᵢⱼ yⱼ

The inverse map is also linear. If det A = 0, the map squashes space flat and cannot be undone.

5. Orthogonal matrix (Eqs. 29–34)

Definition A is orthogonal if AᵀA = I and AAᵀ = I. For a finite square matrix one implies the other. Equivalently (Eq. 30):
A⁻¹ = Aᵀ

Consequences

  1. det A = ±1. det(AᵀA) = (det A)² = 1. So an orthogonal matrix is always nonsingular.
      +1 → proper (a pure rotation), −1 → improper (a rotation combined with a reflection).
  2. Rows are orthonormal (Eq. 31a): ∑ₖ aᵢₖ aⱼₖ = δᵢⱼ. Each row has length 1, and two different rows are perpendicular.
  3. Columns are orthonormal (Eq. 31b): ∑ₖ aₖᵢ aₖⱼ = δᵢⱼ.
  4. So an n×n real orthogonal matrix is the same thing as a set of n orthonormal vectors written as columns (or as rows).
  5. Products and inverses of orthogonal matrices are orthogonal: (AB)ᵀ(AB) = BᵀAᵀAB = I. Orthogonal matrices form a group, O(n). Those with det = +1 form SO(n).
  6. Every eigenvalue has |λ| = 1. A real orthogonal matrix of odd order with det +1 always has λ = 1 as an eigenvalue: the rotation axis.
The book's convention "Orthogonal" can also be defined for complex entries, e.g. satisfies AᵀA = I. Check: [[i, √2],[−√2, i]]·[[i, −√2],[√2, i]] gives (1,1) = −1 + 2 = 1, (1,2) = −i√2 + i√2 = 0. But in the book (and in exams), "orthogonal" means real orthogonal unless stated otherwise. A complex orthogonal matrix does not keep lengths fixed. For complex vectors the right notion is unitary.

Independent parameters: n(n − 1)/2

A real n×n matrix has n² entries. The conditions ∑ₖ aᵢₖ aⱼₖ = δᵢⱼ do not change when i and j are swapped, so only the pairs i ≤ j count. That gives 1 + 2 + … + n = n(n + 1)/2 independent conditions. So

free parameters = n² − n(n + 1)/2 = n(n − 1)/2
n1234n
n(n−1)/201 (an angle θ)3 (Euler angles α, β, γ)6number of planes you can rotate in
Physical meaning n(n−1)/2 is the number of coordinate planes (xy, yz, zx, …). Each plane gives one independent rotation angle. In 3D there are 3 planes and 3 angles, and also 3 components of angular momentum Lₓ, L_y, L_z. In 4D spacetime there are 6 planes, which is why there are 6 Lorentz generators (3 rotations + 3 boosts).

7. Unitary matrix (Eqs. 39–50)

Definition U is unitary if UU† = I and U†U = I. For finite square U one implies the other. Equivalently (Eq. 41):
U⁻¹ = U† = (U*)ᵀ
  1. |det U| = 1 (Eq. 40): det(U†) = (det U)*, so |det U|² = 1 and det U = e^{iφ}, a point on the unit circle.
  2. Rows (and columns) are orthonormal in the complex sense: ∑ₖ uᵢₖ u*ⱼₖ = δᵢⱼ (Eq. 42).
  3. A real unitary matrix is orthogonal. Unitary is the complex version of orthogonal.
  4. Eigenvalues lie on the unit circle, |λ| = 1. Eigenvectors for different eigenvalues are orthogonal.
  5. Products and inverses of unitary matrices are unitary. They form the group U(n). Those with det = 1 form SU(n).

Independent parameters: n²

There are 2n² real numbers (each entry has a real and an imaginary part). Conditions with i ≤ j:

  • i = j: ∑ₖ |uᵢₖ|² = 1. These are real, giving n real conditions.
  • i < j: ∑ₖ uᵢₖ u*ⱼₖ = 0. These are complex, n(n−1)/2 equations × 2 = n(n−1) real conditions.
free real parameters = 2n² − [n + n(n−1)] = 2n² − n² = n²

Unitary and hermitian matrices both have n² parameters, and that is no accident: every unitary matrix is U = e^{iH} with H hermitian.

8. Orthogonal and unitary transformations keep lengths (Eqs. 51–54)

Theorem A square matrix A is unitary ⇔ ‖Ax‖ = ‖x‖ for every vector x.
(⇒) ‖Ax‖² = (Ax)†(Ax) = x†A†Ax = x†x = ‖x‖² (Eq. 52).
(⇐) If x†(A†A − I)x = 0 for all x, then the hermitian matrix A†A − I is zero, so A†A = I.
For real A and real x: orthogonal ⇔ length preserving: ∑ yᵢ² = ∑ xᵢ² (Eq. 54).

Because they keep lengths, they also keep inner products and angles: (Ax)†(Ay) = x†y. They are rigid motions that fix the origin, and they never stretch or squash anything.

9. Change of basis (Eqs. 55–62, Fig. 1)

Let e = {e₁,…,eₙ} be a basis and e′ = {e′₁,…,e′ₙ} another basis of the same space. Each new basis vector is a combination of the old ones: e′ = Pe. Then also e = Qe′ with QP = I (Eq. 58). So:

A matrix that turns one basis into another is always nonsingular.

Components transform the opposite way. The vector itself does not move. Only its description changes. If the axes turn by +θ, the vector looks as if it turned by −θ relative to the new axes:

x′ = P⁻¹x,    x = Px′   (Eq. 59)

Convention used here (as in the book's Fig. 1): the columns of P are the new basis vectors written in old components. With the index form of Eq. 55a, e′ᵢ = ∑ⱼ pᵢⱼ eⱼ, the rows play that role. That only swaps P and Pᵀ, and for rotations it changes nothing important.

10. Similarity transformation (Eqs. 63–67)

Suppose in the old basis the matrix A sends y to x: x = Ay. What matrix does the same job in the new basis? Using x = Px′ and y = Py′:

Px′ = APy′ ⇒ x′ = (P⁻¹AP) y′  ⇒  B = P⁻¹AP,   A = PBP⁻¹

A and B are similar. They are the same linear map described in two coordinate systems.

What similarity preserves

  • Form of every matrix equation (Eqs. 64–66). From ABC + DE = F you get A′B′C′ + D′E′ = F′, where X′ = P⁻¹XP. You insert I = PP⁻¹ between the factors. This is how physicists "go to a convenient basis" to simplify a problem.
  • Determinant: det(P⁻¹AP) = det A.
  • Trace: tr(P⁻¹AP) = tr(APP⁻¹) = tr A.
  • Eigenvalues, characteristic polynomial, rank, powers: (P⁻¹AP)ᵏ = P⁻¹AᵏP.
  • Commuting: if P⁻¹AP and P⁻¹BP are both diagonal, then A and B commute (Ex. 9).

Don't confuse with congruence B = PᵀAP with a general P is a congruence (used for quadratic forms). It equals a similarity only when Pᵀ = P⁻¹, i.e. P is orthogonal.

Relations between the special matrices

  • Real + unitary ⇔ orthogonal.
  • Hermitian + unitary ⇒ U² = I. Examples: Pauli matrices, reflections. Eigenvalues are ±1.
  • Symmetric + orthogonal ⇒ A² = I. Example: the Householder reflector I − 2xxᵀ/xᵀx (Ex. 14).
  • Triangular + unitary ⇒ diagonal (Ex. 16).
  • Hermitian, anti-hermitian and unitary matrices are all normal (AA† = A†A, Ex. 17).
  • Cayley transform: H hermitian ⇒ (H − iI)(H + iI)⁻¹ unitary (Ex. 18). A skew-symmetric matrix S gives an orthogonal one, (I − S)(I + S)⁻¹.
  • Exponential map: H hermitian ⇒ e^{iH} unitary. S real antisymmetric ⇒ e^{S} orthogonal with det +1.

9. If P⁻¹AP and P⁻¹BP are both diagonal, prove AB = BA.
Show solution

Let D₁ = P⁻¹AP and D₂ = P⁻¹BP. Diagonal matrices commute: D₁D₂ = D₂D₁. Now A = PD₁P⁻¹ and B = PD₂P⁻¹, so AB = PD₁P⁻¹PD₂P⁻¹ = PD₁D₂P⁻¹ = PD₂D₁P⁻¹ = BA. ∎

Physics: observables that can be diagonalised together (sharing an eigenbasis) commute. The converse is the "common eigenvectors" theorem proved later in the book.

13. For which real a, b is orthogonal?
Show solution

16. Show a unitary triangular matrix must be diagonal.
Show solution

Let U be upper triangular and unitary. Then U⁻¹ is upper triangular (inverses of triangular matrices are triangular of the same type). But U⁻¹ = U† is lower triangular. A matrix that is both upper and lower triangular is diagonal. So U† is diagonal, and hence U is diagonal. ∎

Moreover |uᵢᵢ| = 1, so U = diag(e^{iφ₁}, …, e^{iφₙ}).

Column-by-column version: column 1 is (u₁₁, 0, …). Length 1 gives |u₁₁| = 1. Row 1 has length 1, so |u₁₁|² + |u₁₂|² + … = 1 forces u₁₂ = … = u₁ₙ = 0. Repeat for the next row.

17. Show hermitian and unitary matrices commute with their own hermitian conjugates.
Show solution

Hermitian: H† = H, so HH† = H² = H†H.
Unitary: UU† = I = U†U. ∎

Such matrices (AA† = A†A) are called normal. Normal matrices are exactly the ones that can be diagonalised by a unitary matrix.

18. If H is hermitian, show U = (H − iI)(H + iI)⁻¹ is unitary.
Show solution

(H + iI) is invertible: the eigenvalues of H are real, so H + iI has eigenvalues λ + i ≠ 0.
Also, H − iI and (H + iI)⁻¹ commute, because both are functions of H.

U† = [(H + iI)⁻¹]†(H − iI)† = (H† − iI)⁻¹(H† + iI) = (H − iI)⁻¹(H + iI).

U†U = (H − iI)⁻¹(H + iI)(H − iI)(H + iI)⁻¹. The middle factors commute, so this equals (H − iI)⁻¹(H − iI)(H + iI)(H + iI)⁻¹ = I. ∎

For a single real number h this reads u = (h − i)/(h + i), and |h − i| = |h + i| gives |u| = 1. This is the Cayley transform, which maps the real line onto the unit circle.

17. Interesting facts

Nobody computes inverses in practice Numerical software almost never forms A⁻¹. To solve Ax = b it factorises A (LU, QR) instead, which is faster and more accurate. The adjoint formula takes about n! operations; Gauss–Jordan takes about n³.
Quantum mechanics is unitary Time evolution |ψ(t)⟩ = e^{−iHt/ħ}|ψ(0)⟩ is unitary because H is hermitian. That is exactly why total probability stays 1, the length-preservation theorem of Section 8.
Quantum gates Every gate in a quantum computer (Hadamard, CNOT, phase …) is a unitary matrix. Computation without measurement is reversible because unitaries have inverses.
Mirrors cannot be rotated away The orthogonal matrices with det = +1 and those with det = −1 form two separate pieces. You cannot slide continuously from one to the other, because det would have to pass through 0. That is why your left glove never turns into a right glove by rotating it.
SU(2) and spin The 3-parameter SU(2) matrices of Example 7 (with γ = 0) cover the 3D rotations twice: U and −U give the same rotation. That is why an electron must be rotated by 720° to come back to its original state.
Similarity = same physics, different coordinates Diagonalising a Hamiltonian, going to normal modes, or choosing principal axes of the inertia tensor are all similarity (usually orthogonal or unitary) transformations chosen to make the matrix diagonal.
