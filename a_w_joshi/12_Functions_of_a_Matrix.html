0. Roadmap

We know what 210, √5, e3, ln 7 and sin π/2 mean for numbers. This section gives the same meaning to A10, √A, eA, ln A and sin A for a square matrix A. The key idea:

The one idea behind everything A function of a matrix acts on the eigenvalues and leaves the eigenvectors alone.
If Ax = λx then f(A)x = f(λ)x.

Why physicists care: the solution of dx/dt = Ax is x(t) = etAx(0). The time evolution in quantum mechanics is e−iHt/ħ. Rotations are eθJ. All of these are functions of matrices.

A = PΛP⁻¹→f(A) = P f(Λ) P⁻¹orf(A) = α₀I + α₁A + … + αm−1Am−1→eA, ln A, √A, sin A, …
Needed from earlier Diagonalization P⁻¹AP = Λ (Section 9). Minimal polynomial and Cayley–Hamilton (Section 10): every polynomial in A reduces to degree ≤ m − 1. Taylor series of ex, sin x, cos x, ln(1 + x).

1. Two methods

Method 1: diagonalization (Eqs. 1, 2) If P⁻¹AP = Λ = diag(λ₁, …, λₙ), then
f(A) = P f(Λ) P⁻¹,   f(Λ) = diag(f(λ₁), …, f(λₙ))
✔ simple and mechanical
✘ works for diagonalizable matrices only
Method 2: Cayley–Hamilton (Eqs. 58–60) If the minimal polynomial has degree m,
f(A) = αm−1Am−1 + … + α₁A + α₀I
Find the α's from f(λᵢ) = r(λᵢ), plus derivatives for repeated eigenvalues.
✔ works for every matrix
✔ no eigenvectors needed

Why method 1 works: Ak = (PΛP⁻¹)(PΛP⁻¹)…(PΛP⁻¹) = PΛkP⁻¹, because each P⁻¹P in the middle cancels. A power series ΣakAk is therefore PΣakΛkP⁻¹ = Pf(Λ)P⁻¹. Powers of a diagonal matrix are just powers of its entries.

How many roots? Careful The book says: if A has m nonzero eigenvalues, there are km k-th roots. This counts the roots of the form PΛ1/kP⁻¹, and it is exact when the eigenvalues are distinct. Two warnings:
  • Repeated eigenvalue ⇒ infinitely many roots. I (2×2) has, besides ±I, every reflection [[cos θ, sin θ], [sin θ, −cos θ]] as a square root.
  • Some matrices have no square root at all: N = [[0, 1], [0, 0]]. If B² = N, then B⁴ = N² = 0, so B is nilpotent, so B² = 0 (in 2×2), contradiction.
"The principal root" means taking the positive root of each positive eigenvalue. For a positive definite symmetric A it is the unique positive definite root.

4. Matrix series and convergence (Eqs. 24–27)

A series S = Σ akAk converges if every entry converges.  (24, 25)

Convergence theorem (stated without proof) If the scalar series f(λ) = Σakλk converges for |λ| < R, then f(A) = ΣakAk converges iff every eigenvalue satisfies |λᵢ| < R.  (26, 27)
In other words, the spectral radius ρ(A) = max|λᵢ| must be < R.

Why the eigenvalues decide: on each eigenvector the series acts like the scalar series Σakλik. If even one of those diverges, the matrix series diverges.

Entries can mislead A = [[0.5, 100], [0, 0.5]] has huge entries but ρ = 0.5 < 1, so I + A + A² + … still converges, to (I − A)⁻¹ = [[2, 400], [0, 2]]. The partial sums first grow big, then settle. Try it in the lab ("big entries").

8. Hyperbolic and trigonometric functions (Eqs. 50–57, Example 6)

sinh A = ½(eA − e−A) = Σ A2k+1/(2k+1)!,   cosh A = ½(eA + e−A) = Σ A2k/(2k)!  (50)
sin A = (eiA − e−iA)/(2i) = Σ (−1)kA2k+1/(2k+1)!,   cos A = ½(eiA + e−iA)  (51)

All of these exist for every square matrix. Identities like sin²A + cos²A = I, cosh²A − sinh²A = I, and sin 2A = 2 sin A cos A all hold, because only one matrix A is involved and its powers commute. Identities like sin(A + B) = sin A cos B + cos A sin B need AB = BA.

9. The Cayley–Hamilton method: works for every matrix (Eqs. 58–81)

From Section 10, any polynomial in A equals a polynomial of degree ≤ m − 1 (m = degree of the minimal polynomial). The same holds for any function given by a convergent power series:

f(A) = r(A) = αm−1Am−1 + … + α₁A + α₀I   (58, 59)
How to find the α's (Eq. 60) For each eigenvalue λᵢ appearing r times in the minimal polynomial, match the value and the first r − 1 derivatives:
f(λᵢ) = r(λᵢ),   f′(λᵢ) = r′(λᵢ),   …,   f(r−1)(λᵢ) = r(r−1)(λᵢ)
That gives m linear equations for the m unknowns α₀, …, αm−1.

Why derivatives? f(λ) − r(λ) must be divisible by the minimal polynomial (so that it vanishes at A). A root of multiplicity r in the divisor means f − r must vanish there together with its first r − 1 derivatives.

Example 7: Ap for the matrix of Eq. (8) (λ = 1, 2)

r(λ) = α₁λ + α₀. Conditions: 1 = α₁ + α₀ and 2p = 2α₁ + α₀ ⇒ α₁ = 2p − 1, α₀ = 2 − 2p.

Ap = (2p − 1)A + (2 − 2p)I = ⅓[[2p + 2, (2p − 1)√2], [(2p − 1)√2, 2p+1 + 1]]  (64)

This agrees with (11). For non-integer p this is only one of the matrices equal to Ap: other root choices exist.

10. det(eA) = eTr A (Example 12)

(a) Diagonalizable A: det eA = det(P eΛ P⁻¹) = det eΛ = eλ₁eλ₂…eλₙ = eλ₁+…+λₙ = eTr A.  (83–86)

(b) Any A: bring it to triangular form T = P⁻¹AP with diagonal λᵢ. Powers of a triangular matrix are triangular with diagonal λᵢk, so eT is triangular with diagonal eλᵢ. Then det eA = det eT = Πeλᵢ = eTr A.  (87–90)

  • Consequence: eA is always invertible (ex > 0 is never 0).
  • Tr A = 0 ⇒ det eA = 1. This is why traceless matrices generate the groups SU(n) and SL(n). In mechanics, Liouville's theorem (phase-space volume is conserved) is this fact for Hamiltonian flows.
  • Equivalent form: ln det A = Tr ln A, used all the time in field theory and statistics.

11. eAeB vs eA+B (Example 13)

For numbers, eaeb = ea+b. For matrices, expand to second order:

eAeB = I + A + B + ½A² + AB + ½B² + …    eA+B = I + A + B + ½(A² + AB + BA + B²) + …

The difference starts at ½(AB − BA) = ½[A, B]. So:

  • AB = BA ⇒ eAeB = eA+B (exactly).
  • If C = [A, B] commutes with both A and B ([C, A] = [C, B] = 0), then
    eAeB = eA+B+½C   (91)
  • In general you get the Baker–Campbell–Hausdorff series eAeB = exp(A + B + ½[A,B] + (1/12)([A,[A,B]] + [B,[B,A]]) + …).

The book's proof, in steps

  1. Let f(λ) = eλAeλBe−λ(A+B). Then f(0) = I.
  2. Exercise 10 gives eλABe−λA = B + λ[A, B] + (λ²/2!)[A,[A,B]] + …. Here [A, C] = 0, so it stops: eλABe−λA = B + λC, i.e. eλAB = (B + λC)eλA.  (94–96)
  3. Differentiate f, using that and the fact that C commutes with everything here: df/dλ = λC f.  (97)
  4. Solve this scalar-like equation (C is a constant matrix commuting with f): f(λ) = exp(Cλ²/2).  (99a)
  5. Put λ = 1: eAeBe−(A+B) = eC/2 ⇒ eAeB = eA+B+C/2. ∎  (100)
Quantum mechanics Position and momentum satisfy [x, p] = iħ, a constant that commutes with everything. With A = iax and B = ibp, C = [A, B] = −ab[x, p] = −iabħ, so eiaxeibp = ei(ax+bp)e−iabħ/2. This "displacement operator" identity is exactly Eq. (91), and it is behind coherent states of the harmonic oscillator.

13. Book's Exercise 12: all problems solved

1. If AB = BA, show f(A) and g(B) commute (f, g power series).
Show solution

AB = BA ⇒ AjBk = BkAj for all j, k (move each B past each A one at a time). Then f(A)g(B) = Σj,kajbkAjBk = ΣbkajBkAj = g(B)f(A). (The double series converges absolutely, so the terms may be rearranged.) ∎

2. Prove eA is nonsingular even if A is singular, and (eA)⁻¹ = e−A.
Show solution

det eA = eTr A ≠ 0 (Example 12). So eA is nonsingular for every A. Since A and −A commute, eAe−A = eA−A = e0 = I (Example 13 with C = 0). So (eA)⁻¹ = e−A. ∎ Example: A = [[0, 1], [0, 0]] is singular, eA = [[1, 1], [0, 1]] has det 1.

3. Show a0 = I for any nonzero scalar a (0 = null matrix).
Show solution

a0 = exp(0 · ln a) = exp(0) = I + 0 + 0²/2! + … = I. ∎ (ln a exists for a ≠ 0, possibly complex. It is multiplied by the zero matrix anyway.)

10. Show eλABe−λA = B + λ[A, B] + (λ²/2!)[A,[A,B]] + (λ³/3!)[A,[A,[A,B]]] + ….
Show solution

Let F(λ) = eλABe−λA. Then F(0) = B and F′(λ) = AeλABe−λA − eλABe−λAA = [A, F(λ)].

Repeating: F″ = [A, F′] = [A, [A, F]], …, F(n)(0) = [A, [A, … [A, B]…]] (n commutators). Taylor's series F(λ) = ΣF(n)(0)λⁿ/n! gives the result. ∎ (In quantum mechanics this is how eiHt O e−iHt, the Heisenberg picture, is expanded.)

P1. Find etA for A = [[0, 1], [−1, 0]]. rotation
Show solution

A² = −I ⇒ etA = I cos t + A sin t = [[cos t, sin t], [−sin t, cos t]].

P2. A 3×3 matrix has eigenvalues 1, 2, 3. Find det(eA) and Tr(eA). eigenvalues
Show solution

det eA = e6. Tr eA = e + e² + e³.

P3. σx = [[0, 1], [1, 0]]. Find eiθσx. Pauli
Show solution

σx² = I ⇒ eiθσx = I cos θ + iσx sin θ = [[cos θ, i sin θ], [i sin θ, cos θ]]. It is unitary. In general eiθ n̂·σ = I cos θ + i(n̂·σ) sin θ.

P4. Evaluate eA for A = [[2, 1], [0, 2]]. defective
Show solution

A = 2I + N with N² = 0 and 2I commuting with N ⇒ eA = e²(I + N) = e²[[1, 1], [0, 1]]. Or by CH: f(2) = e² = 2α₁ + α₀, f′(2) = e² = α₁ ⇒ α₀ = −e², same answer.

Show solution

Need |2s| < 1 and |0.5s| < 1 ⇒ |s| < 1/2.

P6. Find sin A for A = diag(π/2, π), and sin B for B = PAP⁻¹ (P any invertible matrix). trig
Show solution

sin A = diag(1, 0). sin B = P diag(1, 0) P⁻¹, a projector onto the first eigenvector. Note (sin B)² = sin B.

P7. Find all square roots of diag(4, 9). roots
Show solution

The eigenvalues are distinct, so every root commutes with A and is therefore diagonal: diag(±2, ±3), 4 roots. (Contrast: the 2×2 identity has infinitely many.)

P8. Compute A100 for A = [[1, 1], [0, 2]]. CH method
Show solution

λ = 1, 2. r(λ) = α₁λ + α₀: 1 = α₁ + α₀, 2¹⁰⁰ = 2α₁ + α₀ ⇒ α₁ = 2¹⁰⁰ − 1, α₀ = 2 − 2¹⁰⁰. A¹⁰⁰ = [[1, 2¹⁰⁰ − 1], [0, 2¹⁰⁰]].

P9. Show that if H is hermitian, U = eiH is unitary, and det U = ei Tr H. QM
Show solution

U† = e−iH† = e−iH, and iH commutes with −iH ⇒ U†U = e0 = I. det U = eTr(iH) = ei Tr H, which has modulus 1 since Tr H is real.

P10. Solve ẋ = Ax with A = [[0, 1], [1, 0]], x(0) = (1, 0). ODE
Show solution

A² = I ⇒ etA = I cosh t + A sinh t ⇒ x(t) = (cosh t, sinh t). It moves along the hyperbola x² − y² = 1.

P11. A is real antisymmetric 3×3. Show eA is a rotation (orthogonal with det 1). groups
Show solution

(eA)ᵀ = eAᵀ = e−A = (eA)⁻¹ ⇒ orthogonal. det eA = eTr A = e0 = 1 ⇒ a proper rotation. (Rodrigues' formula: eθK = I + K sin θ + K²(1 − cos θ) for a unit axis generator K.)

P12. If A² = A (projector), find etA. projector
Show solution

Ak = A for k ≥ 1 ⇒ etA = I + A(t + t²/2! + …) = I + (et − 1)A.

16. Interesting facts

"Nineteen dubious ways" A famous 1978 paper by Moler and Van Loan, "Nineteen Dubious Ways to Compute the Exponential of a Matrix", showed that every simple method has hidden numerical traps. Diagonalization fails for nearly defective matrices, and plain Taylor series lose accuracy through cancellation. Modern software uses "scaling and squaring": eA = (eA/2ˢ)2ˢ, which is what the labs here use.
Lie groups and Lie algebras Every continuous symmetry group (rotations, Lorentz, SU(2), SU(3) of QCD) is reached by exponentiating a small set of matrices, its "generators". The commutators [Jᵢ, Jⱼ] = iεijkJk of angular momentum are exactly the BCH data of Section 11.
Trotter formula Even when [A, B] ≠ 0, eA+B = limn→∞(eA/neB/n)ⁿ. This is the basis of Feynman's path integral and of quantum simulation algorithms.
Square roots in quantum computing The "√NOT" gate is a square root of the Pauli-X matrix: ½[[1 + i, 1 − i], [1 − i, 1 + i]]. Squaring it gives X. Matrix roots are a real engineering topic.
Sylvester's formula For distinct eigenvalues, the Cayley–Hamilton method is the same as f(A) = Σ f(λᵢ)Pᵢ with the projectors Pᵢ = Πⱼ≠ᵢ(A − λⱼI)/(λᵢ − λⱼ) of Section 10. James Joseph Sylvester introduced it in 1883.
