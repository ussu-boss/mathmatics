0. Roadmap

A tensor is defined by how its components change when you change coordinates. The definition is not "an arrow" or "a table of numbers". The number of indices is the rank:

1. Where tensors appear in physics (Eqs. 1–2)

Simple laws like a = F/m and j = σE (Ohm's law) assume an isotropic medium, i.e. one with the same properties in every direction. Then the response is parallel to the cause.

In a crystal the current need not flow along E. Each component of j depends on all components of E:

jx = σxxEx + σxyEy + σxzEz
jy = σyxEx + σyyEy + σyzEz
jz = σzxEx + σzyEy + σzzEz   (2)   i.e.   ji = σijEj

The nine σij form the conductivity tensor, a rank-2 tensor. Similarly, an electron in a crystal has an effective mass tensor: ai = (1/m)ijFj.

Isotropic is the special case If σij = σδij (σ times the identity), Eq. (2) reduces to j = σE. A rank-2 tensor is a linear machine that turns one vector into another, possibly rotating it as well as stretching it.

2. Notation and conventions (Eqs. 3–17)

  • N-dimensional space VN, coordinates x¹, x², …, xN. The superscript is a label, not a power. A power is written with brackets: (x²)³.
  • Latin indices (i, j, k) label the unbarred system xi. Greek indices (α, β) label the barred system x̄α.
  • Each set of coordinates is a function of the other: xi = xi(x̄¹, …, x̄N), x̄α = x̄α(x¹, …, xN).  (3)

Example 1: Cartesian ↔ spherical

x = r sin θ cos φ,   y = r sin θ sin φ,   z = r cos θ  (4)
r = √(x² + y² + z²),   θ = tan⁻¹[√(x² + y²)/z],   φ = tan⁻¹(y/x)  (5)

Differentiating with the chain rule:

dxi = Σα (∂xi/∂x̄α) dx̄α,    dx̄α = Σi (∂x̄α/∂xi) dxi   (6)

Einstein summation convention

The rule If an index is repeated in a term, sum over it from 1 to N. No Σ sign is written.
dxi = (∂xi/∂x̄α) dx̄α   (7a, 8)
  • Dummy index: appears twice in a term and is summed. It can be renamed freely: aibi = ajbj = akbk.  (11)
  • Free index: appears once, can take any value 1…N, and must be the same on both sides of an equation. Eq. (8) is really N equations, one for each i.
  • An index must never appear three or more times in one term.

4. The Kronecker delta (Eqs. 18–23)

The coordinates are independent of each other, so ∂xi/∂xj = 1 if i = j and 0 otherwise.  (18)   Define

δij = 1 (i = j), 0 (i ≠ j);    ∂xi/∂xj = δij,   ∂x̄α/∂x̄β = δαβ   (19–21)

The chain rule then gives the key identity:

(∂xi/∂x̄α)(∂x̄α/∂xj) = δij,    (∂x̄α/∂xk)(∂xk/∂x̄β) = δαβ   (22, 23)
In matrix language Let J = [∂x̄α/∂xi] (the Jacobian matrix) and K = [∂xi/∂x̄α]. Then (23) says JK = KJ = I: the two Jacobian matrices are inverses of each other. Lab 4 shows this at any point you choose.

Rules for using δ

  • Substitution: δijAj = Ai. The δ "renames" the index and disappears.
  • δii = N (trace of the identity), not 1!
  • δijδjk = δik (I·I = I).
  • Note: δij = ∂xi/∂xj is careless notation. The mixed δij is the true tensor (Section 16).

5. Contravariant vectors (Eqs. 24–27)

Definition N quantities Ai (index up) are the components of a contravariant vector if, under x → x̄,
Āα = (∂x̄α/∂xj) Aj   (24)
It transforms like the differentials dxi, i.e. like a small displacement.

Inverse: multiply (24) by ∂xk/∂x̄α and sum over α. Using (23a), (∂xk/∂x̄α)(∂x̄α/∂xj)Aj = δkjAj = Ak. So

Ai = (∂xi/∂x̄α) Āα   (25–27)

Example 3(a): velocity is contravariant

Divide dx̄α = (∂x̄α/∂xi)dxi by dt: v̄α = dx̄α/dt = (∂x̄α/∂xi) vi. This is exactly (24).  (30–32)

In spherical coordinates the contravariant velocity components are just (ṙ, θ̇, φ̇) (Exercise 4). Note that θ̇ and φ̇ are angular rates, not speeds: contravariant components need not have the same units.

About "acceleration is also contravariant" The book argues this by differentiating again in time, treating ∂x̄α/∂xi as constant (footnote 3). That is true for linear transformations, such as rotations or fixed oblique axes. For curvilinear coordinates the Jacobian is evaluated at the moving particle, so it changes with time. Then d²x̄α/dt² is not a vector. The acceleration vector is still defined by transforming the Cartesian ai with (24), which is exactly what Example 4 does. The result contains extra velocity-squared terms (the centripetal and Coriolis-like terms), which are the Christoffel-symbol terms of Section 19. Lab 5 shows the difference numerically.

6. Covariant vectors (Eqs. 28–36)

Definition N quantities Ai (index down) are the components of a covariant vector if
Āα = (∂xi/∂x̄α) Ai,    inverse: Ai = (∂x̄α/∂xi) Āα   (28, 29)
It transforms like the derivative operator ∂/∂xi, which uses the inverse Jacobian compared with (24).

Example 3(b): the gradient is covariant

  1. A scalar field has the same value at the same point in every system: φ(x) = φ̄(x̄).  (33)
  2. Define Ai = ∂φ/∂xi and Āα = ∂φ/∂x̄α.  (34)
  3. Chain rule: ∂φ/∂x̄α = (∂φ/∂xi)(∂xi/∂x̄α), i.e. Āα = (∂xi/∂x̄α)Ai. That is (28). ∎  (35, 36)
Contravariant AiCovariant Ai
Transforms likedxi (displacement)∂/∂xi (gradient)
LawĀα = (∂x̄α/∂xi)Ai (matrix J)Āα = (∂xi/∂x̄α)Ai (matrix Kᵀ = (J⁻¹)ᵀ)
Geometric picturecomponents along the directions of coordinate increase (parallel projection)components measured across the constant-coordinate surfaces (perpendicular projection)
Examplesvelocity, displacement dxigradient ∂φ/∂xi, force as −∂V/∂xi
Cartesian coordinatesthe two kinds are identical: for a rotation, J is orthogonal, so (J⁻¹)ᵀ = J
Invariant pairing Contracting one of each gives a scalar: ĀαB̄α = (∂xi/∂x̄α)(∂x̄α/∂xj)AiBj = δijAiBj = AiBi. Example: dφ = (∂φ/∂xi)dxi, the change of a scalar, is the same in all systems. That is why one index is up and the other down.

7. 🔬 Lab 3: see the difference between contravariant and covariant components

Use oblique axes at an angle ω (a linear coordinate change, so everything is exact). The contravariant components are found by drawing lines parallel to the axes (the parallelogram rule): V = V¹e₁ + V²e₂. The covariant components are the perpendicular projections Vi = V·ei. At ω = 90° they coincide, which is why you never noticed the difference in Cartesian coordinates.

8. Tensors of rank 2 and of general rank (Eqs. 37–41)

TypeTransformation law
Contravariant rank 2, AijĀαβ = (∂x̄α/∂xi)(∂x̄β/∂xj) Aij  (37)
Covariant rank 2, AijĀαβ = (∂xi/∂x̄α)(∂xj/∂x̄β) Aij  (38)
Mixed AijĀαβ = (∂x̄α/∂xi)(∂xj/∂x̄β) Aij  (39)
General: contravariant rank p, covariant rank qĀα₁…αpβ₁…βq = (∂x̄α₁/∂xi₁)…(∂x̄αp/∂xip)(∂xj₁/∂x̄β₁)…(∂xjq/∂x̄βq) Ai₁…ipj₁…jq  (41)
  • One Jacobian factor per index: ∂x̄/∂x for every upper index, ∂x/∂x̄ for every lower index. A tensor of rank p + q has Np+q components.
  • p = q = 0: Ā = A. A scalar is invariant (length, mass, energy, volume).
  • In fixed coordinates a rank-2 tensor can be written as an N×N matrix (40). In matrix form (37) is Ā = JAJᵀ, (38) is Ā = KᵀAK, and (39) is Ā = JAK = JAJ⁻¹, a similarity transformation. That is why the eigenvalues of a mixed tensor are invariant.
  • For rotations (J = R orthogonal), all three become Ā = RARᵀ, which is the rule Lab 1 used for σ.
Things that are NOT tensors
  • The coordinates xi themselves: in curvilinear coordinates (r, θ, φ) do not transform by (24). Only the differentials dxi do.
  • Second derivatives ∂²f/∂xi∂xj (Exercise 7): an extra term (∂²xj/∂x̄α∂x̄β)(∂f/∂xj) appears.
  • d²x̄α/dt² in curvilinear coordinates (Section 10).

10. Acceleration in spherical and polar coordinates (Example 4, Eqs. 42–51)

The Cartesian acceleration is ai = d²xi/dt². Transform with (24): āα = (∂x̄α/∂xi)ai.

  1. The nine derivatives from (5):
    ∂r/∂x = sin θ cos φ, ∂r/∂y = sin θ sin φ, ∂r/∂z = cos θ;
    ∂θ/∂x = cos θ cos φ / r, ∂θ/∂y = cos θ sin φ / r, ∂θ/∂z = −sin θ / r;
    ∂φ/∂x = −sin φ / (r sin θ), ∂φ/∂y = cos φ / (r sin θ), ∂φ/∂z = 0   (45)
    (Careful: ∂r/∂x ≠ 1/(∂x/∂r). Partial derivatives do not invert like that.)
  2. Differentiate x = r sin θ cos φ twice in time (47, 48), and likewise y and z.
  3. Combine as in (44) and simplify:
ar = r̈ − rθ̇² − r sin²θ φ̇²
aθ = θ̈ + (2/r)ṙθ̇ − sin θ cos θ φ̇²
aφ = φ̈ + (2/r)ṙφ̇ + 2 cot θ θ̇φ̇   (50)
Misprint in Eq. (50) The book's ā² (= aθ) is missing the term (2/r)ṙθ̇. I checked the result symbolically. Quick check: for motion in the plane φ = const it must match the 2D polar result aφ = φ̈ + (2/ρ)ρ̇φ̇ of Eq. (51), with θ playing the role of the angle. That needs the 2ṙθ̇/r term.

Units: only ar has units of acceleration; aθ and aφ are in s⁻². The familiar "physical" components are aθ̂ = r aθ = rθ̈ + 2ṙθ̇ − r sin θ cos θ φ̇² and aφ̂ = r sin θ aφ.

Plane polar (θ = π/2, r → ρ):

aρ = ρ̈ − ρφ̇²,    aφ = φ̈ + (2/ρ)ρ̇φ̇   (51)

−ρφ̇² is the centripetal term, and (2/ρ)ρ̇φ̇ is the Coriolis-type term. These terms are exactly what is missing if you naively take (ρ̈, φ̈) as "the acceleration".

🔬 Lab 5: true acceleration vs the naive (ρ̈, φ̈)

A particle moves on the chosen path. Orange = the true acceleration vector (from Cartesian d²x/dt²). Grey = what you would get by wrongly treating (ρ̈, φ̈) as contravariant components. They agree only when the extra terms vanish. For uniform circular motion ρ̈ = φ̈ = 0, so the naive "acceleration" is zero, yet the particle clearly accelerates toward the centre.

11. Divergence and Laplacian in cylindrical coordinates (Example 5, Eqs. 52–65)

Cylindrical: x = ρ cos φ, y = ρ sin φ, z = z.  (53)

(a) Divergence of a contravariant vector

  1. Cartesian components from (27): Ax = cos φ Aρ − ρ sin φ Aφ,  Ay = sin φ Aρ + ρ cos φ Aφ,  Az = Az.  (54)
  2. Chain rule: ∂/∂x = cos φ ∂/∂ρ − (sin φ/ρ)∂/∂φ and ∂/∂y = sin φ ∂/∂ρ + (cos φ/ρ)∂/∂φ.  (55)
  3. Apply these to (54), add, and use sin² + cos² = 1. The cross terms cancel.  (56)
div A = ∂Aρ/∂ρ + ∂Aφ/∂φ + ∂Az/∂z + Aρ/ρ   (57)

(b) Same vector given by covariant components

div A = ∂Aρ/∂ρ + (1/ρ²)∂Aφ/∂φ + ∂Az/∂z + Aρ/ρ   (60)

Link to the textbook formula: with physical components Aρ̂ = Aρ = Aρ and Aφ̂ = ρAφ = Aφ/ρ, both (57) and (60) become the familiar

∇·A = (1/ρ)∂(ρAρ̂)/∂ρ + (1/ρ)∂Aφ̂/∂φ + ∂Az/∂z

(c) Laplacian of a scalar (no complications: I is invariant)

∂I/∂x = cos φ ∂I/∂ρ − (sin φ/ρ)∂I/∂φ.  (62)   Applying it twice, then doing the same for y and adding:

∇²I = ∂²I/∂ρ² + (1/ρ)∂I/∂ρ + (1/ρ²)∂²I/∂φ² + ∂²I/∂z²   (65)

These "brute-force chain rule" derivations are long. Sections 19–20 give a short general formula: div A = (1/√g)∂(√g Ai)/∂xi, with √g = ρ (cylindrical) or r² sin θ (spherical).

12. Why tensors? (Galilean invariance)

Ten scientists in ten labs each choose their own Cartesian axes. One finds the projectile's maximum height to be 2 m, so every other scientist must find 2 m too. One measures a magnetic field of 500 gauss pointing east, so the others must find the same vector, even though each writes different components. Experience says: physical phenomena do not depend on where you put the origin or how you orient your axes (the principle of Galilean invariance).

Consequence A physical law must keep its form in every frame. Laws written as tensor equations do this automatically:
if A…… = B…… in one system, then Ā = B̄ in every system
Reason: the difference C = A − B is a tensor. If all its components are 0 in one system, the transformation law (41) makes them 0 in every system. That is why only scalars, vectors and tensors can appear in physical laws, and both sides of an equation must be the same type.
  • Tensors are geometric objects; components are not. The vector u is the same in every frame. Only its components ui depend on the frame. The index notation hides this, but it shows the rank and type at a glance.
  • A vector space is defined by addition (the parallelogram law) and scalar multiplication. The arrow picture is only a helpful representation (Section 1).
  • Higher-rank tensors have no simple picture, so we must define them by their transformation law. This also protects us from "silly ideas", like picturing electron orbits too literally.
  • Sections 20–21 extend this from Galilean invariance in 3D space to Lorentz invariance in 4D spacetime.
Type check, a quick test for any equation Every term must have the same free indices, each at the same height. In ji = σijEj, both sides have free index i down ✓ (j is a dummy, once up and once down). Ai = Bi can only be true in special (Cartesian) frames.

14. Book's Exercise 15: all problems solved

1. Obtain the inverse transformations of Eqs. (37), (38), (39) and (41).
Show solution

Multiply each law by the inverse Jacobians and use (23). For (37): multiply by (∂xk/∂x̄α)(∂xl/∂x̄β) and sum over α, β. The factors combine into δkiδljAij = Akl. So:

Aij = (∂xi/∂x̄α)(∂xj/∂x̄β)Āαβ;   Aij = (∂x̄α/∂xi)(∂x̄β/∂xj)Āαβ;   Aij = (∂xi/∂x̄α)(∂x̄β/∂xj)Āαβ
Ai₁…ipj₁…jq = (∂xi₁/∂x̄α₁)…(∂xip/∂x̄αp)(∂x̄β₁/∂xj₁)…(∂x̄βq/∂xjq) Āα₁…αpβ₁…βq

Rule: swap the roles of barred and unbarred everywhere.

2. What is δii in N dimensions? Evaluate δijδji and δijδjkδki.
Show solution

δii = δ¹₁ + … + δNN = N. δijδji = δii = N (substitution). δijδjkδki = δikδki = δii = N. (In matrix language: Tr I = Tr I² = Tr I³ = N.)

3. Show (a) δijAik = Ajk; (b) δijδjkAkq = Aiq.
Show solution

(a) In the sum over i, only the term i = j survives (δ = 1 there, 0 elsewhere): ΣiδijAik = Ajk.
(b) First δijδjk = δik (sum over j), then δikAkq = Aiq. ∎

4. The Cartesian velocity components are dx/dt, dy/dt, dz/dt. Prove that its spherical components are dr/dt, dθ/dt, dφ/dt.
Show solution

Velocity is contravariant: v̄α = (∂x̄α/∂xi)(dxi/dt). By the chain rule this is exactly dx̄α/dt, since x̄α depends on t only through xi(t). Hence (vr, vθ, vφ) = (ṙ, θ̇, φ̇). ∎ (Physical components: ṙ, rθ̇, r sin θ φ̇.)

5. Find the components of acceleration in cylindrical coordinates (ρ, z, φ) and compare with the plane polar result of Example 4.
Show solution

x = ρ cos φ, y = ρ sin φ, z = z. The inverse Jacobian: ∂ρ/∂x = cos φ, ∂ρ/∂y = sin φ, ∂φ/∂x = −sin φ/ρ, ∂φ/∂y = cos φ/ρ, ∂z/∂z = 1.

ẍ = (ρ̈ − ρφ̇²)cos φ − (ρφ̈ + 2ρ̇φ̇)sin φ,   ÿ = (ρ̈ − ρφ̇²)sin φ + (ρφ̈ + 2ρ̇φ̇)cos φ.

aρ = cos φ ẍ + sin φ ÿ = ρ̈ − ρφ̇²;   aφ = (−sin φ ẍ + cos φ ÿ)/ρ = φ̈ + 2ρ̇φ̇/ρ;   az = z̈.

These are exactly Eq. (51) plus the trivial z̈. The z-direction is Cartesian and does not interact with the others.

6. Find the components of the gradient of a scalar field in plane polar coordinates. Also give the gradient in spherical coordinates.
Show solution

The gradient is covariant, and its components in any coordinates are simply the partial derivatives (Example 3b):

polar: (∂f/∂ρ, ∂f/∂φ);    spherical: (∂f/∂r, ∂f/∂θ, ∂f/∂φ)

Check in polar: Aφ = (∂x/∂φ)Ax + (∂y/∂φ)Ay = −ρ sin φ ∂f/∂x + ρ cos φ ∂f/∂y = ∂f/∂φ ✓.

The familiar textbook forms (∂f/∂ρ, (1/ρ)∂f/∂φ) and (∂f/∂r, (1/r)∂f/∂θ, (1/(r sin θ))∂f/∂φ) are the physical components, i.e. projections on unit vectors. Covariant components divided by the scale factors (hρ, hφ) = (1, ρ) and (hr, hθ, hφ) = (1, r, r sin θ) give the physical ones.

7. Show that the second derivatives Aij = ∂²f/∂xi∂xj of a scalar are not the components of a rank-2 tensor.
Show solution

Āαβ = ∂/∂x̄α(∂f/∂x̄β) = ∂/∂x̄α[(∂xj/∂x̄β)(∂f/∂xj)]

= (∂xi/∂x̄α)(∂xj/∂x̄β)(∂²f/∂xi∂xj) + (∂²xj/∂x̄α∂x̄β)(∂f/∂xj).

The first term is the tensor law (38). The second, extra term vanishes only if the transformation is linear (second derivatives of x(x̄) are zero). So Aij is not a tensor in general. ∎

Example: f = x in polar coordinates. ∂²f/∂x² = 0 in Cartesian, so if it were a tensor all its polar components would be 0. But f = ρ cos φ gives ∂²f/∂φ² = −ρ cos φ ≠ 0. (The cure is the covariant derivative of Section 19.)

8. Show that in spherical coordinates (a) div Ai = ∂Ar/∂r + ∂Aθ/∂θ + ∂Aφ/∂φ + 2Ar/r + cot θ Aθ; (b) div Ai = ∂Ar/∂r + (1/r²)∂Aθ/∂θ + (1/(r² sin²θ))∂Aφ/∂φ + 2Ar/r + (cot θ/r²)Aθ; (c) ∇²I = Irr + Iθθ/r² + Iφφ/(r² sin²θ) + 2Ir/r + (cot θ/r²)Iθ.
Show solution

Shortcut (justified in Section 20): div A = (1/√g) ∂(√g Ai)/∂xi with √g = r² sin θ.

(a) (1/(r² sin θ))[∂(r² sin θ Ar)/∂r + ∂(r² sin θ Aθ)/∂θ + ∂(r² sin θ Aφ)/∂φ] = ∂Ar/∂r + 2Ar/r + ∂Aθ/∂θ + cot θ Aθ + ∂Aφ/∂φ ✓.

(b) The same vector in covariant components: Ar = Ar, Aθ = Aθ/r², Aφ = Aφ/(r² sin²θ) (raising indices with the metric diag(1, r², r² sin²θ)). Substitute into (a). The r² in Aθ does not depend on θ, so ∂Aθ/∂θ = (1/r²)∂Aθ/∂θ. Result (b) ✓.

(c) ∇²I = div(grad I) with covariant Ai = ∂I/∂xi. Put Ar = Ir, Aθ = Iθ, Aφ = Iφ into (b) ✓. This is the standard spherical Laplacian, (1/r²)∂r(r²∂rI) + …, expanded.

Brute-force route (as in Example 5): write the Cartesian components in terms of the spherical ones via (27), express ∂/∂x, ∂/∂y, ∂/∂z through (45), and add. It is long but mechanical.

9. A fluid in a plane has vx = x², vy = y². Find the polar components of its velocity.
Show solution

vρ = (∂ρ/∂x)vx + (∂ρ/∂y)vy = cos φ·ρ²cos²φ + sin φ·ρ²sin²φ = ρ²(cos³φ + sin³φ).

vφ = (∂φ/∂x)vx + (∂φ/∂y)vy = (−sin φ/ρ)ρ²cos²φ + (cos φ/ρ)ρ²sin²φ = ρ sin φ cos φ (sin φ − cos φ).

17. Interesting facts

Einstein's "great discovery" Einstein reportedly joked that the summation convention was his great contribution to mathematics. It appeared in his 1916 general relativity paper, simply to stop writing hundreds of Σ signs.
The word "tensor" comes from the Latin tendere, "to stretch". It was first used for the stress tensor in elasticity (Woldemar Voigt, 1898), which describes how a material is stretched. Ricci and Levi-Civita built the general "absolute differential calculus" in 1900, and Einstein learned it from his friend Marcel Grossmann.
Graphite conducts electricity about 10,000 times better along its layers than across them. Its conductivity tensor is extremely anisotropic, so in graphite j can point far away from E (try σ₁/σ₂ large in Lab 1).
Effective mass In silicon the conduction electrons have effective masses of about 0.98 mₑ along one crystal axis and 0.19 mₑ across it. Push one sideways and it accelerates in a different direction. The mass tensor of Eq. (1a) is real physics, and it matters for transistor design.
Up and down indices = column and row vectors In matrix language a contravariant vector is a column, a covariant vector is a row (a "covector"), and AiBi is row × column = a number. Physicists' bra ⟨ψ| and ket |φ⟩ follow the same idea.
