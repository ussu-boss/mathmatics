0. Roadmap

A quadratic form is a polynomial where every term has degree exactly 2, such as 8x² + 2√2 xy + 7y². Any such polynomial can be written as xᵀAx with a symmetric matrix A. Once it is in that form, the eigenvalues and eigenvectors of A tell you everything:

  • what shape the curve or surface xᵀAx = c has (ellipse, hyperbola, ellipsoid, hyperboloid, …),
  • the directions of its axes (the eigenvectors),
  • the lengths of its axes (√(c/λ)),
  • whether the form is always positive (all λ > 0). In physics this is the question of whether energy has a minimum, i.e. whether there is a stable equilibrium.
polynomial→xᵀSx, S symmetric→rotate: y = Pᵀx→λ₁y₁² + λ₂y₂² + λ₃y₃²→read the shape
Needed from earlier x† = conjugate transpose (for real x it is just the transpose x̃ = xᵀ). A real symmetric matrix has real eigenvalues and orthonormal eigenvectors, so it is diagonalized by an orthogonal P: PᵀAP = Λ (Section 10). Orthogonal matrices are rotations (or reflections).

1. Bilinear form and quadratic form (Eqs. 1–5)

Definitions With x = {xi}, y = {yi} and A = [aij] (n×n):
Bilinear form:   B = Σi,j aij xi* yj = x†Ay   (1, 3)
Quadratic form:   Q = Σi,j aij xi* xj = x†Ax   (4)
The value of either one is a single number: (1×n)(n×n)(n×1) = 1×1.
  • "Bilinear": B is linear in y, and linear in x apart from complex conjugation. Doubling y doubles B.
  • "Quadratic": every term has degree 2 in the components of x. Doubling x multiplies Q by 4 (if x is real).
  • For n = 2 with real x: xᵀAx = a₁₁x₁² + (a₁₂ + a₂₁)x₁x₂ + a₂₂x₂². Only the sum a₁₂ + a₂₁ matters.

2. Every real quadratic form has a symmetric matrix (Eqs. 6–11)

For real x and real A, Q = xᵀAx is a number, so it equals its own transpose:

xᵀAx = (xᵀAx)ᵀ = xᵀÃx   (6)   ⇒   xᵀAx = ½(xᵀAx + xᵀÃx) = xᵀSx,   S = ½(A + Ã)  (7, 8)

So we can always replace A by its symmetric part S. The antisymmetric part K = ½(A − Ã) adds nothing, because xᵀKx = 0 for every x. (Proof: xᵀKx is a number, so it equals its transpose xᵀK̃x = −xᵀKx. A number equal to its own negative is 0.)

Fast recipe: polynomial ↔ symmetric matrix
  • Diagonal entry sii = coefficient of xi².
  • Off-diagonal sij = sji = half the coefficient of xixj.
Example: 8x² + 2√2 xy + 7y² ↔ [[8, √2], [√2, 7]].   3x² + 3y² − 4z² − 18xy ↔ [[3, −9, 0], [−9, 3, 0], [0, 0, −4]].

3. Hermitian forms (Examples 3, 4)

Definition If H is hermitian (H† = H), then Q = x†Hx is called a hermitian form. x may be real or complex.
Theorem (Example 3): a hermitian form is always real Q is a 1×1 matrix, so Q† = Q*.  (13)
Also Q† = (x†Hx)† = x†H†(x†)† = x†Hx = Q.  (14)
So Q* = Q, i.e. Q is real. ∎

Converse (Exercise 5): if x†Hx is real for every x, then H is hermitian. Antihermitian (Exercise 7): if A† = −A, the same steps give Q* = −Q, so Q is purely imaginary or 0.

Why physics cares: in quantum mechanics the expectation value ⟨ψ|H|ψ⟩ = ψ†Hψ is a hermitian form. It is real because observables are hermitian.

Worked Example 4 (book)

H =
ap − iqr − is
p + iqbu − iv

x†Hx = a|x₁|² + b|x₂|² + c|x₃|² + 2 Re[(p − iq)x₁*x₂ + (u − iv)x₂*x₃ + (r − is)x₁*x₃]  (16)

  • both λ > 0: a bowl (positive definite: Q > 0 except at 0)
  • both λ < 0: an upside-down bowl (negative definite)
  • opposite signs: a saddle (indefinite)
  • one λ = 0: a trough (semidefinite). Q = 0 along a whole line.

The coloured arrows on the floor are the eigenvectors. Along one the surface rises fastest (λmax), along the other slowest (λmin). On the unit circle, Q always stays between λmin and λmax.

5. Principal axis transformation in 2D (Eqs. 17–30)

Take A = [[a, h], [h, b]] real symmetric and x = (x₁, x₂)ᵀ real. The equation

xᵀAx = c   ⇔   ax₁² + 2hx₁x₂ + bx₂² = c   (18, 19)

is a conic section. The cross term 2hx₁x₂ means its axes are tilted relative to the coordinate axes.

Steps

  1. A is real symmetric, so there is an orthogonal P (columns = normalized eigenvectors) with PᵀAP = Λ = diag(λ₁, λ₂).  (20)
  2. Insert PPᵀ = I: xᵀAx = xᵀP(PᵀAP)Pᵀx = (Pᵀx)ᵀΛ(Pᵀx).  (21)
  3. New coordinates y = Pᵀx = P⁻¹x (a rotation).  (22)
  4. The equation becomes λ₁y₁² + λ₂y₂² = c, with no cross term:  (23a)
    y₁²/(c/λ₁) + y₂²/(c/λ₂) = 1   (23b)

All the cases

SignsCurve
c, λ₁, λ₂ all the same signellipse, semi-axes √(c/λ₁) and √(c/λ₂) (a circle if λ₁ = λ₂)
λ₁, λ₂ opposite signs, c ≠ 0hyperbola
λ₁, λ₂ opposite signs, c = 0pair of crossing straight lines (the asymptotes)
λ₁, λ₂ same sign, c opposite signimaginary curve (no real points)
λ₁, λ₂ same sign, c = 0a single point (the origin)
one λ = 0, other has the sign of cpair of parallel lines
one λ = 0, c = 0a single (double) line
one λ = 0, other opposite to cno real curve
Shortcut without eigenvalues λ₁λ₂ = det A = ab − h² and λ₁ + λ₂ = a + b. So for c > 0: ab − h² > 0 (and a > 0) gives an ellipse, ab − h² < 0 gives a hyperbola, ab − h² = 0 gives parallel lines. This is the familiar "h² − ab" test from coordinate geometry. The tilt angle satisfies tan 2θ = 2h/(a − b).

Worked Example 5 (book): 8x² + 2√2 xy + 7y² = 3

  1. A = [[8, √2], [√2, 7]].  (26)
  2. Characteristic equation: λ² − 15λ + (56 − 2) = λ² − 15λ + 54 = (λ − 9)(λ − 6) = 0 ⇒ λ = 9, 6.
  3. λ = 9: (8 − 9)x + √2 y = 0 ⇒ y = x/√2 ⇒ normalized (√(2/3), 1/√3).
    λ = 6: 2x + √2 y = 0 ⇒ (1/√3, −√(2/3)).  (27)
  4. P = [[√(2/3), 1/√3], [1/√3, −√(2/3)]],   y = Pᵀx.  (28, 29)
  5. 9x′² + 6y′² = 3 ⇒ 3x′² + 2y′² = 1, an ellipse.  (30)
  6. Semi-axes: along x′, 1/√3 ≈ 0.577 (minor); along y′, 1/√2 ≈ 0.707 (major).
  7. The major axis is along the eigenvector (1/√3, −√(2/3)) with slope −√2. So it makes the angle tan⁻¹(−√2) ≈ −54.7° with the x-axis.
Rule to remember The larger eigenvalue gives the shorter axis, because the semi-axis length is √(c/λ).

6. Quadric surfaces in 3D (Eqs. 31–42)

For x = (x₁, x₂, x₃)ᵀ and real symmetric A (3×3), xᵀAx = c is a surface. Let U be the orthogonal matrix of eigenvectors and y = Uᵀx. Then  (31–33)

y₁²/(c/λ₁) + y₂²/(c/λ₂) + y₃²/(c/λ₃) = 1   (34)

2 (one negative)hyperboloid of one sheet (a cooling-tower shape, connected)

In the first three cases the principal axes lie along the eigenvectors y₁, y₂, y₃.

Worked Example 6 (book): 3x² + 3y² − 4z² − 18xy + 12 = 0

  1. Rewrite as −3x² − 3y² + 4z² + 18xy = 12, i.e. xᵀAx = 12 with A = [[−3, 9, 0], [9, −3, 0], [0, 0, 4]].  (36, 37)
  2. The z-part is already separate, so λ = 4 with eigenvector (0, 0, 1). The 2×2 block [[−3, 9], [9, −3]] has λ = −3 ± 9, i.e. 6 with (1, 1)/√2 and −12 with (1, −1)/√2.  (38)
  3. P = [[1/√2, 0, 1/√2], [1/√2, 0, −1/√2], [0, 1, 0]] (columns for λ = 6, 4, −12).  (39)
  4. 6x′² + 4y′² − 12z′² = 12 ⇒ x′²/2 + y′²/3 − z′²/1 = 1.  (41)
  5. Two positive and one negative ⇒ hyperboloid of one sheet. Its axis (the direction it opens along) is z′ ∥ (1, −1, 0)/√2. The waist ellipse has semi-axes √2 and √3.

Direction cosines (42): x′ = (1/√2, 1/√2, 0), y′ = (0, 0, 1), z′ = (1/√2, −1/√2, 0).

7. Positive definite forms (Exercise 6 and beyond)

Definitions A real symmetric S (or its form xᵀSx) is positive definite if xᵀSx > 0 for every x ≠ 0; positive semidefinite if xᵀSx ≥ 0 for every x; indefinite if xᵀSx takes both signs.
Theorem For real symmetric (or hermitian) S:   S is positive definite ⇔ every eigenvalue of S is positive.
Proof: with y = Pᵀx (P orthogonal, so y ≠ 0 ⇔ x ≠ 0), xᵀSx = λ₁y₁² + … + λₙyₙ². This is > 0 for every y ≠ 0 ⇔ every λᵢ > 0. (For ⇒, take y = eᵢ.)
Why the book says "the converse is not necessarily true" For a non-symmetric A, the eigenvalues of A itself do not control xᵀAx. Only the eigenvalues of S = ½(A + Aᵀ) do.
  • A = [[1, 1], [−1, 1]]: xᵀAx = x² + y² > 0 for every x ≠ 0, but the eigenvalues of A are 1 ± i, which are not positive. So "positive form ⇒ positive eigenvalues" fails.
  • Even the forward direction can fail for non-symmetric A: A = [[1, 10], [0, 1]] has eigenvalues 1, 1, yet xᵀAx = x² + 10xy + y² = −8 at (1, −1).
The safe rule: first symmetrize, then look at the eigenvalues.

Quick tests for positive definiteness (symmetric S)

  • Sylvester's criterion: all leading principal minors are > 0. For [[a, h], [h, b]]: a > 0 and ab − h² > 0.
  • All eigenvalues > 0.
  • S = BᵀB with B invertible (e.g. a Cholesky factorization).
  • Necessary (not sufficient): every diagonal entry is > 0, and tr S > 0.

Extremes on the unit sphere (Rayleigh quotient)

For |x| = 1: λmin ≤ xᵀSx ≤ λmax. The extremes are reached at the corresponding eigenvectors, because xᵀSx = Σλᵢyᵢ² with Σyᵢ² = 1 is a weighted average of the λ's. This is a favourite NET question: "the maximum of 2x² + 2xy + 2y² on x² + y² = 1" is the largest eigenvalue of [[2, 1], [1, 2]], i.e. 3.

Physics

  • Kinetic energy T = ½ q̇ᵀMq̇ is a positive definite form (mass matrix M).
  • Potential near equilibrium: V ≈ ½ qᵀKq. The equilibrium is stable ⇔ K is positive definite. A saddle (indefinite K) means unstable.
  • Moment of inertia about the unit direction n is I(n) = nᵀIn. The surface xᵀIx = 1 is the inertia ellipsoid, and its principal axes are the principal axes of the body.
  • Exercise 9: V = (x−y)² + (y−z)² + (z−x)² is semidefinite (λ = 0, 3, 3). It stays at 0 along the line (1, 1, 1) and grows quadratically away from it.

9. Book's Exercise 11: all problems solved

1. For any matrix A and vector x, show that x̃Ax = x̃Ãx.
Show solution

x̃Ax is a 1×1 matrix (a number), so it equals its own transpose. Using (ABC)ᵀ = CᵀBᵀAᵀ and (x̃)ᵀ = x: (x̃Ax)ᵀ = x̃ Ã x. Hence x̃Ax = x̃Ãx. ∎

2. Write (a₁x₁ + a₂x₂ + … + aₙxₙ)² as x̃Ax with A symmetric. What is the rank of A?
Show solution

Let a = (a₁, …, aₙ)ᵀ. Then a₁x₁ + … + aₙxₙ = aᵀx, and its square is (aᵀx)(aᵀx) = (xᵀa)(aᵀx) = xᵀ(aaᵀ)x.

A = aaᵀ, i.e. aij = aiaj, which is symmetric. Every column is a multiple of a, so rank A = 1 (if a ≠ 0). Its eigenvalues are |a|² (eigenvector a) and 0 (n − 1 times).

3. u₁, …, uk, x are n-vectors. Show (ũ₁x)² + … + (ũkx)² = x̃UŨx, where U (n×k) has i-th column uᵢ.
Show solution

Ũx is the k-vector whose i-th entry is ũᵢx (row i of Ũ is ũᵢ). Then |Ũx|² = (Ũx)ᵀ(Ũx) = x̃UŨx = Σᵢ(ũᵢx)². ∎ Since UŨ is a sum of the rank-1 matrices uᵢũᵢ, this generalizes Exercise 2. The matrix UŨ is positive semidefinite.

4. A real symmetric, Ax = λx, Ay = μy, λ ≠ μ. Show x̃Ay = 0 and x ⊥ y.
Show solution

x̃Ay = x̃(μy) = μ x̃y. Also x̃Ay = (Ãx)ᵀy = (Ax)ᵀy = λ x̃y, since à = A. Subtracting: (λ − μ)x̃y = 0 ⇒ x̃y = 0 (as λ ≠ μ). Then x̃Ay = μ·0 = 0. ∎

5. If x†Hx is real for every x, show H is hermitian.
Show solution

Let K = H − H†. If x†Hx is real, then x†Hx = (x†Hx)* = (x†Hx)† = x†H†x, so x†Kx = 0 for all complex x.

Take x = eⱼ: kjj = 0. Take x = eⱼ + el: kjl + klj = 0. Take x = eⱼ + i el: i kjl − i klj = 0 ⇒ kjl = klj. Together kjl = 0, so K = 0, i.e. H = H†. ∎

The complex x are essential. For real x only, every real matrix with a real form would count, e.g. [[0, 1], [−1, 0]] gives 0, but it is not symmetric.

6. Show x†Ax > 0 for every x ≠ 0 if every eigenvalue of A is positive. Show the converse is not necessarily true.
Show solution

For A hermitian (the intended case): A = UΛU†, so x†Ax = y†Λy = Σλᵢ|yᵢ|² with y = U†x ≠ 0. If every λᵢ > 0, this is > 0. ∎

Converse fails for non-hermitian A: A = [[1, 1], [−1, 1]] gives xᵀAx = x₁² + x₂² > 0 for every real x ≠ 0, but its eigenvalues 1 ± i are not positive (not even real). For real symmetric A the converse does hold (take x = eigenvector). See Section 7 for the full picture.

7. A antihermitian ⇒ x†Ax purely imaginary or zero.
Show solution

Q = x†Ax ⇒ Q* = Q† = x†A†x = −x†Ax = −Q. So Re Q = 0. ∎ (Alternatively, A = iH with H hermitian, so Q = i·(real).)

8. Interpret x̃Ax = c geometrically for (a) A = [[0, 1, 1], [1, 0, 1], [1, 1, 0]], c = 4; (b) A = [[2.6, −0.2, 0.2], [0.2, 2.1, 0.4], [0.4, 0.2, 2.8]], c = 15.
Show solution (a)

The form is 2(xy + yz + zx) = 4. A = J − I (J = all ones). The eigenvalues of J are 3, 0, 0, so A has 2, −1, −1. Eigenvector for 2: (1, 1, 1)/√3. For −1: any vector ⊥ (1, 1, 1).

Principal form: 2y₁² − y₂² − y₃² = 4 ⇒ y₁²/2 − y₂²/4 − y₃²/4 = 1. One positive, two negative ⇒ hyperboloid of two sheets. It is a surface of revolution about the line x = y = z, with vertices at distance √2 from the origin along (1, 1, 1)/√3, i.e. at ±(√2/√3)(1, 1, 1). Check: at (a, a, a), 2·3a² = 4 ⇒ a² = 2/3 ✓.

Show solution (b)

A is not symmetric, so use S = ½(A + Ã) = [[2.6, 0, 0.3], [0, 2.1, 0.3], [0.3, 0.3, 2.8]]. Its eigenvalues are approximately 1.969, 2.451, 3.080, all positive. With c = 15 > 0 the surface is an ellipsoid.

Semi-axes √(15/λ): ≈ 2.760, 2.474, 2.207, along the eigenvectors ≈ (−0.19, −0.90, 0.39), (−0.84, 0.35, 0.42), (0.51, 0.25, 0.82). It is nearly a sphere of radius ≈ 2.4, slightly squashed. (Load "Ex 8(b)" in Lab 3.)

The printed numbers do not give tidy eigenvalues for any symmetric reading. That is a sign of a misprint, but the geometric answer (ellipsoid) is the same either way, because all the eigenvalues stay close to 2–3.

9. V(r) = (x−y)² + (y−z)² + (z−x)². Show there is a line along which V is constant, and that V increases as the particle moves away from it.
Show solution

Expand: V = 2x² + 2y² + 2z² − 2xy − 2yz − 2zx = rᵀKr with K = [[2, −1, −1], [−1, 2, −1], [−1, −1, 2]] = 3I − J.

The eigenvalues of J are 3, 0, 0, so K has 0, 3, 3. For λ = 0 the eigenvector is (1, 1, 1)/√3. For λ = 3, any vector ⊥ (1, 1, 1).

In principal coordinates, V = 0·y₁² + 3y₂² + 3y₃² = 3(y₂² + y₃²) = 3 d², where d = distance from the line x = y = z.

On the line (d = 0), V = 0 is constant. Moving away, V = 3d² grows with distance. This is a "trough" potential (positive semidefinite). ∎

P4. Maximum and minimum of 3x² + 2xy + 3y² on x² + y² = 1? Rayleigh

Eigenvalues of [[3, 1], [1, 3]]: 4 and 2. max 4 at (1, 1)/√2, min 2 at (1, −1)/√2.

P5. For which k is x² + 2kxy + 4y² positive definite? definite
Show solution

Leading minors: 1 > 0 and 4 − k² > 0 ⇒ |k| < 2. At k = ±2 it is semidefinite: (x ± 2y)².

P6. Is S = [[2, −1, 0], [−1, 2, −1], [0, −1, 2]] positive definite? Sylvester

Minors: 2, 4 − 1 = 3, det = 2·3 − (−1)(−2) = 4. All positive ⇒ yes. (Eigenvalues 2 − √2, 2, 2 + √2.)

12. Interesting facts

Sylvester's law of inertia (1852) However you diagonalize a real quadratic form, by any invertible change of variables and not just rotations, the number of positive, negative and zero coefficients never changes. Sylvester called this triple the "inertia" of the form. Only the rotation method also keeps the axis lengths.
The name "principal axes" comes from rigid-body mechanics: Euler found that every body has three perpendicular axes about which it can spin without wobbling. They are the eigenvectors of the inertia tensor, i.e. the principal axes of the inertia ellipsoid.
Cooling towers are hyperboloids of one sheet. The surface is "doubly ruled": two families of straight lines lie completely inside it. So it can be built from straight steel beams, yet it is curved and strong.
Special relativity uses the indefinite form x² + y² + z² − c²t² (signature +++−). The light cone is the "cone" case c = 0 of Section 6. Lorentz transformations are exactly the linear maps that preserve this form, just as rotations preserve x² + y² + z².
The Hessian test for maxima and minima of f(x, y) is this chapter in disguise: near a critical point f ≈ f₀ + ½ xᵀHx, so a positive definite Hessian gives a minimum and an indefinite one a saddle.
