0. Roadmap

Special matrices get their names from conditions on their elements. Each condition removes some freedom, so this section also teaches you to count independent parameters, a favourite CSIR-NET/GATE question. Every special matrix is defined by one of two kinds of condition:

  • a pattern of zeros (diagonal, scalar, triangular), or
  • a relation between A and A*, Ã, A† (real, imaginary, symmetric, antisymmetric, Hermitian, antiHermitian).
Square, diagonal, scalar, I→Who commutes with them?→6 types from A*, Ã, A†→Unique decompositions→Triangular→Counting parameters→Independent matrices, Pauli basis→Polynomial matrices→Trace
Names to know A "constant matrix" (book) is the same as a scalar matrix aI. "Right-triangular" (book) is upper triangular, and "left-triangular" is lower triangular. "Spur" (German) or "diagonal sum" means the trace. AntiHermitian is the same as skew-Hermitian, and antisymmetric is the same as skew-symmetric.

1. Square, diagonal, scalar (constant) and unit matrices

Definitions
  • Square matrix of order n: m = n. Its principal diagonal consists of a₁₁, a₂₂, …, aₙₙ (from top-left to bottom-right). All the other elements aᵢⱼ (i ≠ j) are off-diagonal.
  • Diagonal matrix: all off-diagonal elements are zero, so (A)ᵢⱼ = aᵢᵢδᵢⱼ. It is written diag(a₁₁, …, aₙₙ). (Some diagonal entries may also be zero.)
  • Constant (scalar) matrix: a diagonal matrix with all diagonal elements equal, (A)ᵢⱼ = aδᵢⱼ, i.e. A = aI.
  • Unit (identity) matrix: a = 1, (I)ᵢⱼ = δᵢⱼ. Iₙ is the identity of order n.
square⊃diagonal⊃scalar aI⊃I (a = 1) and 0 (a = 0)
Arithmetic of diagonal matrices
  • diag(aᵢ) + diag(bᵢ) = diag(aᵢ + bᵢ), diag(aᵢ)·diag(bᵢ) = diag(aᵢbᵢ). Diagonal matrices always commute with each other.
  • diag(aᵢ)ᵏ = diag(aᵢᵏ), and diag(aᵢ)⁻¹ = diag(1/aᵢ) (if no aᵢ = 0). det = Πaᵢ, Tr = Σaᵢ.
  • D·A scales the rows of A, and A·D scales the columns: (DA)ᵢⱼ = dᵢaᵢⱼ and (AD)ᵢⱼ = aᵢⱼdⱼ.
  • The scalar matrix aI behaves exactly like the number a: (aI)A = A(aI) = aA.

2. Who commutes with diagonal and constant matrices?

Book Example 1 If B commutes with a diagonal matrix A = diag(a₁, …, aₙ) whose diagonal elements are all different, then B is diagonal.

Proof: (AB)ᵢⱼ = aᵢbᵢⱼ and (BA)ᵢⱼ = bᵢⱼaⱼ. Equating them gives (aᵢ − aⱼ)bᵢⱼ = 0. For i ≠ j, aᵢ ≠ aⱼ, so bᵢⱼ = 0. ∎

Book Example 2 Let Ekl be the matrix with 1 in position (k,l) and 0 elsewhere, (Ekl)ᵢⱼ = δᵢₖδⱼₗ. There are n² of them. If B commutes with Ekl for all k (and one fixed l), then B is a constant matrix.

Proof: (BEkl)ᵢⱼ = bᵢₖδⱼₗ and (EklB)ᵢⱼ = δᵢₖbₗⱼ. Put j = l: bᵢₖ = δᵢₖbₗₗ. So the off-diagonal bᵢₖ are 0 and every diagonal element equals bₗₗ. Hence B = bₗₗI. ∎

⚡ What it means (a very common exam fact)
  • Only scalar matrices commute with every matrix. (This is the matrix version of Schur's lemma.)
  • If some diagonal entries of A are equal, B may have nonzero entries in the corresponding block. For A = diag(1, 1, 2), the matrices commuting with A have the form . In QM this is degeneracy: inside a degenerate block, you can mix states freely.
  • Matrices commuting with σ_z = diag(1, −1) are diagonal. Matrices commuting with σₓ have the form .

4. Unique decompositions

Three ways to split any matrix (each is unique)
A = ½(A + A*) + ½(A − A*) (real + purely imaginary; any m×n)
A = ½(A + Ã) + ½(A − Ã) (symmetric + antisymmetric; square)
A = ½(A + A†) + ½(A − A†) (Hermitian + antiHermitian; square)

Book Example 3 (two proofs that the Hermitian + antiHermitian split exists and is unique)

Element method: suppose A = B + C with B† = B and C† = −C. Element-wise, aᵢⱼ = bᵢⱼ + cᵢⱼ. Take the dagger of A = B + C to get A† = B − C, i.e. aⱼᵢ* = bᵢⱼ − cᵢⱼ. Adding and subtracting gives bᵢⱼ = (aᵢⱼ + aⱼᵢ*)/2 and cᵢⱼ = (aᵢⱼ − aⱼᵢ*)/2. These are uniquely fixed by A, and one checks bⱼᵢ* = bᵢⱼ and cⱼᵢ* = −cᵢⱼ.

Matrix method (shorter): A = B + C and A† = B − C give B = (A + A†)/2 and C = (A − A†)/2. Then B† = (A† + A)/2 = B and C† = (A† − A)/2 = −C. ∎

The book's lesson: there are two ways to prove matrix identities, (1) element by element and (2) with matrix operations. The second is shorter and more elegant. Use it whenever you can.

⚡ Also write it as A = H₁ + iH₂ with both H's Hermitian H₁ = (A + A†)/2 and H₂ = (A − A†)/(2i). This is the matrix analogue of z = x + iy, and "Hermitian ↔ real numbers, antiHermitian ↔ imaginary numbers" is a good guide in general.

5. Book Example 4: x̃Ax = 0 for antisymmetric A

If A is antisymmetric (Ã = −A) and x is any column vector, then the number x̃Ax = Σᵢⱼ aᵢⱼxᵢxⱼ = 0.

Proof 1 (elements): swap the dummy indices i ↔ j: Σ aᵢⱼxᵢxⱼ = Σ aⱼᵢxⱼxᵢ = −Σ aᵢⱼxᵢxⱼ. A number equal to its own negative is 0.

Proof 2 (matrices): x̃Ax is 1×1, so it equals its own transpose: x̃Ax = (x̃Ax)ᵀ = x̃Ãx = −x̃Ax ⇒ 0.

Variations (all from the same trick)
  • A quadratic form only sees the symmetric part: x̃Ax = x̃Sx with S = ½(A + Ã). So when quadratic forms come up (Section 11), always symmetrise first.
  • Hermitian H: x†Hx is real. (Proof: (x†Hx)* = (x†Hx)† = x†H†x = x†Hx.) So expectation values ⟨ψ|H|ψ⟩ are real.
  • AntiHermitian K: x†Kx is purely imaginary.
  • Geometrically, for real antisymmetric A, the vector Ax is always perpendicular to x. That is the property of a magnetic force qv × B: it does no work.
  • Tr(SK) = 0 when S is symmetric and K is antisymmetric. (Proof: Tr(SK) = Tr((SK)ᵀ) = Tr(KᵀSᵀ) = −Tr(KS) = −Tr(SK).)

6. Triangular matrices

Definition A square matrix is triangular if all the elements on one side of the principal diagonal vanish.
  • Right- (upper) triangular: aᵢⱼ = 0 for i > j, e.g. .
  • Left- (lower) triangular: aᵢⱼ = 0 for i < j, e.g. .
  • Strictly triangular: also zero on the diagonal. Such a matrix is nilpotent, Nⁿ = 0.
Properties
  • A product of two upper (lower) triangular matrices is upper (lower) triangular. So are all their powers (Exercise 12).
  • The diagonal of the product is the product of the diagonals: (T₁T₂)ᵢᵢ = (T₁)ᵢᵢ(T₂)ᵢᵢ. Hence the diagonal of Tᵏ is tᵢᵢᵏ (Exercise 18).
  • det T = t₁₁t₂₂⋯tₙₙ. The eigenvalues of T are its diagonal entries (Section 9).
  • The inverse of an invertible upper triangular matrix is upper triangular, with diagonal 1/tᵢᵢ.
  • The transpose of an upper triangular matrix is lower triangular. A matrix that is both upper and lower triangular is diagonal.
  • Upper triangular n×n matrices form a vector space of dimension n(n+1)/2.

7. Counting independent (real) parameters

The rule A general complex m×n matrix has 2mn real parameters (each element has a real and an imaginary part). For a special matrix:
number of independent real parameters = 2mn − (number of independent real conditions)
Or count directly: list the elements you are free to choose, and how many real numbers each one costs.

Book's method, shown for a complex symmetric matrix

Direct count: only the elements with i ≤ j are free. There are 1 + 2 + … + n = n(n+1)/2 of them, each complex, giving n(n+1) real parameters.

Conditions count: aᵢⱼ = aⱼᵢ for i < j is n(n−1)/2 complex equations, i.e. n(n−1) real conditions. Then 2n² − n(n−1) = n(n+1) ✓.

8. Linearly independent matrices and linear combinations

Definition (as for vectors, Section 1) Matrices A₁, …, A_p of the same order are linearly independent if Σcᵢ Aᵢ = 0 forces all cᵢ = 0. Otherwise they are dependent, and at least one of them is a linear combination of the others: A_k = −Σi≠k(cᵢ/c_k)Aᵢ. For two matrices, dependent means A₁ = cA₂.

Book Example 6: the standard basis Ekl

(a) The mn matrices Ekl (1 at (k,l), 0 elsewhere) are independent: Σ aklEkl is the matrix whose (k,l) entry is akl. That is zero only if every akl = 0.
(b) Any B = [bᵢⱼ] equals Σ bklEkl. So mn is the maximum number of independent m×n matrices, and {Ekl} is a basis.

Real vs complex coefficients: a subtle point (handle it carefully)

The book's rule: for a type of special matrix, the maximum number of independent matrices equals the number of real parameters if only real coefficients are allowed, and half of it if complex coefficients are allowed. This works for types that stay inside the type when multiplied by complex numbers (complex symmetric, antisymmetric, triangular, …). For example, symmetric matrices have n(n+1) real parameters, so there are n(n+1)/2 independent ones over ℂ.

Hermitian matrices are different: iH is not Hermitian, so Hermitian matrices form a vector space only over ℝ, of dimension n². Remarkably, n² independent Hermitian matrices (such as I, σₓ, σᵧ, σ_z) stay independent even with complex coefficients, and they then span all n×n complex matrices. That is why the book's answer for Hermitian is n² in both cases.

10. Matrices with polynomial elements

If every element fᵢⱼ(x) of an m×n matrix is a polynomial of degree ≤ p, the matrix can be written uniquely as

A(x) = B₀ + B₁x + B₂x² + … + B_p x^p, with (B_k)ᵢⱼ = coefficient of x^k in fᵢⱼ(x)

(Uniqueness follows because the coefficients of a polynomial are unique.) This form is used in the proof of the Cayley–Hamilton theorem (Section 12).

11. The trace (Spur, diagonal sum)

Tr A = Sp A = Σᵢ aᵢᵢ
Book Example 9: the trace is invariant under cyclic permutations

For A (m×n) and B (n×m): Tr(AB) = Σᵢ Σⱼ aᵢⱼbⱼᵢ and Tr(BA) = Σⱼ Σᵢ bⱼᵢaᵢⱼ, which is the same double sum. So Tr(AB) = Tr(BA), even though AB is m×m and BA is n×n.

For k matrices, put C = A₁⋯A_r and D = A_{r+1}⋯A_k. Then Tr(CD) = Tr(DC) gives Tr(A₁A₂⋯A_k) = Tr(A_{r+1}⋯A_kA₁⋯A_r). ∎

Only cyclic permutations work. Tr(ABC) = Tr(BCA) = Tr(CAB), but in general Tr(ABC) ≠ Tr(ACB) (e.g. with Pauli matrices: 2i vs −2i).

2. Show (a) every matrix is uniquely real + purely imaginary; (b) every square matrix is uniquely symmetric + antisymmetric.
Show solution

(a) Suppose A = R + P with R* = R (real) and P* = −P (purely imaginary). Conjugating gives A* = R − P. So R = (A + A*)/2 and P = (A − A*)/2 are forced (uniqueness), and these choices do work (existence).

(b) A = S + K with S̃ = S and K̃ = −K. Transposing gives Ã = S − K, so S = (A + Ã)/2 and K = (A − Ã)/2. This is the same argument as Example 3, with ~ in place of †.

3. If A and B are both symmetric, or both antisymmetric, show that BA is the transpose of AB.
Show solution

(AB)ᵀ = B̃Ã. Both symmetric: B̃Ã = BA. Both antisymmetric: B̃Ã = (−B)(−A) = BA. Either way, (AB)ᵀ = BA. Consequently AB is symmetric ⇔ AB = BA.

4. (a) The sum of Hermitian matrices is Hermitian. (b) The product of two Hermitian matrices is Hermitian ⇔ they commute.
Show solution

(a) (A + B)† = A† + B† = A + B.

(b) (AB)† = B†A† = BA. So (AB)† = AB ⇔ BA = AB. (Both directions are covered: if they commute, AB is Hermitian, and if AB is Hermitian, they commute.)

5. (a) For Hermitian A, B, when is aA + bB Hermitian? (b) For antiHermitian A, B, when is aA + bB antiHermitian?
Show solution

(a) (aA + bB)† = a*A + b*B. This equals aA + bB for every Hermitian A and B ⇔ a* = a and b* = b, i.e. a and b are real. (Take B = 0 and A = I to see that a* = a is needed.)

(b) (aA + bB)† = −(a*A + b*B), which must equal −(aA + bB). Again ⇔ a and b are real.

6. H₁ is Hermitian and H₂ is antiHermitian. Show H₁ + iH₂ and H₁ − iH₂ are Hermitian.
Show solution

(iH₂)† = −iH₂† = −i(−H₂) = iH₂, so iH₂ is Hermitian. Then H₁ ± iH₂ is a sum (or difference) of Hermitian matrices, hence Hermitian.

9. I, A = , B = ½, C = ½, D = ½, F = ½. Show (a) A² = B² = C² = I, (b) AB = D, (c) AC = BA = F.
Show solution

(a) A² = I is clear. B² = ¼ = I, and C² = I similarly.

(b) AB: A flips the sign of row 2 of B, so AB = ½ = D ✓.

(c) AC = ½ = F ✓. BA: A on the right flips the sign of column 2 of B, so BA = ½ = F ✓.

Meaning: A, B, C are reflections in three mirror lines 60° apart, and D, F are rotations by ∓120°. Together with I, these 6 matrices form a group: the symmetry group of an equilateral triangle (S₃ ≅ C₃ᵥ), the smallest non-abelian group. Check: D³ = I and DF = I.

17. Interesting facts

  • Charles Hermite (1855) introduced Hermitian forms while studying number theory, long before quantum mechanics made them famous.
  • The "only scalar matrices commute with everything" fact is a baby version of Schur's lemma, the cornerstone of group representation theory: in an irreducible representation, any matrix that commutes with all the group matrices is a multiple of I. Degeneracies in QM come from this.
  • Counting parameters gives Lie group dimensions: U(n) has n² parameters (from Hermitian generators), SU(n) has n² − 1 (traceless), and SO(n) has n(n−1)/2 (real antisymmetric). So SU(2) has 3 parameters (spin), SU(3) has 8 (gluons) and SO(3) has 3 (rotations).
  • The 2×2 Hermitian matrices form a real 4-dimensional space, the same as spacetime: x^μ ↔ x⁰I + x·σ, with det = (x⁰)² − |x|², the Minkowski interval. This is how SL(2,ℂ) describes Lorentz transformations.
  • Book Exercise 9's six matrices are the symmetry group of NH₃ and of an equilateral triangle, the first example in any group-theory course.
  • "Spur" is the German word for trace, which is why old physics papers write Sp A.
