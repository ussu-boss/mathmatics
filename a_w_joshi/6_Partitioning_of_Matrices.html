0. Roadmap

A big matrix can be cut into smaller rectangular pieces called blocks. You can then treat each block as if it were a single number and do algebra with the blocks. The answer is the same as working element by element. It is often much shorter, and it shows the structure.

Cut into blocks→Add block by block→Multiply block by block (cuts must match)→Inverse from smaller inverses→Submatrices→Rank
Key idea in one line Block algebra works exactly like ordinary 2×2 algebra, with one warning: blocks are matrices, so they don't commute. Keep the order of every product, and never divide; multiply by an inverse on the correct side instead.
Needed from earlier Matrix product (Section 2), inverse and the reverse-order rule (AB)⁻¹ = B⁻¹A⁻¹ (Section 5), determinants and minors (Section 4).

1. Partitioning a matrix into blocks (Eqs. 1–3)

Take an m×n matrix A. Draw one horizontal line after row k and one vertical line after column l. You get four blocks:

A =    A₁: k×l,  A₂: k×(n−l),  A₃: (m−k)×l,  A₄: (m−k)×(n−l)

  • The cuts can go anywhere (1 ≤ k ≤ m, 1 ≤ l ≤ n), and you can use any number of cuts, not just one each way.
  • Blocks in the same block-row have the same number of rows. Blocks in the same block-column have the same number of columns.
  • Two matrices of the same size cut at the same places are identically partitioned.
  • Extreme cases: no cuts gives one block, A itself. Cutting after every row and column makes every block a 1×1 element, which is ordinary element-wise work. Cutting only into columns gives A = [a₁ a₂ … aₙ] (a list of column vectors). Cutting only into rows gives a stack of row vectors.

3. Block multiplication (Eqs. 5–8)

Rule A is m×n and B is n×p. If the column cuts of A are at the same places as the row cuts of B (the partitions are conformable), then
=
It is the ordinary 2×2 product formula with the order kept: A₁B₁, never B₁A₁.

Why it works: element (i, j) of AB is ∑ₖ aᵢₖbₖⱼ. Split the sum over k into k ≤ l and k > l. The first part is an element of A₁B₁ (or A₃B₁, …) and the second part is an element of A₂B₃ (or A₄B₃, …). Nothing else is going on.

Which cuts are free? The row cuts of A (giving k, m−k) and the column cuts of B (giving t, p−t) can be anywhere. They just become the row and column cuts of AB. Only the "inner" cut, A's columns against B's rows, must match.

5. Inverse by partitioning: Book Example 1 (Eqs. 9–14)

Let M = with A: m×m, B: m×n, C: n×m, D: n×n. M is square of order m + n. B and C are rectangular, so B⁻¹ and C⁻¹ do not exist. The answer may use only A⁻¹, D⁻¹ and inverses of square combinations.

Derivation, step by step

Guess the inverse in the same block shape, Z = . Then MZ = I gives:

The inverse of a large matrix comes from inverses of smaller ones.
Schur complements (modern name) M/A = D − CA⁻¹B is the Schur complement of A, and M/D = A − BD⁻¹C is the Schur complement of D. The diagonal blocks of M⁻¹ are just their inverses. Memory aid: "the other diagonal block, minus (off-diagonal)(inverse)(off-diagonal)", with the three factors in the order that makes the sizes fit.

Special cases and checks

  • 1×1 blocks (numbers a, b, c, d): P = 1/(a − bc/d) = d/(ad − bc), Q = −(b/a)·a/(ad − bc) = −b/(ad − bc), and so on. This is exactly the familiar 2×2 inverse. ✓
  • B = 0 or C = 0 gives the block-triangular inverses of Section 4. B = C = 0 gives diag(A⁻¹, D⁻¹).
  • Version needing only A⁻¹ (use when D is singular): S = (M/A)⁻¹, Q = −A⁻¹BS, R = −SCA⁻¹, P = A⁻¹ + A⁻¹BSCA⁻¹.
  • Comparing the two forms of P gives the Woodbury identity: (A − BD⁻¹C)⁻¹ = A⁻¹ + A⁻¹B(D − CA⁻¹B)⁻¹CA⁻¹.
Careful The formula needs the Schur complements (and A, D) to be invertible. M can be invertible even when A or D is singular. Example: M = has A = D = 0. Then you must use the other version, or reorder the blocks.

Factorise M (block LDU, "block Gaussian elimination"):

=
Schur determinant formula
det M = det A · det(D − CA⁻¹B) = det D · det(A − BD⁻¹C)
If CD = DC (C, D same size, A, B too): det M = det(AD − BC). Compare with ad − bc, but note the order AD − BC.

Use: 4×4 determinants become two 2×2 determinants. It also shows M is invertible ⇔ the Schur complement is invertible (when A is).

7. Submatrices and rank (Eq. 15, Example 2)

Submatrix Any matrix obtained from A by deleting some rows and/or some columns. Every block of a partition is a submatrix, but submatrices don't need to be made of adjacent rows or columns.

For A = (Eq. 15), some submatrices are , (rows 1–2, columns 1 and 3), [3 5 1], [9], …

How many square k×k submatrices does an m×n matrix have? C(m,k)·C(n,k). For a 4×4 matrix: 16 of order 3, 36 of order 2, 16 of order 1.

Rank (book's definition) A has rank r if it has at least one nonsingular r×r submatrix, but every square submatrix of order greater than r is singular.
In words: rank = the size of the largest nonzero minor.

Facts about rank

  1. 0 ≤ rank A ≤ min(m, n). Only the zero matrix has rank 0.
  2. rank Aᵀ = rank A, because det of a square submatrix is unchanged by transposition. Same for A* and A†.
  3. Square n×n: nonsingular ⇔ rank = n (full rank). Singular ⇔ rank < n.
  4. Rank = the maximum number of linearly independent rows = the same for columns (this is proved later in the book, Example 8.7). This gives a much faster method: row-reduce and count the nonzero rows.
  5. Elementary row and column operations don't change the rank.
  6. rank(AB) ≤ min(rank A, rank B). Multiplying by a nonsingular matrix doesn't change the rank.
  7. Rank 1 ⇔ A = (column)(row) = uvᵀ, with u, v nonzero. Every row is a multiple of one row.

8. Feel the rank: a 3D picture

Think of the three rows of a 3×3 matrix as three arrows in space. They span a box (a parallelepiped). Its volume is |det|.

  • Rank 3: the box has real volume. The rows point in three independent directions.
  • Rank 2: the box is flat, because all three arrows lie in one plane. det = 0, but some 2×2 minor is nonzero.
  • Rank 1: all arrows lie on one line. All 2×2 minors are zero too.

9. Where block matrices appear in physics

  • Dirac matrices are written in 2×2 blocks of Pauli matrices: β = , αᵢ = . Products like αᵢαⱼ are computed block-wise using σᵢσⱼ.
  • Symmetry ⇒ block diagonal. If a Hamiltonian commutes with a symmetry, then in a symmetry-adapted basis it is block diagonal. Each block can be diagonalised separately (group theory, molecular orbitals).
  • Coupled systems: two subsystems with coupling B: H = . The Schur complement H₁ + B(E − H₂)⁻¹B† is the "effective Hamiltonian" (Löwdin partitioning, self-energy).
  • Hamilton's equations use the block matrix J = (symplectic form). The Lorentz group, and ABCD transfer matrices in optics, are other block examples.
  • Numerical computing: fast matrix multiplication on computers works in blocks (tiles) that fit in the cache. Strassen's algorithm is a clever 2×2 block trick: 7 block products instead of 8.

14. Interesting facts

Schur and the Schur complement Issai Schur studied determinants of block matrices in 1917, but the name "Schur complement" was coined only in 1968 by Emilie Haynsworth. Today it appears in statistics (conditional covariance of Gaussians), circuit theory (Kron reduction), and finite-element methods.
Strassen's 7 multiplications Multiplying 2×2 block matrices normally needs 8 block products. In 1969 Strassen found a way with only 7. Applied recursively, this multiplies n×n matrices in about n^2.81 operations instead of n³.
Conditional Gaussians If a Gaussian vector has covariance [[Σ₁₁, Σ₁₂],[Σ₂₁, Σ₂₂]], the covariance of part 1 given part 2 is exactly the Schur complement Σ₁₁ − Σ₁₂Σ₂₂⁻¹Σ₂₁. This is block matrices in statistics.
Rank in data A large data table that is "nearly rank k" can be stored as a product of a tall and a wide matrix. This is the idea behind image compression with the SVD and behind recommendation systems.
Block-diagonal = decoupled Whenever a physics matrix becomes block diagonal, the system has split into independent subsystems that don't talk to each other. Finding that basis is what "using symmetry" really means.
