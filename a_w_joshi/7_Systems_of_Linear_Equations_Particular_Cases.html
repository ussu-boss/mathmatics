0. Roadmap

Question of this section: given some linear equations, are there no solutions, exactly one, or infinitely many? We answer it by building up slowly: 1 unknown, then 2 (lines in a plane), then 3 (planes in space). Every time, the answer depends on a determinant, and more generally on ranks. At the end comes Cramer's rule, which gives the unique solution as a ratio of determinants.

ax = b→2 lines→3 lines→planes in 3D→rank A vs rank [A|b]→Cramer: xₖ = Dₖ/det A
The one picture to keep in mind Each linear equation is a line (2 unknowns) or a plane (3 unknowns). A solution is a point lying on all of them at once. Count the common points: 0, 1 or ∞. These are the only possibilities. A linear system can never have exactly 2 solutions.

1. The general system and some words (Eqs. 1–3)

A linear equation in x₁,…,xₙ has no powers higher than 1, no products xᵢxⱼ, and constant coefficients. m such equations in n unknowns:

a₁₁x₁ + a₁₂x₂ + … + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + … + a₂ₙxₙ = b₂
  ⋮
aₘ₁x₁ + aₘ₂x₂ + … + aₘₙxₙ = bₘ   ⟺   Ax = b

A is m×n (the coefficient matrix), x is n×1, b is m×1.

WordMeaning
Homogeneousb = 0 (every bᵢ = 0)
Inhomogeneousb ≠ 0 (at least one bᵢ ≠ 0)

Nontrivial solutiona solution with at least one xᵢ ≠ 0

2. One equation in one unknown: ax = b (Eq. 4)

The school answer "x = b/a" fails when a = 0. The full list of cases:

CaseConditionSolutions
1aa ≠ 0, b = 0exactly one: x = 0 (trivial)
1ba ≠ 0, b ≠ 0exactly one: x = b/a ≠ 0
2aa = 0, b ≠ 0none (0·x = b is impossible)
2ba = 0, b = 0infinitely many: every x works
The four lessons (they hold for every size of system)
  1. "Coefficient nonzero" (a ≠ 0, later det A ≠ 0) ⇒ unique solution.
  2. Unique and homogeneous ⇒ only the trivial solution.
  3. "Coefficient zero" ⇒ either no solution or infinitely many.
  4. A homogeneous equation has a nontrivial solution ⇔ the coefficient is zero (a = 0, later det A = 0).

Several equations, one unknown (Eq. 5): a₁x = b₁, …, aₘx = bₘ. If some aᵢ = 0 with bᵢ ≠ 0, there is no solution. Otherwise solve any one equation and check it in all the others. A solution exists ⇔ b₁/a₁ = b₂/a₂ = … = bₘ/aₘ. More equations than unknowns usually means no solution, unless the equations happen to agree.

3. Two equations in two unknowns: two lines (Eqs. 6–15, Fig. 3)

a₁₁x₁ + a₁₂x₂ = b₁
a₂₁x₁ + a₂₂x₂ = b₂    det A = a₁₁a₂₂ − a₁₂a₂₁

Case 1: det A ≠ 0 → exactly one solution

x₁ = (b₁a₂₂ − b₂a₁₂)/det A,    x₂ = (b₂a₁₁ − b₁a₂₁)/det A   (Eq. 8)
  • 1a: b = 0 → only x₁ = x₂ = 0. Two lines through the origin cross only there.
  • 1b: b ≠ 0 → one nontrivial solution. Two lines with different slopes cross at one point.

Case 2: det A = 0 → the lines are parallel (same slope)

det A = 0 ⇔ a₁₁/a₁₂ = a₂₁/a₂₂ (Eq. 15): equal slopes. Then the second equation's left side is a multiple of the first's. Everything depends on whether the right side follows the same multiple:

  • 2a: b ≠ 0 and a₂₂b₁/a₁₂ = b₂ (i.e. a₂₁/a₁₁ = a₂₂/a₁₂ = b₂/b₁, Eq. 12). The second equation is a multiple of the first, the same line, so there are infinitely many solutions: x₂ = (b₁ − a₁₁x₁)/a₁₂ with x₁ arbitrary.
  • 2b: b ≠ 0 and a₂₂b₁/a₁₂ ≠ b₂. These are distinct parallel lines, so there is no solution.
  • 2c: b = 0. Both lines pass through the origin with the same slope, so they are the same line and there are infinitely many solutions: x₂ = −a₁₁x₁/a₁₂.
Geometry in one sentence The ratio of the coefficients sets the slope. The right-hand side sets where the line cuts the axis. b = 0 means the line passes through the origin. det A = 0 means the slopes are equal.

4. Three equations in two unknowns: three lines (Eqs. 16–18, Fig. 4)

A solution exists only if all three lines pass through one common point. The key quantity is the determinant of the 3×3 augmented matrix:

D =
  • If no two lines are parallel, |D| is proportional to the area of the triangle the three lines form. The lines meet at one point ⇔ the triangle shrinks to a point ⇔ D = 0.
  • D = 0 ⇔ one row is a combination of the other two, e.g. (a₃₁, a₃₂, b₃) = c(a₁₁, a₁₂, b₁) + d(a₂₁, a₂₂, b₂) (Eq. 18). The equations are linearly dependent: if two hold, the third holds automatically.
Conclusions
  1. D ≠ 0 ⇒ no solution. This is the only statement that is always safe.
  2. All three equations describe the same line ⇒ D = 0 and infinitely many solutions.
  3. D = 0 and not all the same line ⇒ exactly one solution if no two lines are parallel, and no solution if some two are parallel (and distinct).
D = 0 does NOT guarantee a solution Three distinct parallel lines: the 2nd column of D is a multiple of the 1st, so D = 0, yet there is no common point. You must also check the ranks (Section 6).

5. Three unknowns: planes in space (Eqs. 19–24)

An equation a₁x₁ + a₂x₂ + a₃x₃ = b is a plane with normal vector (a₁, a₂, a₃). If b = 0 it passes through the origin and is a 2-dimensional subspace.

One equation

Every point of the plane works. Solve for one variable: x₃ = (b₁ − a₁₁x₁ − a₁₂x₂)/a₁₃, with x₁ and x₂ arbitrary. This is a two-fold arbitrariness (2 free parameters).

The pattern: rank [A|b] counts the independent equations, and rank A counts the independent left-hand sides (the associated homogeneous equations). They are equal ⇔ there is a solution.

6. The rank rule (preview of Section 8)

Rouché–Capelli (Kronecker–Capelli) theorem For m equations in n unknowns, Ax = b:
  • Solvable ⇔ rank A = rank [A | b].
  • If solvable, the number of free parameters is n − rank A. Unique solution ⇔ rank A = n.
  • Homogeneous Ax = 0 is always solvable. It has a nontrivial solution ⇔ rank A < n. For square A: ⇔ det A = 0.

Why: rank [A|b] > rank A means b is not a combination of the columns of A. But Ax = x₁(col 1) + … + xₙ(col n), so Ax can never equal b.

Practical recipe for 3 or more equations The book suggests: solve any three independent equations first, then check the solution in the remaining ones. Or use the solver in Section 9, which row-reduces [A | b] and reads off both ranks.

7. Cramer's rule (Eqs. 25–35)

Derivation for 3×3

Take a₁₁x₁ + a₁₂x₂ + a₁₃x₃ = b₁ and the two similar equations. Multiply equation i by the cofactor Aⁱᵏ and add all three (Eq. 26):

x₁(∑ᵢ aᵢ₁Aⁱᵏ) + x₂(∑ᵢ aᵢ₂Aⁱᵏ) + x₃(∑ᵢ aᵢ₃Aⁱᵏ) = ∑ᵢ bᵢAⁱᵏ

By the alien-cofactor rule (Eq. 4.5), ∑ᵢ aᵢⱼAⁱᵏ = (det A)δⱼₖ. Only the coefficient of xₖ survives, and it equals det A:

xₖ det A = b₁A¹ᵏ + b₂A²ᵏ + b₃A³ᵏ = Dₖ

The right side is the expansion, down column k, of the determinant Dₖ = det A with column k replaced by b.

Cramer's theorem If det A ≠ 0, the system of n equations in n unknowns has exactly one solution:
xₖ = Dₖ / det A,    k = 1, …, n

Corollaries

  1. det A = 0 but some Dₖ ≠ 0 ⇒ no solution. (From xₖ·0 = Dₖ ≠ 0.)
  2. det A ≠ 0 and b = 0 ⇒ all Dₖ = 0 (a column of zeros) ⇒ only the trivial solution.
The trap: det A = 0 and all Dₖ = 0 Then Cramer's rule says nothing. For n = 2 this means infinitely many solutions (if A ≠ 0). For n ≥ 3 there may be no solution! Example: x + y + z = 1, x + y + z = 2, x + y + z = 3. Here det A = 0 and every Dₖ has two equal columns, so all Dₖ = 0, yet the planes are parallel and there is no solution. Use ranks instead.

When to use Cramer It is excellent for 2×2 and 3×3 systems, for symbolic coefficients, and when you need only one unknown (compute a single Dₖ). For large n it is very slow (n + 1 determinants). Gaussian elimination is what computers use.

8. Feel Cramer's rule: areas

Write the 2×2 system as x₁a₁ + x₂a₂ = b, where a₁ and a₂ are the columns of A. We want to know how much of a₁ and how much of a₂ build b.

det[a₁ a₂] is the (signed) area of the parallelogram on a₁ and a₂. Replace a₁ by b: det[b a₂] = det[x₁a₁ + x₂a₂, a₂] = x₁ det[a₁ a₂], because the x₂a₂ part adds a column parallel to a₂, which adds no area. So

x₁ = area(b, a₂) / area(a₁, a₂),    x₂ = area(a₁, b) / area(a₁, a₂)

10. Physics application: Kirchhoff's laws (Exercises 4, 5)

Kirchhoff's laws turn any DC circuit into a linear system:

  • Junction law: the currents into a node add up to the currents out of it.
  • Loop law: around any closed loop, the sum of EMFs equals the sum of the IR drops.

The circuit has a unique set of currents exactly when the coefficient determinant is nonzero. A negative answer only means the real current flows opposite to the arrow you guessed.

P7. Find the parabola y = a + bx + cx² through (1, 2), (2, 3), (3, 6).
Show solution

a + b + c = 2, a + 2b + 4c = 3, a + 3b + 9c = 6. Differences give b + 3c = 1 and b + 5c = 3 ⇒ c = 1, b = −2, a = 3. So y = x² − 2x + 3. (The determinant is a Vandermonde determinant, (2−1)(3−1)(3−2) = 2 ≠ 0, so the solution is unique.)

P8. Balance C₃H₈ + O₂ → CO₂ + H₂O by setting up a homogeneous system.application
Show solution

Write x₁C₃H₈ + x₂O₂ = x₃CO₂ + x₄H₂O. C: 3x₁ = x₃. H: 8x₁ = 2x₄. O: 2x₂ = 2x₃ + x₄. That is 3 equations in 4 unknowns, rank 3, so there is 1 free parameter. With x₁ = 1: x₃ = 3, x₄ = 4, x₂ = 5. Answer: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O.

P9. True or false: "If det A = 0 and all Dₖ = 0, the system has infinitely many solutions."
Show solution

False for n ≥ 3. Counterexample: x + y + z = 1, 2, 3. Every Dₖ has two proportional columns, so all are 0, but there is no solution (three parallel planes). For n = 2 with A ≠ 0 the statement is true.

P10. Line of intersection of the planes x + y + z = 1 and x − y = 0.
Show solution

rank 2, so there is 1 parameter. Put x = t: then y = t and z = 1 − 2t. Line: (0, 0, 1) + t(1, 1, −2). The direction (1, 1, −2) is the cross product of the normals (1,1,1) × (1,−1,0) = (1, 1, −2) ✓.

P11. A is 3×3 with det A = 0, and b is a combination of the columns of A. How many solutions does Ax = b have?
Show solution

rank A = rank [A|b] < 3, so the system is consistent with at least one free parameter: infinitely many.

P12. Show that a homogeneous system with more unknowns than equations (n > m) always has a nontrivial solution.
Show solution

rank A ≤ m < n, so there are n − rank A ≥ 1 free parameters. Choosing a free parameter ≠ 0 gives a nontrivial solution.

P13. Using Cramer's rule, find only z in: x + y + z = 2, 2x − y + z = 1, x + 2y − z = 3.
Show solution

det A = 1(1 − 2) − 1(−2 − 1) + 1(4 + 1) = −1 + 3 + 5 = 7.
D₃ = = 1(−3 − 2) − 1(6 − 1) + 2(4 + 1) = −5 − 5 + 10 = 0. So z = 0. (Then x + y = 2 and 2x − y = 1 give x = 1, y = 1. Check the third: 1 + 2 − 0 = 3 ✓.)

15. Interesting facts

Older than matrices Solving linear systems by elimination appears in the Chinese text Nine Chapters on the Mathematical Art (around 200 BCE), using counting rods arranged in a grid. That is essentially an augmented matrix, almost 2000 years before Gauss.
Cramer wasn't first Gabriel Cramer published his rule in 1750, but Colin Maclaurin had it in a work published in 1748, and Leibniz used determinant-like ideas in 1693. Determinants came before matrices historically.
Why computers avoid Cramer Cramer with cofactor expansion takes about (n + 1)! operations. For n = 20 that is ~5 × 10¹⁹, years even on a fast computer. Gaussian elimination needs about n³ ≈ 8000 operations.
The prism case Three planes can pairwise intersect in three parallel lines, like the faces of a Toblerone box, and still have no common point. This is the 3D version of three lines forming a triangle, and the reason "no two parallel" does not guarantee a solution.
Physics everywhere Circuit analysis, truss and statics problems, chemical balancing, curve fitting and finite-difference solutions of Laplace's equation all reduce to Ax = b, sometimes with millions of unknowns.
