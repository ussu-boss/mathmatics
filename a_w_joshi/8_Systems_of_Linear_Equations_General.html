0. Roadmap

Section 7 handled small systems by geometry. Here is the complete answer for any number of equations m and unknowns n, using just two numbers:

r = rank A (coefficient matrix),    s = rank B,  B = [A | b] (augmented matrix)
Compute r and s→s > r ⇒ no solution→s = r ⇒ solutions with n − r free parameters→Same tool decides if vectors are independent→row rank = column rank
Needed from earlier Rank as the largest nonzero minor (Section 6), linear dependence of vectors (Section 1), inverse (Section 5), and the case analysis of Section 7.

1. The big picture: each equation removes one dimension

Think of (x₁, …, xₙ) as a point in n-dimensional space.

  • One equation a₁₁x₁ + … + a₁ₙxₙ = b₁ leaves an (n − 1)-dimensional set of solutions (a line in 2D, a plane in 3D, a "hyperplane" in general).
  • Two (independent) equations leave n − 2 dimensions, and so on.
  • m independent constraints leave n − m dimensions.
Regime"Usual" outcomeExceptions
m < n (fewer equations)infinitely many, (n − m)-fold arbitrarinessno solution if the equations are inconsistent; more freedom if they are dependent
m = nexactly one solutiondet A = 0: none or infinitely many
m > n (more equations)no solutionsolutions exist if the extra equations are combinations of the others

The exceptions are exactly where "m" must be replaced by the number of independent equations, and that number is the rank.

2. The two ranks r and s (Eqs. 2–3)

A = (m×n),    B = (m×(n+1))
  • s = number of linearly independent equations in the system.
  • r = number of linearly independent left-hand sides, i.e. independent equations of the associated homogeneous system.
  • Always s = r or s = r + 1. Adding one column can raise the rank by at most 1 (and never lowers it).
  • r ≤ min(m, n), and s ≤ min(m, n + 1).
The fundamental theorem (stated in the book without proof)
  1. s = r ⇒ the system has solutions, with (n − r)-fold arbitrariness: n − r free parameters. (n − r = 0 means a unique solution.)
  2. s > r (i.e. s = r + 1) ⇒ no solution. The equations are inconsistent.

Why (b): s > r means the column b is not a combination of the columns of A. But Ax = x₁(col₁) + … + xₙ(colₙ) is always such a combination, so it can never equal b.
Why (a): pick r independent equations and the r unknowns whose columns give a nonzero r×r minor. Move the other n − r unknowns to the right side as free parameters. Then solve the r×r system by Cramer. The remaining m − r equations are combinations of these, so they hold automatically.

Homogeneous systems are always consistent When b = 0, adding a zero column cannot change the rank, so s = r always and x = 0 is always a solution. The only question is whether there are more: nontrivial solutions ⇔ r < n.

5. More equations than unknowns, m > n (Examples 4, 5)

Homogeneous

r ≤ n. If r = n: only the trivial solution, however many equations there are. If r < n: infinitely many, with (n − r) parameters.

Inhomogeneous

s ≤ n + 1. If s = n + 1 there are n + 1 independent constraints on n unknowns, which is impossible, so no solution. If s ≤ n, decide by comparing r and s as usual.

Practical method from the book Pick any n independent equations, solve them, and substitute the result into the remaining m − n equations. If they are all satisfied, that is the solution. If not, there is no solution.
Example 4: 7x + 4y = 3,  −2x + 3y = 4,  2x + y = −2.

B = , det B = 7(−6 − 4) − 4(4 − 8) + 3(−2 − 6) = −70 + 16 − 24 = −78 ≠ 0. So s = 3 = n + 1 ⇒ no solution. (Three lines forming a triangle, Fig. 7.4a.)

Example 5: 2x + y + 3z = 7,  3x − 2y + 8z = 7,  x − 2y + 4z = 1,  −2x + y − 4z = −3.

The first three equations have rank 2 (det = 2(−8 + 16) − 1(12 − 8) + 3(−6 + 2) = 16 − 4 − 12 = 0). Their solution is x = 3 − 2z, y = z + 1, z arbitrary (Eq. 25).

Substitute into eq 4: −2(3 − 2z) + (z + 1) − 4z = −6 + 4z + z + 1 − 4z = z − 5 = −3 ⇒ z = 2.

x = −1,   y = 3,   z = 2

The 4th equation removed the last free parameter. Here r = s = 3 = n, so the solution is unique even though m = 4 > n.

6. Structure of the solution set: x = xₚ + xₕ extra, very useful

Theorem If xₚ is any one solution of Ax = b, then every solution is x = xₚ + xₕ, where xₕ runs over all solutions of the associated homogeneous system Ax = 0.
Proof: A(x − xₚ) = b − b = 0, so x − xₚ is a homogeneous solution. Conversely A(xₚ + xₕ) = b + 0 = b.
  • The homogeneous solutions form a vector space (the null space, or kernel) of dimension n − r. This is the rank–nullity theorem: rank + nullity = n.
  • So the inhomogeneous solution set is the null space shifted by xₚ. It is a line, plane, … parallel to the homogeneous one, but not through the origin.
  • Example 1(a): xₚ = (7/5, 9/5, 0, 0), and xₕ = z(−4/5, −3/5, 1, 0) + w(−1/5, 8/5, 0, 1).
  • Same idea in physics: the general solution of a linear ODE is (particular integral) + (complementary function).

7. Computing r and s in practice: Gaussian elimination

Checking every minor (Section 6) is slow. Elementary row operations do not change the rank:

  1. swap two rows,
  2. multiply a row by a nonzero number,
  3. add a multiple of one row to another.

They also do not change the solutions of the system. So reduce B = [A | b] to row-echelon form (a staircase of pivots):

  • r = number of nonzero rows in the A-part, s = number of nonzero rows in the whole of B.
  • A row like [0 0 … 0 | c] with c ≠ 0 means "0 = c": inconsistent (s = r + 1).
  • Columns without a pivot belong to the free unknowns. There are n − r of them.

8. How many vectors are independent? (Eq. 27, Example 6)

Given n vectors x₁, …, xₙ, each with m components, solve

a₁x₁ + a₂x₂ + … + aₙxₙ = 0   (Eq. 27)

for a₁, …, aₙ. This is a homogeneous system with coefficient matrix P = [x₁ x₂ … xₙ] (the vectors as columns). If its solution has k arbitrary constants, then the number of independent vectors is n − k.

Example 6 (theorem) x₁, …, xₙ are linearly independent ⇔ P = [x₁ … xₙ] has rank n.
Proof: Eq. 27 is P·a = 0 (Eq. 30). Its only solution is a = 0 ⇔ rank P = n (by Section 2), and "only a = 0" is the definition of independence.
Corollary 1 If m < n, rank P ≤ m < n, so more than m vectors in m dimensions are always dependent. Example: any 4 vectors in 3D space.
Corollary 2 If m = n: n vectors of dimension n are independent ⇔ det[x₁ … xₙ] ≠ 0. The matrix built from n independent n-vectors as columns is nonsingular.

9. Row rank = column rank (Example 7)

Theorem The rank of a matrix equals the maximum number of linearly independent columns, and also the maximum number of linearly independent rows.

Proof idea (book): suppose k of the n columns are independent and the rest depend on them. The m×k matrix of those k columns has rank k (Example 6). Adding the dependent columns back does not raise the rank, so rank A = k = number of independent columns. Since rank Aᵀ = rank A (determinants don't change under transposition) and the columns of Aᵀ are the rows of A, the number of independent rows is also k. ∎

Illustration: A =

Rows: R₂ = 2R₁, and R₁, R₃ are independent ⇒ 2 independent rows.
Columns: C₃ = 2C₂ − C₁, since 2(2, 4, 1) − (1, 2, 1) = (3, 6, 1) = C₃ ✓. C₁ and C₂ are not parallel ⇒ 2 independent columns.
Rank = 2 counted either way.

Why this is surprising For a 3×100 matrix the rows are 3 vectors in 100-dimensional space, and the columns are 100 vectors in 3-dimensional space. They look like totally different objects, but the number of independent ones is always the same (here ≤ 3).

4. Show that if Ax = 0 for all n-dimensional vectors x, then A = 0.
Show solution

Choose x = eⱼ (1 in place j, 0 elsewhere). Then Aeⱼ = j-th column of A = 0. This holds for every j = 1, …, n, so every column is zero ⇒ A = 0. ∎

In terms of rank: the null space is all of ℝⁿ, so the nullity is n and rank A = n − n = 0. Only the zero matrix has rank 0.

P1. x + 2y + 3z = 6, x + 3y + 5z = 9, 2x + 5y + az = b. Find the conditions for a unique solution, no solution, and infinitely many solutions.GATE classic

P7. x₁ and x₂ both solve Ax = b with b ≠ 0. Which of x₁ − x₂, x₁ + x₂, ½(x₁ + x₂), 3x₁ − 2x₂ also solve Ax = b?
Show solution

A(αx₁ + βx₂) = (α + β)b. It is a solution ⇔ α + β = 1. So ½(x₁ + x₂) and 3x₁ − 2x₂ work. x₁ − x₂ solves Ax = 0 instead, and x₁ + x₂ gives 2b.

P8. A homogeneous system has 6 equations, 4 unknowns and rank 4. How many solutions does it have?
Show solution

Only the trivial one: r = n = 4. Having more equations doesn't matter.

P9. Prove: a homogeneous system with more unknowns than equations always has a nontrivial solution.
Show solution

r ≤ m < n ⇒ n − r ≥ 1 free parameter.

P10. Three vectors in ℝ²: (1, 0), (0, 1), (2, 3). Find a nontrivial relation.
Show solution

2v₁ + 3v₂ − v₃ = 0. By Corollary 1 one must exist, since 3 vectors in 2 dimensions are always dependent.

P11. Rank of the n×n matrix with aᵢⱼ = i + j (n ≥ 2)?tricky
Show solution

Row i = i(1, 1, …, 1) + (1, 2, …, n). Every row is a combination of the two vectors u = (1,…,1) and v = (1,2,…,n), which are independent. So the rank is 2.

P12. If the columns of a square matrix A are linearly independent, what can you say about Ax = b?
Show solution

rank A = n ⇒ det A ≠ 0 ⇒ a unique solution x = A⁻¹b for every b (Corollary 2).

P13. Show that rank(AB) ≤ rank A.
Show solution

Each column of AB is A times a column of B, i.e. a combination of the columns of A. So the column space of AB lies inside that of A, and dim ≤ rank A. (Similarly, rank(AB) ≤ rank B using rows.)

14. Interesting facts

Rouché–Capelli The theorem "consistent ⇔ rank A = rank [A|b]" is named after Eugène Rouché (1875) and Alfredo Capelli (1892). In Russia it is called the Kronecker–Capelli theorem, and in Spain the Rouché–Frobenius theorem. The same result has many names.
"Rank" is everywhere The rank of a matrix tells you how many independent pieces of information it holds. Data compression, recommendation systems and quantum entanglement (the Schmidt rank of a two-particle state) all measure rank.
Least squares When m > n and there is no exact solution (s > r), experimental physicists still want the "best" x. The answer solves AᵀAx = Aᵀb, a square n×n system. This is how straight-line fits through noisy data work.
Underdetermined + sparsity When m < n there are infinitely many solutions. Modern "compressed sensing" (used in MRI scanners) picks the one with the fewest nonzero entries, which lets you reconstruct images from far fewer measurements than unknowns.
Gauss and Ceres Gauss developed elimination and least squares in 1801 to predict where the lost asteroid Ceres would reappear, from only a few observations. It was found exactly where he said.
